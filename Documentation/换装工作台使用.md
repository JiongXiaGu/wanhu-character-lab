# 换装工作台 · V5

`npm ci`后`npm run dev`，或双击Start-Local.cmd。普通入口静态试衣；诊断参数review=1默认FBX慢跑。

选择固定男性或女性。没有身高、胖瘦和精度选项；切换基模保留衣服、颜色与暂停动画相位。推荐搭配不会改变性别，“全部10款”可跨男女选择。

右栏更换上衣、下装、头饰、鞋及附件；上衣款式包含领、袖和腰带，不提供无限叠穿。服饰支持主布、下装/内衬、缘边/腰带三色；金属和工具附件保留材质色。发型明确选择高髻、低髻或双髻，帽冠遮蔽后取下恢复。

锁定仅影响随机搭配，不阻止手动选择。seed相同、输入配方与锁集合相同可复现；撤销最多30步。保存仅当前浏览器单槽，不是账号/云存档。

## 文件

导入只接受完整Recipe V5；旧版及额外字段直接报错，当前装扮不变。旧浏览器键不会恢复，不做迁移。请重新搭配后导出V5。

配方JSON只记录外观，不是模型。目标骨架动画JSON是wanhu-target-motion v2，含固定bodyProfile；不是Unity AnimationClip/Avatar，也不包含完整弓箭道具事件。

## FBX试衣

将FBX放进动画参考目录（可有子目录），重启开发服务。动作库支持中英文/分类/文件名检索、收藏、上下一条；中央可选全部动作、暂停、变速、逐帧和拖动进度。坐姿拨开关、射箭、慢跑、抓举建议优先检查。

“动画与结构检查”默认折叠，包含素模、无光照、布线、骨架和源对照；不是另一套动作来源。穿衣外观改由独立服饰负责；去掉服饰查看的是PR #15已修正膝部/裆底的固定裸模（524tris），不是当前服饰制作任务。旧礼衣和分裳仍为短衣/裤式简化，和本轮新增的连续长裙long_skirt是不同资产。

## 已完成的前两批

第一批劳作短衣、交领常服、半臂配内衬，与直筒布裤、束脚行动裤可以男女交叉换穿。没有新增内衬槽位。`npm run review:local -- --wardrobe`提供第一批衣服截图入口，详细面数与边界见《服饰第一批制作与验收.md》。

第二批加入背心、短打短褂、短裤和分片裙裤，推荐夏日劳作/轻装围裳使推荐总数为10。帽饰留量保持，取帽仍恢复同一发型。`npm run review:local -- --lightwear`检查第二批静态混搭与帽饰，加`--full`覆盖完整关键动作、染色、近景和相位保持。历史制作见《轻便服饰与头饰安全留量.md》。

## 当前：短裤、短裙与长裙

右栏“下装”直接选择：封口短裤short_trousers、日常短裙true_short_skirt、素面长裙long_skirt。原short_skirt显示为“分片裙裤·旧短下裳”，仍是原分腿结构；旧V5文件不被替换成另一件真裙。下装库共11款。

短裤可配背心或短褂，两条真裙还可配交领常服，男女共用。裙身对应primary，裙腰与封底secondary，下缘accent；染色不改变几何或静态权重。三件分别176／180／252三角形，逻辑顶点100／97／133。

`npm run review:local -- --skirts`为160张快速视口，加`--full`为412张；另有工作台和16次真实UI换装保持暂停相位检查。图片仍须实际打开。

日常裙装以普通站立、行走、起步、轻跑和坐姿为用途；Snatch深蹲、大开腿、高踢、翻滚属于压力边界，不承诺零穿模。固定裙底并非布料，底部暗面和近景低模折面仍可见。结构、固定封底接触诊断及实际审图范围见《短裤封边与连续裙装.md》和《工作交接.md》。
