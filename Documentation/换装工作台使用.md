# 衣冠工坊使用

拉取 main 后双击 `Start-Local.cmd`，或 `npm ci && npm run dev`。正式预览先 `npm run build` 再 `npm run preview`。不部署 Vercel。

默认进入静态试衣，左侧选男/女，选择搭配灵感；右侧更换上衣、下装、头饰和鞋，再调整三色染色、发式及发色。"全部 8 款" 可查看跨体型推荐，不会偷偷切换男女。切换体型保留当前身高；左侧身材重置才使用男 1.76m、女 1.66m。

## 保存与探索

"导出配方" 输出 Recipe V4 JSON，"导入配方" 严格验证并重建角色。导入的不是 FBX/GLB。"保存装扮"/"恢复装扮" 使用当前浏览器 localStorage 的一个槽位，可能被浏览器清理；重要结果请导出。撤销回退最近最多 30 次编辑，不是完整项目历史。

"随机搭配" 使用整数种子 0–4294967295；每次完成后种子加一。重复输入同种子与相同身体/锁定项可以复现。右侧各部件和染色、发式旁的锁定只影响随机，不妨碍手动编辑。预设是一键组合，因此不受随机锁定约束。

## 试衣与检查

中间下方选择任意 FBX（共 11 个），暂停、变速、拖进度或重播。"绑定姿态（静态）" 只查看原 A 绑定，不创建程序动作。切换服饰/身体后保留暂停相位，换 FBX 不重复建立模型几何。

右侧"动画与结构检查"中可显示素模、布线、骨骼、源骨架和头部朝向；可导出当前体型目标骨架动画 JSON。源与目标头部校准维持既有修复，不用 HeadTop_End 方向当面朝向。

快捷例：

- `?look=town-female&bodyType=female`：杏衫青裙静态试衣。
- `?look=ceremony-male&mixamo=jogging`：绛色礼衣慢跑。
- `?review=1&look=ceremony-female&bodyType=female&mixamo=shooting-arrow&paused=1&phase=.5&view=three`：宫装在射箭中段三视图。
- 原 `?outfit=archer&headwear=farmer_straw_hat` 等链接继续有效。
