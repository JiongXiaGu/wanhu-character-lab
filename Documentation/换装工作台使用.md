# 换装工作台使用 · V2

拉取main，Node22.12+，双击Start-Local.cmd或npm ci后npm run dev。默认静态试衣。

左侧切换男女、身材、八套推荐；右侧七部件槽位、三色染色、发式发色。任何身体能使用全部搭配。预设只改外观，不赋予职业/财富/宫廷身份。切换身体保留现有身高；重置身材才恢复男女默认值。

## 动作试衣

右侧动作试衣库提供中文/英文/文件名搜索、分类、收藏、上一个/下一个。收藏保存在当前浏览器，不属于角色配方。坐姿、射箭、慢跑提供快捷入口；劳动分类包含已归类的搬举测试。抓举不是锄地/推车动画，源文件未提供的道具和场景不会自动出现。

中央动作下拉也能选择所有片段。暂停后拖动进度；上一帧/下一帧以30fps步长定位；重播从头开始。源骨架同步对照和头部朝向工具在右侧折叠检查栏。FBX仅驱动人体，不代表弓弦/箭/事件或工具抓握已完成。

## 新增文件

把FBX放进动画参考/，支持子目录。重启开发服务（或先npm run prepare:mixamo再重启）；构建也自动扫描。无法提取会输出具体文件名，不静默忽略。catalog.generated.ts由脚本生成，不手工加两套注册表。新增未知片段默认单次末帧保持。

## LOD试衣

中央衣物细节LOD0/1/2是真实几何等级，不改变Recipe。比较同一坐姿、射箭或抓举相位，检查腰髋/膝线和轮廓。它不是整个人物的最终人群LOD；当前原身体仍保留，未实现自动距离切换和全身低模。

V2将原宽大裙壳简化为连续裤式分裳。显示仍使用原部件ID以兼容保存，款式名称改为分裳，不把轮廓取舍掩盖成原连筒长裙已经物理正确。

## 保存

撤销最近30步；浏览器保存单个装扮；JSON导入导出跨浏览器保留配方。随机锁定只约束随机，不限制手动选择。非法导入保持现有人物。Recipe导出不是FBX模型，动画JSON导出也不是Unity现成导入器。
