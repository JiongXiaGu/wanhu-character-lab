# 换装工作台 · V5

`npm ci`后`npm run dev`，或双击Start-Local.cmd。普通入口静态试衣；诊断参数review=1默认FBX慢跑。

选择固定男性或女性。没有身高、胖瘦和精度选项；切换基模保留衣服、颜色与暂停动画相位。推荐搭配不会改变性别，“全部10款”可跨男女选择。

右栏更换上衣、下装、头饰、鞋及附件；上衣款式包含领、袖和腰带，不提供无限叠穿。上衣/裤装均支持主布、下装/内衬、缘边/腰带三色；金属和工具附件保留材质色。发型明确选择高髻、低髻或双髻，帽冠遮蔽后取下恢复。

锁定仅影响随机搭配，不阻止手动选择。seed相同、输入配方与锁集合相同可复现；撤销最多30步。保存仅当前浏览器单槽，不是账号/云存档。

## 文件

导入只接受完整Recipe V5；旧版及额外字段直接报错，当前装扮不变。旧浏览器键不会恢复，不做迁移。请重新搭配后导出V5。

配方JSON只记录外观，不是模型。目标骨架动画JSON是wanhu-target-motion v2，含固定bodyProfile；不是Unity AnimationClip/Avatar，也不包含完整弓箭道具事件。

## FBX试衣

将FBX放进动画参考目录（可有子目录），重启开发服务。动作库支持中英文/分类/文件名检索、收藏、上下一条；中央可选全部动作、暂停、变速、逐帧和拖动进度。坐姿拨开关、射箭、慢跑、抓举建议优先检查。

“动画与结构检查”默认折叠，包含素模、无光照、布线、骨架和源对照；不是另一套动作来源。穿衣外观改由独立衣裤负责；去掉衣裤查看的是PR #15已修正膝部/裆底的固定裸模（524tris），不是当前服饰制作任务。礼衣和分裳暂为短衣/裤式简化版，不代表完整长裙。

## 服饰第一批

选择劳作短衣、交领常服、半臂配内衬；搭配直筒布裤或束脚行动裤，男女均可交叉换穿。Recipe仍V5，无新增内衬槽位。`review:local -- --wardrobe`提供专门的衣服截图入口，详细面数/色区/验收边界见《服饰第一批制作与验收.md》。
## 第二批轻便服饰

新增干活背心、短打短褂、及膝短裤、短下裳·分片裙裤，原五件常服和职业搭配保持。轻便推荐为夏日劳作/轻装围裳，男女都可选，推荐总数为10。帽饰允许夸张外扩，取帽仍恢复同一发型。

`npm run review:local -- --lightwear`生成第二批静态混搭与帽饰图片；加`--full`覆盖关键动作、染色、近景和相位保持。图片需要实际打开审查。短下裳采用能分开随两腿运动的A字裙裤，不是连续布料裙。
