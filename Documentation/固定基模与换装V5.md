# 固定基模与换装 V5

## 目标与配方

固定成年男女基模、一档标准低模，以服饰、发型、帽饰和染色提供差异。Web只做外观与FBX试衣，Unity负责玩法，不建设连续体型或缩放编辑器。

Recipe V5精确六字段：version、bodyType、slots、dyes、hairStyle、hairColor。七slots完整，三色六位HEX。未知／缺字段、旧版本、超过32KB文件拒绝且不改变当前角色。存储键wanhu.character.wardrobe.v5，不读取旧键或迁移旧配方。createRecipe只用于内部，用户文件必须parseRecipeFile严格验证。

动作导出wanhu-target-motion v2，bodyProfile只含固定基模id/version，不存身高胖瘦，不是Unity AnimationClip或Avatar。保留三发式、跨男女混搭、三色／发色、锁定、seed、30步撤销、保存、文件往返、动态FBX搜索／分类／收藏、逐帧和暂停相位保持。10张搭配灵感维持原ID且不强制改性别；旧“基础搭配”入口和Outfit预设协议已退役。

## 服饰与人体

patterns当前管理7上衣／5下装；鞋只保留cloth_shoes。assets拥有独立衣裤裙鞋及静态双权重；assembly按固定covers装配可见皮肤。人体不负责适应衣服，各服饰共享当前基模的20骨骼，不增加服装Animator。

服装wanhu-modular-garments-v7，皮肤wanhu-skin-cage-v3，绑定wanhu-fixed-bodies-v1。资源v7不是Recipe升级。男女源皮肤各524三角形，女性沿用固定制作映射一次。

short_trousers为封口短裤；true_short_skirt为连续真短裙；long_skirt为连续素面长裙；work_pants与work_wrap是当前两种实用长裤。短裤／短裙只遮pelvis/thigh，保留原小腿；长裙与长裤还遮shin。背心／短褂只遮torso，裸露上臂仍绘制。旧short_skirt及其他被淘汰裤型已从当前协议删除。

## 检查与边界

身体／绑定保护签名不刷新，上传FBX／参考模型不改。源帧和中点采样算法不变，但样本总数按当前5款正式下装加body动态计算，不再把退役资产计入。裙装固定封底与腿出口／末端裙边的数学接触单列，但仍计算并记录原始交点；两条连续裙的Snatch深蹲举重列为服饰压力边界。普通动作非接口穿插继续阻塞。

普通站立、行走、起步、轻跑、坐姿属于日常裙装范围；极端开腿、高踢、翻滚不是承诺。9相位有限值检查不能替代源键／中点贯穿或实际看图。数值检查、真实截图、人工抽查分别记录于工作交接。
