# 固定基模与换装 V5

## 目标

两个固定成年男女基模、一档标准低模，以服饰轮廓、发式、头饰和染色提供差异。Web只做外观与FBX试衣，Unity负责玩法；不建设连续体型或缩放编辑器。

## Recipe契约

Recipe V5精确包含六个顶层字段：version、bodyType、slots、dyes、hairStyle、hairColor。七个slots必须完整；三色必须为六位HEX。未知字段、缺字段、旧版本及大于32KB的文件拒绝，当前角色保持不变。存储键为wanhu.character.wardrobe.v5，不读取旧键、不迁移旧配方。

动作导出wanhu-target-motion版本2，bodyProfile只含固定基模id／version，不再存连续体型。该JSON不是Unity AnimationClip或Avatar。

保留三种发式、跨男女混搭、三色／发色、部件锁定、seed随机、30步撤销、浏览器保存、文件导入导出、全部FBX动态扫描、搜索／分类／收藏、暂停逐帧和源骨架对照。当前23份FBX不是数量上限。推荐搭配现为10套：原8套全部保留，加夏日劳作／轻装围裳；推荐不强制切换性别。基础农户／卫兵／弓手是现有可编辑资产，不是旧协议兼容层。

## 服装与人体的边界

`patterns.ts`管理9上衣／9下装；`assets/`提供独立衣裤鞋网格与静态双权重；`assembly.ts`按资产覆盖表装配可见皮肤。人体不负责适应衣服轮廓。各衣服可以有独立拓扑，但共享当前基模的同一套20骨骼，不新增服装Animator。

当前几何为 `wanhu-modular-garments-v6`，皮肤为 `wanhu-skin-cage-v3`，绑定为 `wanhu-fixed-bodies-v1`。资源版本v6不代表Recipe变成V6。男女皮肤均524三角形，女性服装沿用既有固定映射一次。

第一批升级劳作短衣、交领常服、半臂配内衬、直筒布裤和束脚行动裤；第二批新增真无袖背心、短袖短褂、及膝短裤与A字分片短下裳，并扩大包覆帽饰。半臂仍为一件上衣，短下裳仍为一个下装槽。后者明确采用裙裤式简化，不宣称连续软布短裙。

短装只覆盖自身需要的区域：第二批上衣covers为torso；下装covers为pelvis／thigh。必须保留裸露的原上臂和小腿，不能沿用长袖／长裤覆盖去整块删掉它们。戴包覆帽时沿用原发髻遮蔽规则，不缩小源头皮／头发，不新增按发型拟合表。
