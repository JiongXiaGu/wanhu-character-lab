# 固定基模与换装 V5

## 目标与配方

固定成年男女基模、一档标准低模，以服饰、发型、帽饰和染色提供差异。Web只做外观与FBX试衣，Unity负责玩法，不建设连续体型或缩放编辑器。

Recipe V5精确六字段：version、bodyType、slots、dyes、hairStyle、hairColor。七slots完整，三色六位HEX。未知／缺字段、旧版本、超过32KB文件拒绝且不改变当前角色。存储键wanhu.character.wardrobe.v5，不读取旧键或迁移旧配方。createRecipe只用于内部，用户文件必须parseRecipeFile严格验证。

动作导出wanhu-target-motion v2，bodyProfile只含固定基模id/version，不存身高胖瘦，不是Unity AnimationClip或Avatar。保留三发式、跨男女混搭、三色／发色、锁定、seed、30步撤销、保存、文件往返、动态FBX搜索／分类／收藏、逐帧和暂停相位保持。推荐10套维持原ID，不强制改性别。

## 服饰与人体

patterns管理9上衣／11下装；assets拥有独立衣裤裙鞋及静态双权重；assembly按固定covers装配可见皮肤。人体不负责适应衣服，各服饰共享当前基模的20骨骼，不增加服装Animator。

服装wanhu-modular-garments-v7，皮肤wanhu-skin-cage-v3，绑定wanhu-fixed-bodies-v1。资源v7不是Recipe升级。男女源皮肤各524三角形，女性沿用固定制作映射一次。

short_trousers为加厚封边短裤；true_short_skirt为连续真短裙；long_skirt为连续素面长裙。旧short_skirt保留分片裙裤语义，不改ID或偷偷替换旧V5造型。短裤／短裙只遮pelvis/thigh，保留原小腿；长裙还遮shin。背心／短褂只遮torso，裸露上臂仍绘制。帽饰与源头发本轮不改。

## 检查与边界

身体／绑定保护签名不刷新，上传FBX／参考模型不改。所有旧源帧和中点样本保留，11下装加body共24,216样本。裙装固定封底与腿出口／末端裙边的数学接触单列，但仍计算并记录原始交点；只有两条新裙子的Snatch深蹲举重列为服饰压力边界。旧衣裤无例外，普通动作非接口穿插继续阻塞。详情见《短裤封边与连续裙装.md》。

普通站立、行走、起步、轻跑、坐姿属于日常裙装范围；极端开腿、高踢、翻滚不是承诺。9相位有限值检查不能替代源键／中点贯穿或实际看图。数值检查、真实截图、人工抽查分别记录于工作交接。
