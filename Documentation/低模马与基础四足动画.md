# 低模马与基础四足动画

## M1的目标与范围

马是《万户天工》的独立低模实验资产，不是人物服装或Recipe槽位。先验收马本体、四足骨架和Idle／Walk／Run／Eat，再由用户决定是否合并以及进入M2。当前没有骑手、RiderSeat运行时、上／下马、坐骑控制或正式马具。

采用与人物相容的写意块面：栗色主体、实体鬃尾、略大的头部、明确的耳朵和蹄子。不做写实肌肉、毛发、皮肤纹理或复杂五官。主壳提供胸腔、腹部和臀部轮廓，腿保留关节附近截面，不以预设三角形数字反推造型。

## 网格与资源边界

当前网格为1524个三角形、806个逻辑顶点、25根骨骼。低模块面在渲染时逐三角拆点，实际BufferGeometry为4572个渲染顶点；不能将该数字当作逻辑顶点。一个马本体SkinnedMesh、一套Skeleton、每逻辑顶点至多两非零权重。

网格版本为wanhu-horse-mesh-m1-v1，绑定与动作分别为wanhu-horse-rig-m1-v2、wanhu-horse-motion-m1-v2。绑定v2仅把Neck支点移入肩胸；绑定世界中的外形点、上颈、头和人物骨架没有因此改动。资源版本不升级人物Recipe。

| 部分 | 三角形 |
|---|---:|
| 胸腹臀连续主壳 | 192 |
| 颈部／头部 | 120／120 |
| 四条腿 | 每条144，共576 |
| 四个蹄 | 每个48，共192 |
| 马鬃／额发 | 72／36 |
| 双耳 | 每侧36，共72 |
| 双眼／眼部小亮面／鼻孔 | 每侧各8，共48 |
| 尾部 | 96 |

每个制作壳闭合，颈根、腿根、鬃尾和眼部等处保留固定制作重叠；并非整匹马的单一焊接流形。自动检查要求各壳合法、闭合、朝向正确，不能把通过解释成各壳之间零数学相交。不存在随动作临时删面、碰撞修正或皮肤滑动。

## 代码职责与生命周期

| geometry/legs.ts | 四腿截面、关节过渡、蹄和袜色 |

| rig.ts | 名称、父关系、局部绑定、真实inverse bind |

| HorseViewport.tsx | 马的画幅、相机、灯光、材质检查和只读Review钩子 |

| src/animation/clip-clock.ts | 人物与马共用的有限时间游标，不认识具体骨架 |

网格／绑定在Actor创建时生成；切换动作复用同一网格。四个AnimationClip创建时烘焙，播放阶段只推进时间并采样轨道，不执行作者层几何生成、IK或腿部目标求解。卸载页面时停止帧循环并释放Mixer、Skeleton、Geometry、材质、相机控制器和阴影资源。

没有为牛、猪、驴提前抽象Quadruped平台。人物Viewport的源FBX对照与20骨骼接口保持独立，不强行套用给马。共享部分是原时间游标的等价抽取和review:local启动器，不重做人物动画／重定向系统。

权重形式为[boneA,boneB,weightA]，另一权重为1-weightA。关节过渡环用相邻两骨，头、蹄和小结构通常刚性归属一骨；硬边拆点复制原权重，不重新求解。蒙皮使用世界姿态矩阵乘真实inverse bind，不能把第一动画帧当作绑定。

## 四种动作与轨道职责

| 动作 | 时长 | 内容与检查重点 |
|---|---:|---|
| Horse_Idle | 3.6秒 | 轻呼吸、头颈变化、小幅甩尾，不是雕像，也不大幅摇背 |
| Horse_Walk | 1.2秒 | 四拍交替，后左→前左→后右→前右；抬蹄与关节弯曲配合，小幅背部起伏 |
| Horse_Run | 0.8秒 | 独立非对称接地相位与更大收伸腿，不是Walk倍速；包含伸展和腾空 |
| Horse_Eat | 6秒 | 平滑低头、觅食停留、轻微头部变化和抬头，完整循环，无嘴部骨架 |

每个片段有24条局部四元数轨道及1条Pelvis局部位置轨道。Root不写动画轨道，不含水平根运动或缩放。Pelvis／Spine／Chest负责低幅躯干变化；Neck／NeckUpper／Head分担头颈；各腿四骨负责局部关节与蹄朝向；Tail／TailEnd负责有限摆动。蹄姿在作者层抵消链条俯仰，不读取地形或目标位置。

曲线在创建片段时按30fps烘焙为标准AnimationClip。含完整末帧，末帧回到第一姿态。共享时间游标处理有限正时长、暂停定位、循环、结束保持和重播；播放和相机操作不重建网格。

首稿审图与数值复核发现Walk最低蹄点约入地4厘米、Eat口鼻离地偏高。v2重新标定作者层骨盆高度曲线及颈根支点，而不是加入实时贴地、增加整马缩放或把地面降低。新增检查将过量入地／悬空吃草列为失败，不再仅输出诊断后宣称通过。

## Horse Lab入口

使用任务分支启动npm run dev，人物默认工作台保持。人物页顶部中央提供“人物工坊 / 动物工坊”一级切换器；点击“动物工坊”当前直接进入Horse Lab。也可使用页面查询参数?lab=horse。独立页面提供四个动作、静态绑定、播放／暂停、重播、前后逐帧、时间／相位、循环和速度。

相机有正面、左侧、右侧、背面、前侧三分之四、后侧三分之四，以及正交／透视和鼠标旋转缩放。另有原色／素模／线框、骨架与参考网格。暂停切换相机保持相位。

本地一键入口为npm run review:local -- --horse。它复用既有启动器；--horse当前执行完整104张视口图矩阵，--full不删减或改成另一套矩阵。不得把GitHub runner中的该命令称为执行者本机网页截图。

## 自动检查与证据边界

npm run check:horse依次执行check-horse.ts和check-horse-ground.ts。前者检查逻辑顶点有限值、索引、退化面、逐壳封闭与方向、绑定对称、骨骼父序、最多双权重、真实inverse bind、四个片段、轨道时间／单位四元数、首尾接缝及矩阵有限性。每片段241个姿态，总964姿态、776984个逻辑顶点采样；循环推进、单次末帧保持、重播、时间非法值与网格复用另外检查。

Spine向上方向和垂直位移有数值保护，不能以不爆炸代替步态美术。ground检查读取同一SHA、同一绑定／动作版本的真实采样结果，要求蹄点不低于-0.012米、头不穿地，Eat最低头部离地0.01–0.12米。五个故障注入验证旧版4厘米入地、头部穿地、悬空吃草、NaN和缩水采样会失败。该允许量是低模平面实验容差，不代表承诺零滑步或任意地形适应。

真实浏览器矩阵为6张静态视图，加4动作×3视角×8相位的96张，再加素模／骨架两张，共104张视口原PNG。另有工作台与390px页面各一张，以及9张接触表。相位为0、0.125、0.25、0.375、0.5、0.625、0.75、0.875；动画视角为front、left、three。

浏览器检查逐帧1/30秒、上一帧返回、暂停换相机相位保持、真实播放前进、速度控制、末帧保持／跨末帧循环、原人物20骨骼与Recipe V5，以及人物／动物顶部一级工作区切换器的当前态和目标地址。检查通过不是逐三角运动相交证明。每张图保存校验值，不能只挑好图留证。

正式马匹job追加在Character Model Review中，artifact为horse-m1-review。原model-review和其余五条永久流程、所有人体／服饰／源FBX压力样本完整保留；不增加第七条永久workflow。临时候选workflow在进入正式阶段时删除。具体受测SHA、下载产物及实际打开图像记录在工作交接与对应PR验收评论，不能引用旧裙装六项成功冒充M1成功。

## 后续骑乘的设计预留

以下只是设计坐标，不会在当前运行时创建骑乘锚点或逻辑。未来RiderSeat优先挂Spine，初始局部位置可从(0,0.35,0.12)开始校准；该处在绑定时约为世界(0,1.65,0)，位于背中段。验收骑手时还须检查实际骨盆／腿姿和动作适配，不直接把这个初值当最终坐姿。

未来DismountLeft／Right适合定义在实例Root的左右地面空间，候选偏移为(-0.9,0,0)和(0.9,0,0)。它们不随头颈和单腿摆动。本阶段不创建SaddleGuide、骑乘动画、人物父子绑定或上／下马流程。

迁Unity时应保留骨骼顺序、父索引、局部绑定、inverse bind、双权重和局部轨道，显式核对坐标、正方向与xyzw。当前没有马的Unity导入器、GPU动画纹理、批量实例化或大规模性能测试；单体预览关闭静态包围盒剔除，迁移前需要烘焙动作并集边界。低面数不等于已实现GPU群体运行时。

## 保留的视觉限制

近景颈根、后肢关节和腿根能看见低模折面，封闭壳制作交界有重叠。Run的收腿仍偏简化机械感，Eat是固定蒙皮低头，不含嘴唇或咀嚼肌肉。Walk／Run为原地动画，蹄在地面平面上前后摆动本身不是正式移动系统；没有根速度耦合，也不宣称完全无滑步。

有限相位接触表和关键原图抽查不能证明全部连续时刻零穿插。本阶段没有实时IK、蹄地形适配、碰撞纠正、毛发／尾巴物理、行为树、NavMesh、其他动物、马车、装备库存或任何骑乘内容。
