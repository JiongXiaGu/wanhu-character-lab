# 低模马与基础四足动画

## 目标与当前范围

M1马本体已经通过PR #20合入main。马仍是独立低模实验资产，不是人物服装或Recipe槽位。src/horse保持马的模型、25骨骼与Idle／Walk／Run／Eat；M2骑乘由src/riding组合现有人物与马，不把骑乘职责塞回马本体。骑乘挂接见《骑乘与坐骑挂接.md》。

采用与人物相容的写意块面：栗色主体、实体鬃尾、略大的头部、明确的耳和蹄。不做写实肌肉、毛发、皮肤纹理或复杂五官。现有动作仍是供形变预览的原地实验，不因M2接入自动宣称步态美术正式验收。

## 网格与资源

当前网格1524三角形、806逻辑顶点，25骨骼，每逻辑顶点最多双权重。渲染硬边逐三角拆点后4572顶点，不得混淆两个顶点数字。一个马本体SkinnedMesh和Skeleton。

网格wanhu-horse-mesh-m1-v1，绑定wanhu-horse-rig-m1-v2，动作wanhu-horse-motion-m1-v2。M2不更改这些版本；骑乘资源另有自己的版本，不升级人物Recipe。

每个制作壳闭合，颈根、腿根、鬃尾和眼部等处保留固定制作重叠，不是整匹马单一焊接流形。检查逐壳合法、封闭和朝向，不意味着不同壳之间零数学相交。没有随动作临时删面、碰撞纠正或皮肤滑动。

## 代码职责与生命周期

geometry/builder.ts提供闭合截面和小八面体工具；geometry/body.ts拥有胸腹、颈头的外形与静态权重；legs.ts拥有腿与蹄；details.ts拥有鬃尾、耳、眼鼻。rig.ts拥有骨骼与绑定，skinning.ts装配渲染Actor并释放资源。animation.ts在创建片段时烘焙局部轨道，player.ts只推进有限时间游标并采样标准Mixer。HorseViewport与HorseLab拥有独立场景与控件。

换动作不重建网格，播放不执行作者层几何生成、IK或腿目标求解。卸载时停止RAF并释放Mixer、Skeleton、Geometry、材质、相机控制器和阴影资源。不要提前抽象通用Quadruped。原人物FBX对照与20骨骼接口保持独立；仅共享src/animation/clip-clock.ts和按需review启动器。

## 骨架与绑定

米制，+X右、+Y上、+Z前。HORSE_JOINTS是索引、父序和绑定位置的实现权威；完整表也由check:horse输出。骨架为Root、Pelvis、Spine、Chest、Neck、NeckUpper、Head，四腿各Upper／Middle／Lower／Hoof，Tail／TailEnd。耳和眼鼻随Head，无面部骨链；尾只有两骨，无物理。

绑定局部位置为本骨绑定世界位置减父骨位置，局部旋转单位xyzw=(0,0,0,1)，缩放(1,1,1)。权重记录为[boneA,boneB,weightA]，另一权重1-weightA；硬边拆点只复制，不重新求解。使用世界姿态矩阵乘真实inverse bind，不能用动画首帧作绑定。

Spine绑定世界(0,1.30,-0.12)，M2使用普通RiderSeat挂点，不改变骨骼调色板。M1预留的(0,0.35,0.12)座面偏移已由组合层采用并加上男女骨盆坐面距离；不能把它直接理解为人物Hips世界位置。左右下马点(-0.9,0,0)/(0.9,0,0)仍仅设计预留，不创建上下马流程。

## 动作与轨道

| 动作 | 时长 | 制作内容 |
|---|---:|---|
| Horse_Idle | 3.6秒 | 轻呼吸、头颈变化、低幅甩尾 |
| Horse_Walk | 1.2秒 | 后左→前左→后右→前右四拍交替，小幅背部起伏 |
| Horse_Run | 0.8秒 | 独立非对称接地相位，更大收伸腿与腾空，不是Walk加速 |
| Horse_Eat | 6秒 | 低头、停留觅食、抬头完整循环，无嘴部骨架 |

每片段24条局部四元数轨道及一条Pelvis局部位置轨道，Root不写动画轨道，没有水平根运动或缩放。Pelvis／Spine／Chest负责躯干，双节颈与头分担低头，四腿负责关节与蹄朝向，尾部低幅摆动。蹄姿在作者层抵消链条俯仰，不读地形或目标。

作者曲线按30fps烘焙标准AnimationClip，含回到首姿的完整末帧。clip-clock处理有效正时长、暂停定位、循环、结束保持和重播。Walk首稿4cm入地和Eat头偏高由v2作者高度曲线与颈根校准修正，没有降低地面、整体缩放或加入实时贴地。

## 页面与检查

main运行后由“动物工坊”进入?lab=horse；?lab=horse&pose=bind&paused=1可直接静态检查。右侧二级入口可去骑乘试衣。马本体仍保留四动作、逐帧、循环、变速、时间与相位，正／左／右／背／前后三分之四相机，正交／透视、素模、线框、骨架与参考网格。暂停换相机不改变相位。

npm run check:horse执行网格、骨骼、权重、真实绑定、轨道、首尾、有限矩阵、播放与网格复用检查；每片段241姿态，共964姿态、776984逻辑点采样。ground门槛要求蹄不低于-0.012米、头不穿地、Eat最低头离地0.01–0.12米。五个故障注入保护旧4cm入地、头穿地、悬空吃草、NaN及缩水采样，不能降为仅诊断。

当前正式自动检查由Targeted Numeric Checks按改动路径执行。旧“六条永久workflow／每次自动104张马图”是历史流程，不再适用。需要视觉审查才运行npm run review:local -- --horse或Manual Visual Review；该马脚本保留104视口图（静态6＋四动作×三视角×八相位96＋素模骨架2）、工作台与小屏及接触表作为按需工具，不要求日常每轮运行。生成图片不等于人工看图通过。

## 已知边界与迁移

近景颈根、后肢关节及腿根可见低模折面，制作壳交界有固定重叠。Run收腿仍简化，Eat不含嘴唇／咀嚼。旧M1受测Eat最低蹄约低于检测平面4.6mm，是在容差内，不写完全不入地。原地动画没有根速度耦合，不宣称零滑步或任意地形适配；有限相位检查也不是全时域零穿插证明。

迁Unity需保持骨骼顺序、父索引、局部绑定、inverse bind、双权重及局部轨道，核对方向和xyzw。当前无动物Unity导入器、FBX成品导出、GPU动画纹理、批量实例化或群体性能验证。单体预览关闭静态包围盒剔除；迁移前需烘焙动作并集边界。低面数不等于群体运行时已经实现。
