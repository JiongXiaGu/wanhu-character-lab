# 骑乘与坐骑挂接

## 目标与边界

骑乘组合层复用原V5人物与坐骑目录，不新建骑手人体、不把坐骑塞进人物七槽位。Recipe仍只有version、bodyType、slots、dyes、hairStyle、hairColor六字段。M2基本骑乘和M3马鞍／缰绳已获用户接受；M4-A加入灰驴，M5增加双峰骆驼；已认可的马和灰驴资源不重做。物种资产细节见《多坐骑与灰驴.md》，鞍具与绳算法见《马鞍与缰绳.md》。

提供静态骑姿、停驻、步行和奔跑。骑手动作是项目制作并烘焙的局部轨道，不是新增Mixamo FBX；原人物工坊仍只使用静态绑定与原FBX，不能把骑姿当FBX失败回退或恢复旧程序劳动动作库。没有上下坐骑、手指弯曲、实时IK、地形贴蹄、导航、玩家移动、骑射或马车；进食只在坐骑本体页播放。

## 数据所有权

src/horse、src/donkey与src/camel各自拥有本体、绑定和动作；src/mounts/catalog.ts注册完整坐骑与适配配置，src/mounts/player.ts用语义动作采样当前资源。动物骨骼数量不由骑乘UI规定：原马25骨、灰驴27骨、骆驼29骨，各自真实绑定。两套Skeleton不与人物20骨合并，不共用男女最终矩阵。

src/riding/types.ts将Rider_Idle／Walk／Run映射到当前坐骑idle／walk／run，读取当前时长。rider-seat负责座点与男女挂接；rider-pose在创建时烘焙该坐骑的跨坐和持缰姿态；riding-player拥有组合层生命周期；reins在两套骨架同帧采样后更新原缓冲。RidingViewport只持有一个场景和RAF；RiderWardrobe编辑同一V5配方；RidingLab管理界面状态而不生成几何。

MountDefinition只提供真实需求下的最小接口，不成为通用四足平台。历史horse／horsePhase字段和__HORSE_REVIEW__属于原马测试兼容出口；实现使用当前坐骑，不能因此硬编码25骨或Horse_Walk时长。

## 挂点与绑定空间

米制，+X右／+Y上／+Z前。当前三种坐骑的Spine → RiderSeat → RiderRoot → 人物SkinnedMesh。实际背骨名来自物种SaddleProfile；Seat是普通Group，不插入动物骨骼调色板。SaddleRoot与Seat为同背骨下稳定兄弟挂点，替换鞍具不删除人物Seat。

坐面归当前物种的鞍具配置所有，RiderRoot减去男女各自绑定Hips位置，再加骨盆到坐面的制作距离。马保持M3认可数值，灰驴有自己的较窄跨坐方向；这些值不进入玩家配方。坐面不是Hips原点。

人物Actor先独立创建与绑定，再挂到坐骑。挂接后不重新bind、不重算inverse bind、不调用Skeleton.pose。整动物平移、旋转与等比缩放必须只应用一次；骨架Helper保持正确世界变换，不在Seat下重复应用变换。

## 骑姿与时间

每种坐骑读取自己的RiderFit，按男／女尺寸设定大腿外展、膝和小腿方向；马原腿手数值不因引入灰驴改变。骆驼通过RiderFit可选upperArmDirection／forearmDirection调整持缰高度；其他物种未配置时使用原数值，不改马／驴轨道。手掌仍只有既有低模块面，没有手指弯曲或精确握拳。局部四元数轨道按30fps创建，完整首尾；只写人物现有20骨，不写根平移／缩放，也不复制动物背部升降。

当前坐骑播放器是唯一时间所有者。先推进或定位坐骑并更新背骨／头骨，再按同一相位采样骑手，最后更新掌心、嘴环与缰绳。暂停、逐帧、变速、循环、单次末帧保持和重播均走同一路径，没有第二个累加器。

## 切换与生命周期

切动作、材质、相机、暂停或拖时间不重建网格。普通／旅行鞍具切换只替换马具并调整座点，保留人物、坐骑、绳缓冲和进度。

换种类先构造候选坐骑及其鞍具、播放器、座点、绳和骑手轨道。成功后保留原人物网格和inverse bind、移除旧动物、挂接新父对象并恢复动作语义与归一化相位。时长改变时秒数随之改变。相机保留方向／缩放，只适配构图高度。非法ID不清空原对象，释放旧资源不能误释放共用人物。

改V5配方只替换骑手；握绳点重新挂到新人物，保留当前动物、相位、绳网格和相机。none隐藏人物／骨架／绳，冻结骑乘但保留装扮和进度；none期间允许换动物，不静默装鞍。隐藏人物只是页面缓存，退出时必须释放。

卸载停止RAF与ResizeObserver，依赖逆序释放绳挂点、马具、两套Mixer／Skeleton、网格材质、Helper、控制器和渲染器。dispose可重复，不残留旧抓握点或动物。只读取wanhu.character.wardrobe.v5中用户明确保存的装扮；外部JSON继续严格验证32KB、字段、版本和现役ID；骑乘不静默覆盖原人物存档。

## 页面与服饰

人物工坊 → 动物工坊 → 骑乘试衣。直接?lab=riding默认栗色马与普通鞍具；灰驴旅行静态入口?lab=riding&mount=donkey_gray&saddle=travel&clip=pose&paused=1。二级模式携带种类和鞍具，从无鞍本体进入骑乘仍需主动选鞍。

全部7上衣、5下装和布鞋可试穿；裤装为骑乘基准。连续封底裙可能与动物和马具穿插，保持试验提示，不自动换裤、拆裙、删封底或随动作删皮肤。手持物保留并提示与持缰冲突，不表示支持骑射／劳动。相机右上，底部默认循环。

## 检查与证据

原check:riding仍以马为基准保留1446稠密动态姿态、70套衣裤及四类故障男女各一次，原check:saddles保留马具和缰绳专项。check:mounts增补灰驴964本体姿态、2892骑乘姿态、70衣裤和物种切换生命周期，M5再追加骆驼同等964／2892／70矩阵及24次三物种切换，不替代旧门槛。

三个浏览器专项均运行真实桌面交互，不生成截图。报告mounts-m4-checks记录实际受测SHA。数值／交互通过不是新增灰驴美术验收，不是所有连续时刻衣物与动物零相交证明。用户接受旧马效果不自动代表新动物姿态、鞍具与接触细节已认可。
