# 骑乘与坐骑挂接

## 目标与边界

骑乘组合层复用现有V5人物与M1马，不新建骑手专用人体，不把马加入人物七槽位。Recipe仍只有version、bodyType、slots、dyes、hairStyle、hairColor六字段。M2的基本跨坐效果已获用户认可；M3在其上增加整体马鞍与同帧缰绳，不借此重做人体、衣裤或原马动作。

当前提供静态骑姿、停驻、步行和奔跑，骑手动作是本项目制作并烘焙的局部轨道，不是新增Mixamo FBX。原人物工坊仍只使用静态绑定与原FBX；骑乘轨道不是FBX失败回退，不恢复旧程序劳动动作库。

马鞍、辔头与缰绳的作者资源、选择规则和动态几何契约见《马鞍与缰绳.md》。没有上下马、手指弯曲、实时IK、地形贴蹄、导航、玩家移动、骑射或马车。Horse_Eat只在马匹本体页保留，不建立骑乘吃草配对。

## 挂点与绑定空间

统一米制、+X右／+Y上／+Z前。挂接仍为Horse Spine → RiderSeat → RiderRoot → 人物SkinnedMesh。SaddleRoot和RiderSeat同属Spine，替换马鞍不删除稳定Seat。Seat为普通Group，不插入25骨骼调色板。

坐面偏移由当前马鞍目录拥有；男性骨盆相对坐面抬高0.13米，女性0.12米。RiderRoot减去该基模绑定Hips位置，再加制作距离。RIDER_FIT是实现权威，不把这些制作值复制为玩家配方字段。原M2的裸马背0.35米偏移属于历史，不再固定用于所有马鞍。

Actor先在原点和真实绑定空间创建，再挂整个人物。挂接后不重新bind、不重算inverse bind、不调用Skeleton.pose代替骑姿。测试必须覆盖整马平移、旋转和等比缩放，骨架Helper保持正确的世界变换而非在Seat下重复应用父变换。

## 骑姿与时间

男女根据各自绑定尺寸跨坐：大腿外展、膝盖下降、小腿在马腹两侧、脚向前。腿部沿用M2认可方向，M3只微调手臂与块面手掌的持缰方向并按鞍面升高坐点。没有手指骨骼，不能宣称已经精确握拳。

Rider_Idle／Walk／Run分别配Horse_Idle／Walk／Run，时长直接读取马定义。动态片段按30fps烘焙完整首尾，每片段只写现有20骨骼的局部四元数；不写根平移或缩放，不复制马背升降。静态骑姿也用固定轨道采样。

HorsePlayer拥有唯一时间。每次先推进／定位马并更新Spine和Head世界矩阵，再以相同相位采样骑手，最后更新掌心与绳。没有第二个累加器；暂停、逐帧、变速、循环、单次末帧保持和重播均走同一链路。无马鞍时冻结骑乘并隐藏骑手／绳，不删除配方或自动换装。

## 换装与生命周期

切动作、相机、材质、暂停、拖时间不重建几何；换马鞍不重建马或骑手。修改V5配方时先构造候选骑手及其轨道，再移除旧对象，挂新人物并把握绳点重挂到新手骨，保留当前相位、马、缰绳缓冲和相机。

退出页面停止RAF、断开ResizeObserver，按依赖顺序释放绳与马具、两套Mixer／Skeleton、几何、材质、Helper、控制器及渲染器。dispose可以重复调用。none期间为恢复原外观而保留的隐藏人物仅是页面缓存，不能在卸载后残留。

只从wanhu.character.wardrobe.v5读取玩家明确保存的装扮；没有保存时提示，不猜另一个页面未保存状态。外部JSON仍经parseRecipeFile验证，超过32KB、旧版本与退役资产拒绝。骑乘不静默覆盖人物工坊存档。

## 页面与服饰边界

入口为人物工坊 → 动物工坊 → 骑乘试衣。直接?lab=riding默认普通马鞍；静态?lab=riding&clip=pose&paused=1；指定旅行款追加saddle=travel。二级切换携带当前马鞍，因此从无鞍马进入骑乘后仍需主动选鞍。相机在右上，底部循环默认开启。

当前全部7上衣、5下装、布鞋保持可选。裤装作为骑乘验收基准；连续封底裙仍为实验装扮，可能与马背／腹部／马具相交，不自动换裤、拆裙、删封底或随动画删皮肤。手持物仍保留原配方，可能与持缰冲突，页面明确提示；不能将保留道具视为已支持骑射或劳动。
