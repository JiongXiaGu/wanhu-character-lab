# C1 窄袖直身长袍

`narrow_long_robe` 是可自由混搭的基础长袍，不代表官员、内侍或其它身份。本轮仍只有这一件；没有 C2、额外腰带槽位、帽子、鞋履或新 Recipe。

## 重新建模的依据

2026-09-28 用户明确否定旧候选：像套水桶，看不到腰。旧版“腰宽至少达到胸宽 95%”的断言实际上保护了被否定的筒形，不能再作为直身长袍的必需条件。

当前方向是胸部留量、可见束腰、克制的长下摆。H 型只约束整体纵向比例和有限下摆体量，不等于胸、腰、髋必须一样粗。腰线需要在无颜色的正面和侧面同时成立；只画一圈腰带不算修复。

## 作者所有权

`assets/narrow-long-robe.ts` 独立拥有衣身环、袖口、几何束带、下摆、内收与双权重。`patterns.ts` 的作者版型为 `narrow-long-robe-v2`，正式可穿戴 ID 不变。没有调用旧礼衣、交领常服或裙装工厂后拉伸。

胸腰髋截面重新组织；腰髋由圆筒改为更扁平的圆角截面，与上下衣身过渡。束带使用五个实际轮廓环产生收束和折边，不是附加色带，也不增加独立装备。膝后和臀后留量单独制作，不为包住下装而把腰重新加粗。

下摆保留小腿上段长度。一次前后开衩实验在静态截图中可读，但抬腿与深蹲的贯穿变多，已丢弃；当前正式候选仍为连续下摆。不能把过程中发出的开衩预览当作当前实现。

`tops.ts` 仍负责分派和调用原封口接口，固定女性映射仍由装配层执行一次。作者几何不根据性别、下装、动作或帧号变化。20 骨、最多双权重、一个最终装配网格、七槽位和六字段 Recipe V5 不变。

## 覆盖、内收与染色

外袍跨 pelvis、thigh 和 shin 上段；`covers` 仅删除完整覆盖的 torso、upperArm、forearm、pelvis、thigh，不删除整段小腿。下装独立，选长袍不得改写 bottom、其几何或选项。

内层由下摆回到腰内，腰内封口高于下装腰口，不用横穿两腿的低位平盖。内外面先确定相同作者对角线，再统一朝向。膝区权重按固定的折弯中性面制作，衣料厚度和局部后侧留量不改变该中性面；这不是逐帧布料修正。

primary、secondary、accent 仍只决定面颜色。统一素模下腰线、折边和窄袖必须继续存在；换色不能改变坐标、权重、面索引、覆盖或封口。

## 检查入口与防退化

```bash
npm run check:c1
npm run check:c1-motion
node scripts/review-garment-focus.mjs --slot top --garment narrow_long_robe --reference ceremony_robe,cross_jacket
```

静态检查保留闭合、流形、重复／退化面、有限值、双权重、独立作者、固定男女、20 骨、完整 Recipe、taxonomy、缺口和染色不变量，以及男女与九种下装共 18 次实际装配。四种代表性 bottom 另外检查本轮上衣相关的静态贯穿。

结构断言同时检查长衣身、窄袖口、下摆体量、正面腰宽、侧面腰厚、束带折边和带高。故障反例从三项扩展为六项：短衣、宽袖、大下摆、正面桶腰、侧面桶腰、只剩颜色的平腰带。改变腰线约束是响应用户的新美术方向，不是降低拓扑或动作检查标准。

动作检查仍为男女 × `work_pants / work_wrap / long_skirt` × `start-walking / jogging / pilot-switches / shooting-arrow / snatch`，共 30 组、6054 个源键／相邻中点／端点姿态。原相交算法、容差和取样没有改变，Snatch 继续完整检查并阻塞。C1 检查追加在原完整下装检查之后，不替代它。

## 当前仍未解决的部分

当前束腰作者模型为 372 个逻辑顶点、740 个三角形；这不是增加人体精度。男性作者正面腰／胸宽比约 0.781，侧面腰／胸厚比约 0.786；实际参数与门槛以代码和数值报告为准。

重做后的完整本地专项报告仍存在 13 组动作阻塞：男女三种下装的 Jogging 和 Snatch，以及男性 `long_skirt` 的 Start Walking。六组坐姿和六组射箭专项采样均没有阻塞，但不能据此宣称所有动作通过。

主要剩余问题是慢跑时前膝／下摆内外层互穿、深蹲时前髋向腰带区域折返，以及男性长裙个别行走相位的后髋接触。不能删除这些样本、扩大豁免、把问题移到不检测的 region，或只展示安全相位后宣称交付。

这些检查不证明所有共面接触或连续时间绝对不穿插，也不覆盖全部手臂／领口。因此仍需查看实际 WebGL 截图。最新精确提交、Actions、图包和实际看图记录见 PR #72 与《工作交接》；旧水桶版的证据只保留为被否定的前后对照。
