# C1 窄袖直身长袍

`narrow_long_robe` 是自由混搭的基础长袍，不代表职业或身份。本轮仍只有这一个 top；没有 C2、腰带槽位、后片槽位或新 Recipe。

## 用户反馈与外部轮廓

用户先否定“像水桶、看不到腰”，随后否定束腰候选的异常臀部。当前外形保留正侧面可读的腰线，收回侧臀突起，让后片从腰下垂落；不能继续收腰或放大下摆制造反差。

原腰下到髋部扩张过快，圆角腰髋与下方圆截面有折线，整段后侧统一加留量又把后片推成硬包。女性固定空间映射会进一步放大反差，男性作者形状通过不能代替女性装配通过。H 型指有限下摆体量和整体纵向比例，不等于胸腰髋同宽；不得恢复旧桶形腰宽门槛。

## 作者职责与当前结构

`assets/narrow-long-robe.ts` 独立拥有衣身、窄袖、几何束带、下摆、内收和制作权重；`patterns.ts` 仍使用 `narrow-long-robe-v3`，正式 ID 不变。只有一套正式 C1 实现，旧候选从 Git 历史追溯。

腰部略放松，侧髋和臀下横向体量收回。各纵向支撑分别拥有前深度、后深度和截面平整程度，不再通过整段 `backEase` 一起膨胀。后膝的必要活动留量与臀部后片分开。没有采用暗褶、倒褶、重叠假褶或隐藏开口；平整后片不等于布料会自动释放活动空间。

外部轮廓沿用上一轮候选。连接拓扑、支撑高度、面区域和全部制作权重保持，仍为 372 个逻辑顶点、740 个三角形。窄袖、胸肩接口、几何束带、膝下衣长及下摆尺寸没有借动作修复扩大。作者参数以代码为准，不在多份文档复制整张表。

## 膝部内收

内层从下摆回折到腰内，封口仍高于下装腰口，不用低位横盖截断双腿。内外层对应点共用权重，先固定作者三角化再统一朝向，避免两层采用不同对角线。

最新修正只调整 Hem、Knee、KneeUpper 三圈的 36 个内层顶点：从实际作者衣面的环向、纵向切线计算法向，沿内侧保留 6mm 作者厚度。原来的同高度径向缩圈不一定垂直于倾斜衣面；本次改变的是内收方向，不是扩大外部臀围、减薄夹层或新增逐帧修正。

腰髋继续保留原径向内收。曾将法向内收扩展到整段内层，完整复测新增了男性 long_skirt 的两帧行走穿插，因此没有保留。其它髋部权重与前片连接试验在失败帧重放中变差，也没有提交。不能把讨论或未采用的方案写成已实现。

这项修正减少了实测慢跑阻塞姿态，但没有消除全部内外层交叉，更没有解决 Snatch 的前片折返。作者态的正确厚度不能代替完整动作验证。

## 覆盖与协议

`tops.ts` 只负责分派及原封口接口。女性映射仍在装配层执行一次；作者资产不读取性别、下装、动作或相位来临时改形。固定成年男女、20 骨、最多双权重、一个最终装配网格、V5 六字段、七槽位和文件保存协议保持。

外袍跨 pelvis、thigh 和 shin 上段；`covers` 仍为 torso、upperArm、forearm、pelvis、thigh，不删除整段小腿。bottom 的选项、作者网格和运行时没有改动。primary、secondary、accent 只改变颜色，不改变坐标、权重、拓扑、覆盖或封口。

没有新人体、骨骼、Renderer、Animator、布料、IK、BlendShape 或运行时补偿；region、隐藏面、交点检测范围和相交容差也没有改变。
