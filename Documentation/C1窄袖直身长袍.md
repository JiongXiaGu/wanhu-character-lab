# C1 窄袖直身长袍

`narrow_long_robe` 是可以自由混搭的基础长袍，不是官员或内侍身份。当前代码和图包仍是 PR #72 候选；动作检查尚未通过，不能宣称 C1 已交付。

## 职责与数据所有权

`assets/narrow-long-robe.ts` 拥有独立的原始男性作者几何、蒙皮、面片、染色色区和开口。它只使用 ring、bridge、face、vertex、orient 和有限权重操作，不调用 `ceremony_robe`、`cross_jacket`、`layered_vest` 或旧裙装工厂。

`patterns.ts` 负责登记作者类型；`tops.ts` 分派新 ID，并通过既有封口接口返回完整资产。`catalog.ts` 只向原上衣选择器加入一项，不生成身份或锁定套装。`taxonomy.ts` 负责版型和检索；`contexts` 的官署、内侍等词不进入 Recipe。

固定男女映射仍由原装配路径执行一次。作者层不读取动作、时间、帧号、职业、下装选择或性别来改变版型。测试负责验证这些不变量，文档不另存一份运行时算法。

## 结构差异

最近似参照是 `ceremony_robe` 和 `cross_jacket`。本件独立制作膝下长衣身、收敛窄袖和小展下摆，不通过颜色制造新款。

精确候选 `ef882d6be569c5c3c6d5d95ead68fb7316147329` 的下缘 Y 为 0.405；两个参照的衣身下缘分别为 1.035 和 0.985。总纵向跨度明显增加。专属断言同时限制袖口投影宽度、下摆／胸部比例和腰部／胸部比例，并加入缩短衣长、加宽袖口、放大下摆三个故障反例。后续修改以断言和实际同机位素模图共同判断，不能只验证 ID 存在。

当前封口后为 324 个逻辑顶点、644 个三角形。它仍是一件 top，不增加 robe／outerwear 槽位、骨骼、Animator、Renderer 或布料系统。

## 覆盖与内收

长袍向下跨越 pelvis、thigh，并在作者几何中进入 shin 上段。`covers` 只声明完整覆盖的 torso、upperArm、forearm、pelvis、thigh；不能因下摆进入小腿就移除整段未被覆盖的小腿皮肤。

当前作者方案采用外部衣身和回折到腰内的内层，保留 neck、左右 cuff、腰内四个封口接口。下摆没有用横穿双腿的平面盖板。内外面先确定三角剖分，再统一朝向，避免反转四边形时改变对角线。

这套回折方案在 Bind Pose 成立，但目前在屈膝和深蹲中仍会发生内外面贯穿。闭合和二流形不等于动作成立。后续可以重做内收几何／权重，不应为了保留当前实现而放宽验收。不能把某个底部区域标成无关 region 来逃避检测，也不能删掉失败动作后宣称通过。

bottom 保持独立；换长袍不能改写下装几何、Recipe 或下装选项。组合检查包括男女与全部现有下装的静态装配，以及三种代表性下装的完整关键动作采样。

## 染色

仍使用 primary、secondary、accent。换色只改变面颜色，不改变坐标、索引、骨权重、覆盖和封口。`check-c1-robe.ts` 逐项比较染色前后的结构数据；统一素模图用于排除配色造成的假差异。

## 数值入口

```bash
npm run check:c1
npm run check:c1-motion
```

静态脚本检查闭合、非流形、重复／退化面、有限值、权重合法、独立作者来源、固定男女映射、20 骨、Recipe 六字段／七槽位、taxonomy、缺口状态、轮廓故障反例、染色和实际混搭。该脚本接入现有 `check:wardrobe-numeric`。

动作脚本覆盖男女 × `work_pants / work_wrap / long_skirt` × `start-walking / jogging / pilot-switches / shooting-arrow / snatch`。每个动作保留全部源键、相邻中点和端点，总共 30 组、6054 个姿态。检查所有顶点有限值，再检查涉及本轮 top 的 pelvis／thigh／shin 三角对及其自身；下装自身仍由原全目录检查负责。

新脚本不替换原完整下装矩阵；原 `check-tailoring-intersections.ts` 通过原矩阵后追加调用它。原几何判定、容差、共享顶点规则与既有裤脚／裙底接触规则未降低。当前 C1 的 Snatch 也完整采样并阻塞；没有新增 C1 交点豁免。

有限采样不证明任意动作或连续时间绝对不穿插。本检查也不涵盖全部共面接触和手臂／领口的贯穿，袖口、射箭、髋部、后摆和两腿之间仍须实际看图。

```bash
  --slot top \
  --garment narrow_long_robe \
  --reference ceremony_robe,cross_jacket
```

现有 Manual Visual Review 增加 `garment-focus` scope，使用原工作流和精确 SHA，不新增第四条永久 Actions。手动输入提供槽位、目标 ID 和一至两个同槽位参照；PR 标题可使用 `[garment-visual top=narrow_long_robe ref=ceremony_robe,cross_jacket]`。

脚本直接检查真实 recipe 和原下拉选择器，未知 ID 不得静默变成旧衣服。它验证镜头不变、20 骨、一个画布、FBX 加载和实际定格相位。目标与参照的素模截图使用相同相机参数。

最低输出包含男女正面／侧面／背面／三分之四、男女正侧素模、两款参照的同机位素模、五个关键动作和两种额外下装。当前执行生成 34 张原始 WebGL 图与 8 张由原图组成的对照拼图，没有使用旧 `review-wardrobe-batch` 图片。
