# C1 窄袖直身长袍

`narrow_long_robe` 是自由混搭的基础长袍，不代表职业或身份。本轮仍只有这一个 top；没有 C2、腰带槽位、后片槽位、帽子、鞋履或新 Recipe。

## 用户反馈与问题来源

用户先否定“像水桶、看不到腰”的旧版，随后否定束腰候选的异常臀部。本轮目标是保留正侧面可读的腰线，收回侧臀突起，让后片从腰下垂落，而不是进一步收腰或放大下摆制造反差。

接手后重新运行旧模型的静态检查与完整动作矩阵，并通过原 garment-focus 补拍男女正、侧、背、三分之四素模。静态问题与动作问题分开判断：旧腰下到髋部扩张过快，圆角腰髋与下方圆截面之间有明显折线；整段后侧统一加留量，使后片显得外鼓。既有女性空间映射还会放大腰髋反差，因此男性作者形状通过不能代替女性装配通过。

H 型仍指有限下摆体量和整体纵向比例，不等于胸腰髋同宽。不得恢复旧“腰宽至少达到胸宽 95%”的桶形门槛。

## 当前作者结构

`assets/narrow-long-robe.ts` 独立拥有衣身、袖口、束带、下摆、内收和制作权重。`patterns.ts` 的作者版型为 `narrow-long-robe-v3`；正式 ID 不变，没有同时保留另一套正式 C1 实现。

腰部略放松，侧髋和臀下横向体量收回。各纵向支撑明确拥有前深度、后深度和截面平整程度；不再通过按高度切换的一段后推倍率，把前、侧、后片绑在一起膨胀。髋部后深度与前片分开，后片从腰下连续连接到臀下；后膝的必要活动留量单独保留，不扩张臀部来包住膝部。

本轮重做的是作者截面和内外层形状，最终保留原连接拓扑、支撑高度与面区域；没有增加面数。仍为 372 个逻辑顶点、740 个三角形。窄袖、胸肩接口、五圈几何束带、膝下衣长及下摆尺寸保持。几何参数只以作者代码为准，不在多份文档复制整张表。

没有采用后中暗褶、倒褶、重叠假褶或隐藏开口，也没有以配色改变轮廓。平整后片不等于已具备布料活动释放能力，动作仍由同一套固定蒙皮决定。

曾试过额外高髋支撑、调整纵向支撑位置和改变髋部权重；完整检查发现新增静态混搭或坐姿阻塞，因此没有保留。当前 Hips / Thigh 的原过渡保持，膝区仍使用原制作中性面，不把“提前跟随大腿”当作通用修复。

## 覆盖、内收与协议

`tops.ts` 仍只负责分派并调用原封口接口。女性映射仍在装配层执行一次，作者资产不读取性别、下装、动作或相位来临时改变几何。固定男女、20 骨、最多双权重、一个最终装配网格、V5 六字段、七槽位和保存协议不变。

外袍跨 pelvis、thigh 和 shin 上段，`covers` 仍只覆盖 torso、upperArm、forearm、pelvis、thigh，不删除整段小腿。bottom 的选项、作者网格和运行时均未改动。

内层随新的前后截面回折到腰内，封口仍高于下装腰口，不用低位横盖截断双腿。没有把内层简单变薄当成收臀；内外层仍保留真实厚度、对应权重与一致作者对角线，先三角化再统一朝向。region、隐藏面、交点检测范围及相交容差没有改变。

primary、secondary、accent 只改面颜色；染色不能改变坐标、权重、拓扑、覆盖或封口。没有新骨骼、Renderer、Animator、布料、IK、BlendShape 或逐帧修正。

## 检查与防退化

```bash
npm run check:c1
npm run check:c1-motion
node scripts/review-garment-focus.mjs --slot top --garment narrow_long_robe --reference ceremony_robe,cross_jacket
```

原闭合、非流形、重复面、退化面、有限值、双权重、独立作者、男女映射、20 骨、Recipe、taxonomy、染色不变量和 18 次实际装配检查保留。四种代表下装仍检查静态贯穿。原六项轮廓故障反例全部保留：短衣、宽袖、大下摆、正面桶腰、侧面桶腰、平腰带。

新增回归从实际男女映射后的衣面测量腰下侧线斜率、侧髋相对垂落弦线的突起、后片弦外鼓包和后臀向下反扣，同时再次验证正侧面腰线。斜率门槛对应相对垂直约 23.3 度；后片容许胸厚 5% 的弦外留量，避免把宽松衣料约束成纸片。具体公式、其余比例门槛与被否定旧形状的测量依据集中在 `check-c1-robe.ts`。男女各有侧臀突扩、仅后片鼓包两个新故障反例；不是只检查参数或 ID。

完整动作矩阵保持男女 × `work_pants / work_wrap / long_skirt` × `start-walking / jogging / pilot-switches / shooting-arrow / snatch`，共 30 组、6054 个源键／相邻中点／端点姿态。没有降低容差、删动作、删样本或新增 C1 接触豁免；C1 仍追加在原完整下装检查之后。失败帧快速重放只用于定位，不能代替最终完整矩阵。

## 尚未解决的动作问题

当前完整复测仍有 12 组阻塞：男女三种下装的 Jogging 与 Snatch。男性长裙 Start Walking 的旧阻塞已消失；六组行走、六组坐姿和六组射箭均通过本轮专项采样，但这不是全动作通过。

慢跑仍有膝／下摆内外层互穿，Snatch 仍有上大腿到髋部的衣面向腰带区域折返及与下装的贯穿。某些失败帧的交点数量仍会增加，不能只用失败组合从 13 降到 12 宣称动作质量全面改善。旧男性长裙行走的实际失败顶点位于前中线附近，不能继续沿用“后髋接触”的不准确定位。

这些检查也不证明共面接触、连续时间或袖口／手／领口全部无穿插。当前仍是 Draft 候选，不合并有明确动作阻塞的模型。
