# BVH 动作接入

BVH 与现有 Mixamo FBX 并列作为人物动作源，第一阶段用于 Web 试衣与视觉验证，不替换现有 FBX 管线，也不改变人物 20 骨骼、Recipe V5、服装绑定或 Unity 运行时契约。

源文件放在 `动画参考_BVH/`。构建前 `prepare:bvh` 递归扫描真实 BVH，生成 `public/bvh/*.json` 和自动目录；生成数据不提交。BVH 提取器把不同命名映射到现有 20 骨骼语义，忽略手指、眼睛、下颌和脚趾的独立驱动，但用中指根与脚趾根辅助手脚方向校准。当前 `upperChest` 折叠为目标 Chest。

输入坐标自动按绑定人体求右、上、前轴，并以绑定 Hips 高度归一化；平面 Root Motion 仍由现有重定向规则剥离，保留局部摆动与高度。若 neck/head 的局部四元数轨道逐值完全重复，提取阶段只保留 neck 驱动并让 Head 使用绑定局部旋转，避免同一头部旋转被父子层级重复叠加。

动作库统一显示 FBX 与 BVH 来源，可按来源筛选。播放、暂停、重播、循环、逐帧、时间轴、源骨架对照和目标骨架叠加继续使用同一套 UI。BVH 首轮不做手指、面部、道具事件、脚底 IK、足锁或 Unity AnimationClip 导出；视觉正确性由用户在 Web Demo 中最终验收。

当前第一份样本为 `动画参考_BVH/简单跳舞_A.bvh`。它只代表导入链路样本，不代表后续所有 BVH 都自动满足骨骼命名和动作质量要求。
