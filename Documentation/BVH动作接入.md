# BVH 动作接入

BVH 是人物外部动作的第二条输入来源，与现有 Mixamo FBX 并列，不替换 FBX。原始文件放在 `动画参考_BVH/`，构建前由 `prepare:mixamo` 一并扫描、解析并生成 `public/bvh/` 临时运行时数据；生成目录不提交。

第一版只处理固定 20 骨骼需要的人体语义。BVH 的 `upperChest` 折叠到目标 Chest，手指、脚趾末端、眼睛和下颌不进入目标骨架；中指近节和脚趾只作为手足方向校准端点。目标人物仍使用同一套 GPU SkinnedMesh、男女固定基模和服装资产。

提取阶段把源骨架统一到 +X 右、+Y 上、+Z 前，并去除根节点第一帧的整体平移基线；之后仍沿用现有世界旋转差 → 20 骨骼局部轨道的重定向。这样不会把 neck/head 相同的局部轨道简单叠加两次，而是从世界姿态差恢复目标层级局部旋转。

动作库 UI 同时显示 FBX 与 BVH，支持来源筛选、播放/暂停、循环、逐帧、时间轴、源骨架同步对照与目标骨架叠加。BVH 当前仅作为视觉验证和动作资产研究，不宣称已经完成 Unity AnimationClip/Avatar 导出、手指动画、面部动画、脚锁、IK 或正式 Root Motion。

新增 BVH 文件后只需放入 `动画参考_BVH/` 并重启开发服务或重新构建；注册 ID 由相对文件名稳定生成。未知 BVH 若缺少必要人体骨骼、时间轴损坏或坐标轴无法确定，会明确失败，不静默回退到程序动作。
