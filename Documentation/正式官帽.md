# C3 · 正式官帽

## 范围与入口

用户已批准接续 C3。本轮只新增一个正式 `headwear`：`official_winged_cap`，中文名“正式官帽”。C1、C2 已合入 main，本轮不主动返工；旧 C2“完成后停止、不进入 C3”是上一轮范围，不阻止本次新授权。

在原人物工坊的“头饰”选择器中选择“正式官帽”。绑定姿态入口：

`?headwear=official_winged_cap&pose=bind&paused=1&view=free`

可自行与现有 `narrow_long_robe`、交领常服、宫女衣裙或军装混搭。没有新人物页面、整套锁定、性别限制、职业或官职字段。默认平民随机池保持不变。

## 为什么不是已有方冠换色

最近似资产是 `scholar_cap`，次级参照为 `cloth_wrap`。C3 采用独立作者几何，不调用它们的帽身或横条工厂。

| 结构维度 | 方冠 | 正式官帽 |
|---|---|---|
| 帽翅 | 后部短矩形横条 | 左右独立长薄翅，微后掠，末端收薄 |
| 帽身侧壁 | 明显向顶部收尖 | 方圆角截面，近直立、轻微内收 |
| 前后高度 | 水平顶面 | 前低后高的斜屋面 |

统一素模必须仍看得出前两项差别。作者空间整体宽 0.67，帽底宽 0.28；左右对称。它是游戏用的泛化文官帽型，不宣称精确复原某一朝代礼制。没有军盔护颊、护颈、高缨、兽面或额外冠饰；不抢占 C7 帝王纵向高冠的轮廓。

## 几何与数据所有权

`src/character/wardrobe/official-headwear.ts` 只拥有帽身和两个薄翅，当前 `c3-official-winged-cap-v1`：48 个逻辑顶点、84 个三角形，三个独立闭合实体。固定作者留量已在坐标中，不添加实时拟合或新头饰缩放路径。

帽身底部、帽顶和两翼端面全部封闭；帽底使用帽身同色。所有顶点是 `[Head, Head, 1]`，随现有头部骨骼刚性运动。固定男女映射由原人物装配完成；不改基模、骨骼、inverse bind、Renderer 或动画播放器。

`adornments.ts` 只增加分派和戴帽时隐藏独立发髻；摘帽仍恢复用户原发型。原主头发、其它帽子的几何和固定安全留量不改。

主色生成低亮布料色，帽顶保留轻微面色差，副色作用于薄翅末端；沿用原三色染色协议，未新增材质或颜色字段。染色不得改变坐标、权重、拓扑或其它衣裤。

## 检查

使用原 `npm run check:lightwear`：保留全部原有头饰矩阵和故障反例，追加正式官帽。男女 × 三发型的帽子闭合、Head 刚性、同色帽底、帽发贯穿及摘帽恢复均执行。

`OfficialCap.Shell.Base.*` 只复用既有 Shell 帽底与头发制作接触规则。帽侧、帽顶和两翼仍完整检查，不新增整件帽饰豁免，不放宽相交算法、容差或已有资产门槛。

`check-c3-headwear.ts` 由原 lightwear 调用，追加真实男女装配、结构差异、六组衣裤混搭、染色几何不变、V5 文件往返和六个故障反例：漏面、翅过短、平顶、强收尖帽身、错骨权重、左右不对称。报告输出到 `review-wardrobe-batch/c3-headwear-numeric.json`。

动作轨道和公共动画库不改。数值形态检查不能替代动作画面；正式视觉检查使用现有 garment-focus，对男女生成四角度、素模、方冠/包巾同机位对照，以及起步、慢跑、坐姿、射箭、Snatch 五个真实 FBX 动作。有限采样与图片不等于全时域无穿插。

## 正式交付

只沿用三条正式 Actions，不修改 package 或 workflow。PR 标题使用：

`[garment-visual headwear=official_winged_cap ref=scholar_cap,cloth_wrap]`

所需 Build、Targeted 和定向 Manual Visual 必须针对最终受测 SHA。下载并实际打开新 WebGL 图后正常合入最新 main；截图生成、AI 看图、合并与用户最终美术确认分别记录。真实运行编号和交付 SHA 以工作交接及 PR 为准，不提前填写成功。

本轮结束于 C3，不开始 C4 内侍长衣、C5 内侍帽、官袍、皇帝/皇后整套或动物扩展。
