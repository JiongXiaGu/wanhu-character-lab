# 家畜与低模鸡

## 目标

鸡面向《万户天工》的经营俯视与高密度场景，不沿用大型坐骑的几何预算。第一只资产为 `chicken_brown` 褐羽成年母鸡，使用三档独立作者LOD：LOD0为140三角形／100逻辑点，重做后的LOD1 v2为72三角形／46逻辑点，LOD2 v2为36三角形／26逻辑点；三档共用原8骨、每点1个非零权重和不透明顶点色材质。硬边展开后的渲染点为420／216／108。没有隐藏高模，也不以运行时删面伪造LOD。

## 低档重做原则

旧LOD1/2 v1省略了脖子，却保留独立头部和小配件，造成头部悬空；这不是正常的LOD取舍。v2重新分配面数，不保留该组旧低档构造器。优先级是完整轮廓、动作连接，然后才是装饰。

`src/chicken/lod.ts`拥有低档作者网格。BodyNeckHead是同一个闭合连通壳，身体、颈、头与喙共享接口顶点，不能恢复为彼此分离的小壳。跨Body/Neck/Head的面沿原骨骼层级变形；这仍是单权重蒙皮，不增加颈骨或运行时修补。

LOD1把48面用于连续主体、4面用于整块尾、4面用于单块小鸡冠、16面用于合并腿脚；去掉独立眼睛、肉垂、翅片和脚趾。LOD2把24面用于连续主体、4面用于尾、8面用于合并腿脚，连独立鸡冠也不保留。喙是主体前端收束，不再单独造头部细节壳。

LOD0的geometry.ts、rig.ts与animation.ts保持不变；不能通过改变原动作、隐藏表面、双面材质或仅截远景掩盖低档问题。低档近距离放大仅用于检查连接，不以增加眼睛细节提高近景精度。

## 栏目与入口

顶层仍是人物工坊、动物工坊。动物工坊二级入口为坐骑本体、骑乘试衣、家畜；家畜入口为 `?lab=livestock`，不增加独立顶层工坊。

右侧依次为家畜种类、基础动作、群体预览、细节层级、折叠模型审查。种类只列已实现的褐羽母鸡，不放其他物种占位。相机在舞台右上，底部保留暂停、重播、逐帧、循环、速度和相位；默认循环。单只支持骨架、色块、素模、线框与参考网格。

固定低档审查入口为 `?lab=livestock&lod=lod1` 与 `?lab=livestock&lod=lod2`；增加 `&clip=peck&phase=.45&paused=1&view=left` 可检查最低啄食姿态。

数量为1、10、50、100、500。单只采用精确骨骼采样；切入群体自动适配经营俯视，并默认日常混合。混合是停驻、行走、啄食的固定种子分布，不是自主行为树；点击任一动作退出混合，便于统一检查。重新散布只改变布局种子、朝向和轻微等比尺寸。移动只在各自留量格位内演示短循环，不含真实导航或碰撞。

底部显示实际LOD、单只三角面、逻辑点与近似屏幕高度。群体统计显示数量、当前LOD对应的全部模型三角形、鸡绘制批次；不把地面计入动物预算，也不把总数标成逐只剔除后的可见数。

## 职责与数据所有权

`src/chicken/geometry.ts`拥有LOD0的15个闭合凸壳和刚性权重，合计140面。没有毛发、透明羽片、额外眼球材质或逐羽建模。

`src/chicken/rig.ts`拥有Root、Body、Neck、Head、左右Leg、左右Wing共8骨。腿挂Root以隔离身体起伏，尾刚性随Body，不增加脚趾骨或尾链。米制、+X右/+Y上/+Z前；逻辑顶点与硬边展开点分别统计。低档可以省略翅片等部件，但不改骨骼名称、顺序、局部绑定或inverse bind。

`src/chicken/animation.ts`拥有停驻3秒、行走0.9秒、奔跑0.6秒、啄食1.5秒。作者姿态在创建阶段烘焙30fps局部位置和四元数轨道，保留首尾。支撑腿向后扫，脚底制作校正在烘焙时执行，不做运行时IK。没有下蛋、飞行、扒地或受惊扇翅。

`src/livestock/catalog.ts`注册已有家畜、各档工厂和预算，动作列表归物种所有。types.ts和actor.ts只提供最小家畜装配，不继承MountDefinition，不读取骑姿、鞍具或缰绳。人物Recipe V5、20骨、FBX、衣柜以及六种旧坐骑的作者资源都不改变。

## 播放与群体

scene.ts持有一个RAF、一个clip-clock、一个Renderer和相机。换动作、材质、暂停、相位不重建网格；换数量重排实例和构图。单只由真实Skeleton/Mixer采样。

pose-cache.ts按实际使用的LOD懒加载，使用同一绑定和动作预烘焙约24fps静态姿态。crowd.ts按动作和8个相位组实例化，同组共享姿态几何和材质；播放不创建新几何、不运行500套Mixer。同一时刻四动作最多32个鸡批次，混合仅用停驻、行走、啄食。这不是Unity GPU骨骼动画、VAT或Entities Graphics实现。

混合观察时长9秒，覆盖当前四动作整周期；同一时钟支持暂停、定位与末帧保持。统一动作循环时错峰，关闭循环时同步单次检查；混合末帧保持各自当前姿态。切动作不触发生产或库存事件。

自动模式按正交镜头的参考屏幕高度整群切换：70px及以上LOD0，26至不足70px用LOD1，更小用LOD2；三个固定档用于作者对照。本次造型修复不改阈值、相机、材质、播放时钟或群体策略。没有逐只视锥/距离剔除或生产级动画降频；正式Unity应分别实现和验证逐实例LOD、剔除与动画降频，不能从浏览器推导Unity帧率。

## 生命周期与往返

家畜只在点击二级栏目时把临时预览写入独立sessionStorage键，保留数量、LOD模式、动作、相位、播放、种子与Orbit相机。普通深链不读取缓存，显式URL优先；坏缓存安全回退。坐骑种类和鞍具继续随链接携带，不覆盖人物配方或原坐骑/骑乘预览缓存。

卸载取消RAF、断开ResizeObserver、清除检查出口并释放控件、Skeleton/Mixer、姿态几何、实例缓冲、材质与Renderer。缓存归页面所有，不跨已销毁页面保存GPU对象。

## 检查与验收

check:livestock保留原三档预算、闭合绕序、8骨单权重、inverse bind、LOD0四动作964个密集姿态、脚底与啄食、正向步态、自动LOD、稳定散布、数量、缓存稳定和重复释放检查。

check-livestock-lod.ts在同一命令中追加LOD1/LOD2各964个实际蒙皮姿态：主体共享拓扑连通性、闭合与Euler特征、有限坐标、颈部面不塌缩、脚底与啄食高度、循环接缝、群体缓存和单只采样一致性。删除跨骨连接面或恢复独立眼睛的故障反例必须失败。闭合性本身不能再被解释为头颈连接正确；有限采样也不代表所有连续时刻零自相交。

check:livestock-browser保留原桌面栏目、四动作、时间控制、所有数量、返回恢复、坏输入、控制台与溢出检查，追加固定LOD1/LOD2四动作和真实档位往返的相位、相机与几何复用检查。默认不截图；review:livestock显式保存原四张加低档单只/啄食四张近景，并写受测SHA和截图参数。不能用LOD0与远处鸡群图替代低档近景证据。
