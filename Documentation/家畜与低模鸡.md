# 家畜与低模鸡

## 目标

鸡面向《万户天工》的经营俯视与高密度场景，不沿用大型坐骑的几何预算。第一只资产是 `chicken_brown` 褐羽成年母鸡。三档实际预算：LOD0 140三角形／100逻辑点；LOD1 56三角形／36逻辑点；LOD2 28三角形／20逻辑点。硬边展开后的渲染点分别420、168、84。三档共用8骨绑定和四动作，每顶点1个非零权重；没有隐藏高模或运行时删面。

简化顺序是先保留头—颈—身—尾的整体关系，再删除眼睛、肉垂、翅膀小壳和脚趾。不能用删掉脖子换取保留头部附件的预算。旧LOD1/2无颈的几何已由v2作者资源替换，不保留运行时回退。

## 栏目与入口

顶层仍为人物工坊、动物工坊。动物工坊二级入口为坐骑本体、骑乘试衣、家畜；家畜入口 `?lab=livestock`。不增加独立顶层工坊，不放尚未实现的物种占位。

右侧保留种类、基础动作、群体预览、细节层级和折叠模型审查。相机按钮位于舞台右上；底部支持暂停、重播、逐帧、循环、速度与相位，默认循环。单只支持骨架、色块、素模、线框和参考网格。

数量为1、10、50、100、500。单只使用精确骨骼采样；群体默认进入经营俯视和日常混合。混合是停驻、行走、啄食的固定种子分布，不是行为树。点击动作退出混合，重新散布只改变位置、朝向、相位组和轻微等比尺寸。移动仅在各自留量格位内演示，不含导航或碰撞。

细节层级提供自动、LOD0、LOD1、LOD2。自动仍按正交镜头中约0.54米参考高度的屏幕像素高度整群切换：70px及以上LOD0、26px至70px以下LOD1、更小LOD2。固定档用于同相位作者对照；本次不修改阈值、镜头或灯光来掩盖造型问题。

统计来自当前几何，显示单只三角形、逻辑点、近似像素高度，以及全部鸡模型三角形和绘制批次。地面不计入动物预算，群体总数不冒称逐只剔除后的可见数。

## 作者几何与绑定

`src/chicken/geometry.ts`继续拥有原LOD0，保留15个闭合凸壳及原140面，不随低档重做改变。其Body、Neck、Head、Beak、Comb、Wattle、Tail、左右Wing／Leg／Foot／Eye保持。

`src/chicken/lod.ts`拥有LOD1/2 v2。两档的尾、身体、脖子、头和喙组成单一连续闭合主壳：相邻截面直接共用逻辑索引，颈截面不是悬空附件。Body、Neck、Head截面分别绑定对应原骨骼，跨截面的连接面承担低模形变。即使啄食时头颈转动，也不靠独立壳体碰巧重叠来维持连接；不增加运行时补洞或第二套姿态算法。

LOD1主壳36面，两条窄腿合计16面，一个小鸡冠4面，共56面。喙为头壳前端，眼睛、肉垂、独立翅膀和脚趾删除；腿与最低限度落地轮廓合并。LOD2主壳20面，两条最小支撑8面，共28面；头喙进一步整体化，鸡冠及其他头部附件全部删除。尾与身体共同变形，不保留悬空尾壳。

`src/chicken/rig.ts`继续拥有Root、Body、Neck、Head、左右Leg、左右Wing这8骨，米制、+X右／+Y上／+Z前。低档可以不使用Wing权重，但不删除或重排骨骼。腿仍挂Root，尾随Body。`animation.ts`保持停驻3秒、行走0.9秒、奔跑0.6秒、啄食1.5秒；原30fps局部轨道、步态制作校正和首尾帧均不变。

`src/livestock/catalog.ts`只注册已存在的资源和真实预算。类型与Actor不继承MountDefinition，不增加鞍具、骑手或缰绳字段。人物Recipe V5、20骨、FBX、衣柜以及六种坐骑作者资源均不属于本次修改范围。

## 播放、缓存与生命周期

`scene.ts`持有一个RAF、一个clip-clock、一个Renderer和相机。固定LOD切换使用既有Actor，不重建Renderer，不重置暂停相位或相机。`pose-cache.ts`以同一绑定与动画按约24fps预烘焙静态姿态，各LOD懒加载并复用；`crowd.ts`按动作和8个相位组实例化，播放不新建几何、不运行500套Mixer。

混合观察周期9秒；统一动作循环时错峰，关闭循环时同步检查末帧。相位、暂停、重播均只改变预览，不触发生产或库存事件。当前仍为整群同LOD，不包含逐实例LOD、逐只视锥或距离剔除、生产级动画降频、Unity GPU动画或Entities Graphics接入。浏览器结果不能推导Unity帧率。

仅点击二级栏目时保存独立sessionStorage预览，恢复数量、LOD模式、动作、时间、种子与Orbit相机。普通深链不读缓存，显式参数优先，坏缓存安全回退；不写人物配方或覆盖坐骑缓存。卸载取消RAF、断开ResizeObserver并释放Actor、Skeleton、Mixer、姿态几何、实例缓冲、控件、材质和Renderer。

## 检查与验收

`check:livestock`保留原预算、闭合、绕序、权重、inverse bind、LOD0四动作964姿态、脚底／啄食高度、循环、正向步态、种子、数量、缓存与重复释放检查。追加的 `check-livestock-lod.ts`对LOD1/2各检查964个真实蒙皮姿态，验证颈部存在、截面厚度、Body—Neck—Head共处一个连通分量、硬边展开后连接点仍重合、动画面不塌缩、脚底和喙高度、群体缓存一致性。删颈、绑错骨、压平颈和切断颈头连接的8个故障反例必须失败，不降低原门槛。

`check:livestock-browser`保留原四动作、所有数量、自动／固定LOD、暂停／时间轴／末帧、栏目恢复、坏输入、控制台与溢出检查，追加固定LOD往返不重建网格、不改变相位和相机。

`review:livestock`显式生成6张关键图：单只、侧面啄食、100只、500只，以及停驻和啄食最低点的三档并排对照。并排图来自正式家畜页真实WebGL截图，三档相机、相位、裁切尺度必须相同；排版只发生在浏览器测试页，不增加产品页面或替换模型。生成截图、AI查看与用户美术认可分别记录。

仍只使用Build & Core Checks、Targeted Numeric Checks、Manual Visual Review三条正式Actions。新增检查进入既有家畜任务，不缩减旧坐骑／人物回归，不增加永久工作流。有限密集采样不等于全部连续时刻零自相交；最终造型和动态观感由用户在网页验收。
