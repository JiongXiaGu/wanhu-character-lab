# 动作系统架构 · Phase 4

## 目标

当前人物系统已经完成：

- 连续 Low Poly 人体
- 固定 20 Bone Skeleton
- Slot-based 装备
- 基础 Locomotion

下一阶段不直接堆职业动画，而是建立可复用 Action System。

目标：

- 农民锄地
- 居民搬运
- 工匠生产
- 商队运输
- 弓箭战斗
- 剑盾战斗

全部共享同一套动作语义。

## ActionDefinition

动画不应该直接绑定职业。

推荐数据：

```text
ActionDefinition

├── id
├── MotionClip
├── BoneMask
├── PropSocket
└── Events
```

例如锄地：

```text
HoeGround

Motion:
ToolSwingTwoHand

Prop:
Hoe

Sockets:
LeftHand → GripA
RightHand → GripB

Event:
42%
ToolContactGround
```

## 第一阶段动作

优先制作：

| 动作 | 用途 |
|-|-|
| Pick | 拾取物品 |
| Place | 放置物品 |
| CarryFront | 抱箱子/粮袋 |
| CarryShoulder | 扛木材 |
| CarryBack | 背柴/背篓 |
| Push | 推车 |
| Pull | 拉车 |
| ToolSwingTwoHand | 锄地/砍柴 |
| ToolSwingOneHand | 锤击 |

这些动作组合后可以形成：

```text
背柴行走
= CarryBack + Walk

推独轮车
= Push + Walk

装货
= Pick + Carry + Place

锄地
= ToolSwingTwoHand + Hoe
```

## Interaction Anchor

人物动作不直接写死世界坐标。

道具提供接口：

```text
PropDefinition

├── LeftGrip
├── RightGrip
├── InteractionPoint
└── Events
```

例如独轮车：

```text
Wheelbarrow

├── LeftHandle
├── RightHandle
└── PushPoint
```

角色只需要匹配 Socket。

## 第一轮视觉验收

每个动作必须生成：

```text
front
side
back
wire
keyframe sequence
```

检查：

- 手是否握住工具
- 肩肘膝是否正常变形
- 道具是否穿模
- 动作循环是否连续
- 同一 Skeleton 是否可复用

GitHub Actions 必须自动生成截图。
