## 本轮内容

src/cattle的geometry.ts、rig.ts、animation.ts、saddles.ts分别拥有独立本体、28骨、四原生片段、普通／旅行牛鞍与挂点。黄牛1956三角形、1032逻辑点、5868硬边顶点、27个闭合作者壳；重点为低宽桶身、短粗颈与垂皮、宽头鼻镜、向外再上弯的牛角、横耳、细尾毛束、四脚八个真实分趾壳。没有从马／驴网格做整体缩放换色。

Cattle_Idle 5.2秒、Walk 1.8秒、Run 1.05秒、Eat 6.8秒，独立烘焙且首尾闭合。普通／旅行鞍具为黄牛专属低宽背垫，旅行袋和卷包仍属于一个模块。鼻带／鼻侧环沿用bitLeft／bitRight字段，独立ReinProfile复用原固定双绳。男女CATTLE_RIDER_FIT扩大跨坐并降低持缰，不重定向人物FBX。

页面内换物种保留人物Geometry、inverse bind、外观和归一化相位；普通／旅行互换不重建人物。none保持隐藏骑手／绳与冻结时钟的既有规则，不给未来猪的无鞍骑乘提前加协议。

额外补全用户要求的两工作台往返检查：preview-session只在明确点击模式链接时写页签sessionStorage，保存各自实际时钟、暂停／循环／速度、Orbit相机和未保存骑手装扮。普通URL深链不读缓存；坏缓存安全回退，不覆盖人物工坊localStorage，也不保留隐藏Canvas。

资产边界集中在《黄牛.md》，共同生命周期集中在多坐骑／骑乘／马具文档。代码为实现权威，文档不重复逐点作者参数。

本轮没有执行人工图像检查，也没有将自动浏览器通过当成美术认可。未新增默认截图矩阵；用户直接在网页验收。优先看厚桶身／短颈比例、宽鼻镜与眼鼻细节、角根及弯角、正面分趾、步行／快跑重量感、普通／旅行鞍与男女骑姿接触。

## 体验入口

拉取main后npm ci、npm run dev，或Windows双击Start-Local.cmd。进入动物工坊，在种类选择黄牛；原坐骑本体／骑乘试衣入口不变。

本体：?lab=mount&mount=cattle_yellow&pose=bind&paused=1

普通静态骑乘：?lab=riding&mount=cattle_yellow&saddle=simple&clip=pose&paused=1

旅行步行：?lab=riding&mount=cattle_yellow&saddle=travel&clip=Rider_Walk

女性旅行：?lab=riding&mount=cattle_yellow&saddle=travel&bodyType=female&clip=Rider_Run&paused=1
