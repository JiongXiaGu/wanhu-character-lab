## 合并后本地体验

确认 PR 已合并后，在已有仓库中执行：

```sh
git fetch origin
git switch main
git pull --ff-only origin main
npm ci
npm run dev
```

Node.js >=22.12，打开终端输出地址，通常为 `http://localhost:5173/`；也可使用 Start-Local.cmd。启动／构建会自动提取 FBX。用户简单视觉复核建议先看男女和几套搭配，再暂停坐姿／深蹲观察髋裆，反馈新回归与已知造型问题时分别标明。
