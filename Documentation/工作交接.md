用户已接受M3马鞍／缰绳效果，并在2026-09-22批准M4-A灰驴、多坐骑UI和推送main。M3基线为064fc96205336fd76e9976d70ca6de640bfb8b8f，PR #29。当前任务PR #30、分支feat/phase-m4-donkey-mounts-20260922；后续必须重读远端main和PR，不能用本页历史SHA覆盖并发改动。

## 已建立的链路

灰驴独立网格、27骨架（包含两耳）、Idle／Walk／Run／Eat，普通／旅行两套鞍具及自己的嘴环、颈侧导向和男女骑姿。不是把马缩小换成灰色。新目录仅封装动物Actor、语义动作和骑乘适配，不建立通用四足生成器。

动物本体使用一个MountLab／MountViewport，原马专用工作台删除；旧?lab=horse仍进入同一页面。界面为坐骑本体／骑乘试衣，种类和鞍具两个下拉框。骑乘其他分区、右上相机与底部默认循环保持。

换物种保留人物网格与inverse bind、配方、鞍具风格、动作语义和归一化相位，重建物种资源并更新坐面；秒数根据当前片段时长变化。普通／旅行互换不重建人物、动物和绳。同物种换人仅重建人物，掌心重挂。none期间冻结骑乘但仍可换动物，不静默装鞍。

## 体验入口

合入后从main拉取，npm ci、npm run dev。动物工坊 → 坐骑本体／骑乘试衣 → 种类选择灰驴。可直接打开?lab=mount&mount=donkey_gray&pose=bind&paused=1检查无鞍模型；?lab=riding&mount=donkey_gray&saddle=travel&clip=pose&paused=1检查旅行骑姿。

先分别检查长耳、短鬃、浅吻、尾毛束和短腿轮廓，再看进食／奔跑，以及男女普通／旅行鞍具。裤装是本轮接触基准，连续封底裙仍可试穿但不保证跨坐无穿插；手持物不自动删除，脚蹬与手指不做IK。
