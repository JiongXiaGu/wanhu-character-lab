## 当前人物预算

基础人体：

- 257 逻辑顶点
- 510 tris

最终角色：

- 默认农户：675 tris
- 农户 + 农具：699 tris
- 卫兵 + 剑盾：806 tris
- 弓手 + 弓箭袋：805 tris

硬法线 / 颜色会增加 Render Vertex，不能拿逻辑 Vertex 冒充 GPU Vertex。

## Skeleton

固定 20 Bone ID。

职业、体型、服装不允许改变 Bone 顺序。

每顶点最多两个非零权重。

当前 Web 主体使用 GPU Skinning。

结构布线 Debug Overlay 有 CPU Skinning，仅用于审查。

## 动画

当前：

- Bind
- Idle
- Walk
- Run
- Wave
- Squat

统一：

~~~text
+X = 右
+Y = 上
+Z = 前
~~~

Walk / Run 为原地动画。

用户曾发现 Walk 像倒退，已修复摆动 / 支撑相位和手腿反相，并加入 CI 回归检查。

## Unity 下一主线

下一阶段不应该继续围绕 Three.js AnimationMixer 扩展复杂系统。

先正式定义并实现 Unity 对照数据：

~~~text
SkeletonDefinition
SkinBinding
MotionClip
ResidentAnimationState
~~~

近景：

~~~text
SkinnedMeshRenderer
+ GPU Skinning
~~~

Crowd：

~~~text
ResidentAnimationState
→ Animation Texture / Bone Buffer
→ Entities Graphics
→ GPU Skinning
~~~

详细见：

`Documentation/GPU骨骼动画迁移契约.md`
