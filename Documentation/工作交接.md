## 图片结论与未完成范围

独立裤装在查看的坐姿与深蹲样本中具有连续腰臀体积，不再依赖旧人体衣面；裤装单独显示也已检查，没有依赖长上衣隐藏一切。查看的普通混搭样本未发现新的明显破洞、缺失部件或爆炸式形变，可以交给用户进行 main 简单视觉复核。

仍存在低模裆下暗面／棱角、膝前硬折及部分姿态偏薄，不能说全部髋裆观感已经自然或所有连续姿态零穿插。当前款式轮廓仍偏简单、相似，需要后续美术制作；裸模没有专项修复。小屏幕未见新控件重叠，但 768 布局仍有较长滚动和空白，不称为已完成移动端精修。

本批不是完整长袍、裙摆、宫装或大规模成衣库。礼衣／分裳暂简化为短衣和裤式轮廓。没有外部服装 Mesh 导入器、DCC 男女独立源文件、Unity 导入插件或 GPU 群体运行。固定女性映射仍使用既有制作映射，不恢复连续体型适配器。

后续从可靠接口完善衣裤轮廓、领袖、边饰和头饰；新增差异大的服装采用专用拓扑与权重，不向人体生成器补通用参数。不扩张实时解算器或 Unity 玩法。原依赖警告未专项升级，不把 build 成功写成安全审计通过。

## 本地使用

确认 PR 已合并后：`git fetch origin` → `git switch main` → `git pull --ff-only origin main` → `npm ci` → `npm run dev`。
Node.js >=22.12；也可使用 Start-Local.cmd。打开终端输出地址，通常为 `http://localhost:5173/`。FBX 放入动画参考目录，重启／构建自动扫描。
