## 固定约束

人体 510 tris / 257 逻辑顶点；固定 20 Bone ID/Parent Map；每顶点最多两个非零权重。职业只是 Slot Recipe 预设，换帽子不能改变动作能力。

正常播放使用已采样轨道，不逐帧人体 IK、不重建人体 Mesh。工作道具节点不增加人体骨骼。结构布线为审查用途，有 CPU 蒙皮开销，不代表生产路径。

所有位移以 +Z 为前方，原地动作由游戏导航负责世界移动。保持步态方向回归，不能出现月球步。

## 验收方式

仅 GitHub Actions runner 内 Vite Preview + Playwright + Artifact。不得恢复 Visual / Vercel；vercel.json 的 git.deploymentEnabled=false 继续保留。

每次执行：更新文档 → 实现 → Build/数值回归 → Actions 截图 → 下载并逐项实际审图 → 修正重跑 → 合入 main。每个动作必须有正/侧/背/布线与关键帧，射箭含释放前后。绿色任务只是自动检查，不是美术结论。

不要求用户每个子动作回复“继续”。完成当前轮可验收版本后再交付，并写明提交 SHA、run ID、截图/测试范围、残余限制。

## 尚未实现的连接层

目前动作库选择片段，尚无自动拾取→导航搬运→放下的世界任务状态机，也没有通用实时分层、任意中断平滑混合、库存或生产结算。

高/低瞄准只验证有限角度姿势；正式目标瞄准和按该角度发射待后续接入。箭仅作离弦可视化，没有世界投射物、命中、伤害或真实弹道。

Unity MeshData/Burst、BlobAsset、Animation Texture/Bone Buffer、Entities Graphics、动画 LOD、万人性能均未完成。数据语义可迁移不等于已完成 Unity 移植。
