## 本轮内容

独立双峰骆驼1792三角形、958逻辑点、29骨（渲染拆点5376），三段长颈、宽脚垫和前双趾。Idle 4.8秒、Walk 1.6秒、Run 1.0秒、Eat 6.8秒；同侧错相步态，原地循环，无水平Root Motion。进食只在本体页。

普通／旅行驼鞍位于两峰之间；旅行含两侧行囊、水袋及后方卷毯。鼻带式缰具独立挂在Head，原固定双绳算法继续使用。男女有独立跨坐和持缰配置，马／驴缺省方向数值保持。

换物种保留人物Geometry／inverse bind、衣物、鞍具、动作语义及归一化相位；none冻结期间也可切换三种动物，不静默装鞍。UI只增加第三种类及对应名称、时长、骨骼数，没有额外页面或装备槽。

## 体验入口

合入后拉取main、npm ci、npm run dev。动物工坊 → 种类选择“双峰骆驼”。

本体：?lab=mount&mount=camel_bactrian&pose=bind&paused=1

骑乘：?lab=riding&mount=camel_bactrian&saddle=travel&clip=Rider_Walk

女性普通驼鞍：?lab=riding&mount=camel_bactrian&saddle=simple&bodyType=female&clip=pose&paused=1

用户重点查看双峰与长颈、脚垫、Walk／Run节奏、Eat近地、鼻带及男女普通／旅行驼鞍。裤装为骑乘基准，连续封底裙和手持物保留实验提示，不自动换裤或删道具。
