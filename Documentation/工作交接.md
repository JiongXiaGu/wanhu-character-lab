# 工作交接

## 当前阶段

当前为 **Phase 2 · Low-Poly Segmented Humanoid**。

用户否定了之前连续人体的 Ring / JointPatch 路线，原因是：

- 布线复杂；
- 面数过高；
- 不适合《万户天工》的大规模城市居民。

当前正式方向改为：

> 借鉴 Minecraft 的工程思想，而不是 Minecraft 的方块外观。

即：

- 固定低边数部件；
- 关节允许重叠；
- 极低三角面；
- 稳定规则布线；
- 刚性 / 有限 Skinning；
- 最终仍然可以合并为一个 Mesh。

## 当前运行链

```text
BodyParameters
→ LowPolyHumanoidBlueprint
→ 16 LowPolyPart
→ box4 / hex6 / oct8
→ buildLowPolyGeometry
→ 1 BufferGeometry
```

旧的：

```text
HumanTopologyBlueprint
Ring
JointPatch
Shoulder Opening
Shared Boundary
```

相关代码暂时保留用于对照，但已经退出当前运行链。

不要继续完善旧 Shoulder / Hip / Neck JointPatch。

## 当前模型结构

16 个逻辑部件：

- Torso
- Pelvis
- Head
- Neck
- Left / Right UpperArm
- Left / Right LowerArm
- Left / Right Hand
- Left / Right UpperLeg
- Left / Right LowerLeg
- Left / Right Foot

关节通过小范围重叠解决，不追求裸体表面连续。

## 当前目标

基础裸体人物：

- Triangle Budget = 500；
- 实际目标约 200～300 tris；
- 1 Mesh；
- 每个顶点写 `bodyPart`；
- 每个顶点写 `boneIndex`；
- 后续默认 rigid weight = 1。
