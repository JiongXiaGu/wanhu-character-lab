# 工作交接

## 当前设计结论

Wanhu Character Lab 用于验证《万户天工》的程序化低模人物生成方案。

当前代码的 Segmented Low-Poly 人体已经完成技术验证，但不再作为最终角色拓扑。

原因：

- 人体表面蒙皮不连续；
- 肩、髋、颈等区域不适合作为最终动画人体；
- 没有从基础拓扑阶段为衣服 Anchor / Body Hide 设计稳定语义。

正式下一方向：

V2 Continuous Low-Poly Base Body + Garment-Friendly Topology

具体固定拓扑、关节环线、Body Face Group、Garment Anchor Loop、Skin Weight 与验收规范见：

Documentation/V2人体拓扑规范.md

这不是回到旧的高分段 JointPatch 方案。

V2 要求：

- 单一连续低模人体 Cage；
- 固定拓扑；
- 极少关节环线；
- 参数只移动顶点；
- Body Face Group 稳定；
- Garment Anchor Loop 稳定；
- 大部分顶点 1 Bone，关节最多 2 Bone；
- 服装默认无实时 Cloth。

## 当前代码保留价值

Segmented prototype 继续保留，用于复用：

- Runtime Mesh Compiler；
- Mesh Validation；
- UInt16 Index；
- UInt8 Semantic；
- Debug View；
- 正交三视图 Review；
- CI。

不要继续在 Segmented prototype 上实现正式 Skinning / Garment。

## 服装设计

详细阅读：

Documentation/服装生成架构.md

正式服装分类：

- Material Only；
- Body-Derived Garment；
- Independent Silhouette Garment；
- Rigid Attachment。

普通衣服优先从 Body Surface 派生。

长袍、裙、宽袖使用独立低模 Cage。

穿衣后必须隐藏对应 Body Faces。

默认不使用 Cloth Simulation。

如果需要轻微动态，优先：

Skeleton → Shader Sway → Few Helper Bones

## 初始面数目标
