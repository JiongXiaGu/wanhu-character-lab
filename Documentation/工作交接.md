# 工作交接

## 项目定位

Wanhu Character Lab 用于验证《万户天工》的程序化低模人物生成方案。

网页不是最终产品，最终实现会迁移到 Unity Runtime。

## 当前阶段

当前为 **Phase 2 · Segmented Low-Poly Humanoid**。

用户确认目前人体比例可以接受，当前主要目标是：

- 保持极低面数；
- 保持布线规则；
- 修正 Mesh 生成质量；
- 建立可自动检查的生成管线；
- 为后续骨骼和服装准备稳定数据协议。

## 当前正式链路

```text
BodyParameters
→ LowPolyHumanoidBlueprint
→ LowPolyPart[]
→ PrismSection[]
→ buildLowPolyGeometry
→ validateLowPolyGeometry
→ 1 BufferGeometry
```

旧的 Ring / JointPatch / Shoulder Opening 路线已经删除，不再恢复。

## 当前模型基准

默认人体：

- Parts: 16
- Vertices: 204
- Triangles: 252
- Triangle Budget: 500
- Index: UInt16
- bodyPart: UInt8
- boneIndex: UInt8

当前 CI 会额外检查：

- default
- tallThin
- shortHeavy
- broadAverage

四种体型。

当前基准结果应为：

```text
inward = 0
degenerate = 0
mixed = 0
overBudget = 0
```

## 最近修复

之前实体显示异常的根因是 Triangle Winding 反向。

已经修正：

- Side Wall Winding；
- Start Cap Winding；
- End Cap Winding；
- Cap 从中心扇形改成 N-2 Triangle Fan；
- 默认模型从约 272 tris 降至 252 tris；
- 增加自动 Mesh Validation。

禁止通过 DoubleSide 解决这类问题。

## 参考成熟系统后的取舍

### MakeHuman / MPFB

吸收：

- 稳定拓扑语义；
- 参数与拓扑分离；
- Rig Definition 与 Mesh 分离。

不照搬：

- 高面数 Base Mesh；
- Morph Target 资产链。

### UMA

吸收：

- Recipe 与最终 Mesh 分离；
- Character Build 阶段化；
- Mesh Combine；
- LOD 独立。

不照搬：

- Slot Mesh 资产作为最终人体来源。
