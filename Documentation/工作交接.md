## Phase 4 动作方向

动作不按职业制作。

统一分层：

```text
Locomotion
Carry
Interaction
Tool
Combat
```

第一轮优先：

- Pick
- Place
- CarryFront
- CarryShoulder
- CarryBack
- Push
- Pull
- ToolSwingTwoHand
- ToolSwingOneHand

这些动作后续组合：

```text
背柴行走 = CarryBack + Walk
推独轮车 = Push + Walk
锄地 = ToolSwingTwoHand + Hoe
装货 = Pick + Carry + Place
```

## 视觉审查要求

不使用 Visual / Vercel 部署。

每个动作必须通过 GitHub Actions 的本地截图审查：

- Build
- Action Validation
- Playwright WebGL Review
- Front / Side / Back / Cage 截图
- 对循环动作输出关键相位序列
- Artifact 上传截图与日志

Agent 必须下载截图 Artifact 并实际审图。不能因为 Build / Action 绿色就宣告完成。

新增 Motion 后如果没有加入截图矩阵，CI 应直接失败。详细见：

`Documentation/GitHubActions截图验收规范.md`

用户不需要每完成一个子动作就回复“继续”。Agent 应把当前阶段连续做到可验收，再通知用户。

重点检查：

- 手部 Socket
- 工具绑定
- 肩肘膝蒙皮
- 道具穿模
- 动作循环
