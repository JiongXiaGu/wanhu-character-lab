# 工作交接 · 衣冠工坊 V1

## 当前方向

用户已确认 **玩家自定义优先，服饰更偏写意**。Web demo 是换装/外观制作与试衣，不是居民生活或经营玩法；Unity 负责后续游戏逻辑。先读 README、《玩家角色自定义与服饰分期》《换装工作台使用》。职业、贫富、官府、宫廷仅为外观推荐主题，不能锁部件或添加身份专用生成器。

## 本轮实现

四组八套搭配：布衣、市井、雅居、礼仪，所有部件可跨男/女使用。新增四上衣、四下装、三头饰、高/低/双髻，六色组和三色自由染色。原农户、卫兵、弓手及装备保留。

UI 为“衣冠工坊”：左侧身体与灵感、中间大预览与 FBX 试衣、右侧部件/染色/发式。提供确定性种子随机、部件/染色/发式锁、撤销、浏览器单槽保存恢复和严格 Recipe V4 导入导出。普通入口默认静态绑定；诊断 review=1 默认 FBX 慢跑，旧链接和原回归兼容。

`wardrobe/catalog.ts` 放推荐、随机、验证；`wardrobe/geometry.ts` 放新增美术；`v3/outfit.ts` 统一组装。Recipe V4 可选 dyes、hairStyle、hairColor，省略仍保留旧输出。不要把角色玩法放进这些模块。

## 必须保留的基础

男性几何基线6627c2e的12份哈希固定；女性V3.6肩腰髋/四肢/下颌比例和头脸保留。连续510tris/257逻辑顶点身体，固定20 Bone ID/Parent，双权重不变。服饰改变可见衣面与轮廓，不改源身体或骨架。刚性工具仍按骨锚点变换，不能逐点随身体形态场弯曲。

11个Mixamo唯一动画来源。禁止恢复旧程序动作。头部使用真实bind世界旋转差，不用HeadTop_End引入额外低头。换外观/体型保持暂停相位，换FBX不重建几何。目标动画JSON含bodyType/profileVersion，不是UnityClip/Avatar。

## 后续

先由用户验收本批轮廓和换装流程，再精修袖口、裙摆自然度、头饰、袍裳层次，不立即大量铺资产。长摆仍偏硬，宽步后侧内衬可能露出或穿插，极端翻转/贴地可能自交。新年龄段、脸型DIY、弓弦/箭/精确握点和事件另立任务。

Unity导入器、Avatar、Blob、GPU Crowd、LOD、万人性能未实现。优先同模型单人对照再群体，动画与服饰网格键分开；当前顶点色不等于可共享染色实例，详见GPU迁移契约。
