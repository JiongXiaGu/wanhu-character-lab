完整源帧／中点贯穿保留原算法、容差、原20,180严格样本，新两裙扩至24,216。短裤仍全部关键动作严格检查。新裙固定封底与腿出口／末端裙边的数学接口单独记录；报告保留原始piercedFrames、接口closureContactFrames和其余blockingFrames，不能以passed声称全部交点为0。

普通动作非接口穿插继续阻塞。只有新增两裙的Snatch深蹲举重是压力观察，旧衣裤不豁免；大开腿、高踢、翻滚不属于裙装低运动服饰承诺。接口范围由7个正反例保护，不能扩到裙身、Calf、腰臀、大腿或上衣。详细诊断随Tailoring产物保存。

## 体验入口与后续边界

拉取最新main后npm ci、npm run dev，右栏下装可见封口短裤／日常短裙／素面长裙／分片裙裤·旧短下裳。新裙均与背心、短褂、交领常服混搭且跨男女；三色独立。推荐不更改性别，暂停换装相位保持。

本轮不是人体修模、动画系统、头发或新帽子任务。继续迭代以服饰轮廓与可靠遮挡为主，不引入连续身材、裙摆骨骼、实时布料、专用IK、碰撞解算或Recipe V6。
