# 工作交接 · V3

## 当前阶段

本轮目标「重做低模人物 + 基础动画 + 自行截图检查」已经完成实现，进入用户美术/交互验收。无需再从 V2 的固定裸模阶段开始。

人体与渲染代码已经重构为 src/character/v3。当前模型是三维体积 cage，不是 V2 的前后两张二维轮廓挤出。旧 segmented/V2 代码与测试删除；历史规范仅保留简短迁移说明。

## 可验收功能

农户、卫兵、弓手和基础人体共用同一人体骨架。已实现头部五官/头发、帽子、基础衣物、剑盾、弓箭袋、农具；身高和体格参数；待机、行走、慢跑、招手、屈膝、A-Pose；暂停、速度、逐帧进度；同屏三视图、结构边线、三角线框、素模、骨骼叠加、截图和 Recipe 导出。

## 真实预算

基础人体：257 逻辑顶点 / 510 三角形。

- 基础人体视图含头发与五官：595 三角形。
- 默认农户（斗笠，无农具）：675 三角形。
- 农户带农具：699 三角形。
- 卫兵带剑盾：806 三角形。
- 弓手带弓和箭袋：805 三角形。

硬法线/颜色需要渲染拆点，不能用逻辑顶点数量冒充 GPU 顶点数量。

## 已验证

几何/动作：12 个职业×体型组合；1152 个采样帧。浏览器：20 张固定截图与交互断言。已实际查看三视图、结构线、招手、屈膝侧面、职业装备与无头饰图。第一轮发现并修复斗笠/盾牌朝向、发顶体积和鞋底离地问题。

详细证据和范围见 V3验收记录.md。最终确认以 main 上的 Actions 为准；不要将旧工作分支的绿灯冒充新提交已通过。

## 模块职责

- v3/types.ts：Recipe、权重、骨骼语义。
- v3/cage.ts：固定面连接、共享索引、方向和结构边。
- v3/body.ts：连续人体、身材形变、骨架位置。
- v3/outfit.ts：可见表面替换、服装细节和装备。
- v3/rig.ts：SkinnedMesh、AnimationClip、AnimationMixer。
- scene/CharacterViewport.tsx：场景、相机、预览和资源释放。
- scripts/check-v3.ts / check-components.ts：几何与蒙皮动作检查。
- scripts/review-v3.mjs：真实浏览器截图与交互。

## 本地

拉取 main 后双击 Start-Local.cmd。启动脚本对干净 main 尝试快进更新；有本地修改或在其他分支时跳过，不覆盖工作。Node.js 要求 22.12+。依赖变化会按 lockfile 重装；端口被占用会选择相邻空闲端口。
