## 本批已实现的代码

独立上衣/裤装/鞋资产接口与注册；7种原有上衣和7种下装进入同一新装配路径。裤装用四片有宽度的裆底连接左右腿口，不依赖旧人体裆点。上衣有短袖、长袖和内衬色区，领缘仍随衣面投影。未增加实时布料、碰撞求解、骨骼或连续体型。

固定覆盖只删除服装下面的皮肤。脱衣恢复源身体，裸露手颈保留；输出含部件/覆盖/开口元数据，未使用皮肤和旧发髻顶点从渲染面清除。身体和绑定数据不变。

删除旧 `wardrobe/tailoring.ts`、身体衣面扩张/染色逻辑、旧的先生成再删除默认发髻路径；`geometry.ts`收敛为`adornments.ts`。不保留并行旧制衣器。旧表面黄金样本退役，保留同源的身体/绑定黄金数据，不偷偷替换旧人体哈希。

Recipe仍为V5六字段，保存键和严格拒绝策略不变。农户/卫兵/弓手、混搭、三色/发色、头饰、种子/锁定/撤销/保存/文件、动作库都保留。

## 尚未完成

这是独立衣裤的第一批制作与工程基础，不是大量新款完成版。礼衣/分裳暂简化为短衣和裤式轮廓；外部衣服Mesh导入器、完整长袍/裙摆、独立DCC男女源文件、服饰海量化、Unity导入插件/GPU群体渲染均未实现。裸模髋裆外观未专项修复，结构调试中的裸模不作为最终穿衣外观。

皮肤覆盖与已测试下装自交通过不等于全部服装接口、手臂/道具及任意连续瞬间零穿插。后续重点用截图检查腰口、袖口、裤脚，扩充成熟版型；不恢复通用体型或实时解算器。原依赖警告未专项升级，不把build成功写成安全审计通过。

## 本地使用

合并后：`git fetch origin` → `git switch main` → `git pull --ff-only origin main` → `npm ci` → `npm run dev`。Node.js >=22.12；也可Start-Local.cmd。FBX放入动画参考目录，重启/构建自动扫描，不固定文件上限。
