## 本轮边界

Shooting Arrow 只驱动人体。静态装备沿用现有 DIY，弓弦、箭、释放事件与精确手握尚未重配。未引入源驾驶舱/水体/第二人物。大幅翻转可能暴露旧肩肘髋蒙皮/服装限制，不能说自动重定向已解决所有美术问题。

没有通用动作混合、中断过渡、脚锁定、物品任务状态机、库存/生产结算或正式投射物。

目标 JSON 包含 20 骨骼局部轨道与来源/体型/根轨迹，但不是 Unity Clip/Avatar/Blob。MeshData/Burst、GPU 群体、LOD、万人性能仍待实现。接下来应先审查源目标动作质量，再做外部工具目标骨架导出/再导入与 Unity 单人对照，而不是再造大量手写动作。
