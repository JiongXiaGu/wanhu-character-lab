# 工作交接

这是新对话、新 AI 或新开发者接手 Wanhu Character Lab 时的首要入口。

## 项目定位

本仓库用于验证《万户天工》的程序化人物生成方案。

它不是最终 Web 产品，也不是独立角色编辑器产品。最终目标是把验证稳定的规则迁移到 Unity，用于大规模城市居民。

网页主要验证：

- 人体参数如何映射为运行时 Mesh；
- 服装如何从 Recipe 生成而不是加载成品模型；
- 骨骼、蒙皮、LOD、合并和缓存策略；
- 角色数据协议是否能被 Web 与 Unity 同时理解。

## 当前技术栈

## 当前 ShoulderPatch 状态

ShoulderPatch v1 的目标是先消除截图中最明显的“躯干旁边插两根柱子”的结构感。

当前：

- Torso 与 ShoulderPatch 仍有内部相交；
- ShoulderPatch 与 Arm Root 使用相同几何边界参数，但当前仍是重复顶点；
- 尚未建立 Torso 开口；
- 尚未共享 Index / Vertex；
- 因此它是过渡架构，不是最终肩部拓扑。

不要把当前相交方案扩散到 Hip / Neck。下一步先把 Shoulder 做成真正无重叠共享边界，再抽象通用 JointPatch。

## Debug Review 规则

重要人体拓扑修改不能只看 Build。

至少检查：

- Shaded：整体轮廓是否自然；
- Wireframe：布线密度和走向；
- Overlay：表面与三角形关系；
- Regions：BodyRegion 是否落在正确位置；
- Ring Guides：Section / Patch 截面是否跳变；
- Front / Side Orthographic：人体比例和左右对称；
- 3/4 Perspective：实际观察下是否出现断层、穿插和明显硬折。
