## 本地体验

`git fetch origin` → `git switch main` → `git pull --ff-only origin main` → `npm ci` → `npm run dev`。Node.js >=22.12，打开终端给出的本机地址。

安装一次 `npx playwright install chromium` 后，`npm run review:local -- --wardrobe` 检查第一批静态组合；加 `--full` 检查完整服饰矩阵。原 `review:local` / `--full` 仍检查人体与裤装形变。只有命令真实跑通时才称作本地真实网页截图。
