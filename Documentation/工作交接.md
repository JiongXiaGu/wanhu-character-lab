## 新代码与原语

动作不按职业制作。统一保持Locomotion / Carry / Interaction / Tool / Combat分类，第一轮用下列具体道具验证通用原语：

- Pick/Place → 木箱。
- CarryFront/CarryShoulder/CarryBack → 木箱、原木、柴捆。
- Push/Pull → 双手独轮车。
- ToolSwingTwoHand/ToolSwingOneHand → 锄头、锤。

`src/character/actions/catalog.ts`定义动作、占槽、事件；`anchors.ts`是道具局部握点；`kinematics.ts`仅构建期解析IK；`bake.ts`统一采样人体与道具；`props.ts`建道具；`player.ts`控制播放和事件。

原 `v3/types,cage,body,outfit,rig` 仍负责Recipe、连续基模、服装和标准SkinnedMesh适配。没有用工作动作取代原来的六种Motion。

## 不能破坏

+Z前。负重推拉为原地动作，导航负责世界位移；车轮累计相位，不能每步清零。

工作预览只临时隐藏冲突手/背装备，不改变Recipe；退出必须恢复弓、箭袋、剑盾等DIY。Bone顺序不变。

Pick/Place停止后保持姿态和事件；暂停不发送/重放事件；主动定位和重播才重设游标。不要把停止和seek重新耦合。

主体GPU蒙皮，不逐帧IK或重建人体Mesh。结构布线、握点是调试CPU路径。

不同骨长有不同绑定矩阵；未来GPU最终矩阵缓存必须包含BindProfileKey，不可仅凭相同20Bone ID直接复用所有体型矩阵。
