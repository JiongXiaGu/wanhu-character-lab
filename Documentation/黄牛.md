# 黄牛：本体与骑乘

## 目标与边界

cattle_yellow是中国古代农耕背景下的可骑乘黄牛／耕牛，与栗色马、灰驴、双峰骆驼并列。不是奶牛、水牛或现代肉牛预设，不以缩放、拉宽马／驴来生成牛。识别重点为厚桶身、短粗颈、宽头鼻镜、弯牛角和真正分趾蹄。

本轮只包含本体、四动作、普通／旅行牛鞍、男女骑姿、既有两工作台接线与自动检查。不做猪／野猪／第五物种、牛车、犁、牛轭、耕田、驮运库存、群体AI、上下坐骑、Root Motion、地形IK、腿IK或实时绳／布料物理。猪无鞍可骑的规则没有提前写入协议。

## 资产所有权

src/cattle/geometry.ts拥有黄牛截面、颜色、弯角、横耳、垂皮、鼻镜、嵌入眼鼻细节及八个趾壳。只复用闭合低模几何工具，不调用旧物种网格工厂。src/cattle/rig.ts拥有28骨的米制绑定。animation.ts拥有四个原生片段的作者曲线及创建时轨道烘焙。saddles.ts拥有普通／旅行鞍具、鼻带、挂点、CATTLE_RIDER_FIT和CATTLE_REIN_PROFILE。

src/mounts/catalog.ts只注册资产与视图构图；src/riding继续拥有人物与坐骑组合、稳定坐点、唯一时钟和缰绳生命周期。人物Recipe V5、20骨、衣柜、Cap、帽饰与FBX作者路径不改。实现与参数以代码为权威，本文说明意图与边界，不维护第二份逐点网格数据。

本体为1956三角形、1032逻辑点、5868硬边拆分顶点、27个闭合作者小壳。闭合是逐作者壳闭合，不表示全身焊接为单一流形；鞍具和动态双绳预算另计。低模硬边保留，不通过改相机、反向播放或平滑法线隐藏建模错误。

## 轮廓与绑定

躯干是较低、宽、饱满的桶身，背线压平、腹部保留体积。颈部短粗，胸前垂皮为闭合低模壳，不是布料。宽额向鼻口收束，深色鼻镜与头部有作者重叠；鼻孔和眼睛的小壳中心投到实际承载三角面上，不在播放时求解贴附。

两角由五道随三维切线变化的截面构成，先外展再上弯，根部嵌合头部、尖端收细且不埋入头壳；不是两根直锥或夸张水牛大角。横耳各有骨骼。尾干细长，由三段尾骨带动，末端单独毛束。

每只Foot有InnerHoof和OuterHoof两个独立闭合趾壳，沿横向留真实几何分缝，不以黑色贴面冒充偶蹄。腿比原马短粗。

28骨为Root、Pelvis、Spine、Chest、NeckBase、Neck、Head，四腿各Upper／Middle／Lower／Foot，Tail／TailMiddle／TailEnd，LeftEar／RightEar。米制、+X右、+Y上、+Z前，每点最多双权重；牛角和面部细节刚性随Head，垂皮仅Chest／NeckBase过渡，趾壳刚性随各自Foot。没有角骨、峰骨或人物骨架改动。

## 四个本体动作

| 统一语义 | 原生片段 | 时长 | 作者表现 |
|---|---|---:|---|
| idle | Cattle_Idle | 5.2秒 | 缓慢呼吸、轻重心变化、横耳和尾束摆动 |
| walk | Cattle_Walk | 1.8秒 | 慢重对角节奏，短颈轻点，较低起伏 |
| run | Cattle_Run | 1.05秒 | 更大步幅、胸臀起伏的沉重快跑，不作赛马疾驰 |
| eat | Cattle_Eat | 6.8秒 | 短颈与宽头一起下探，低位扫动啃食后抬起 |

片段首尾闭合，Root保持绑定，无水平根位移、缩放轨道、地形或腿部IK。创建AnimationClip时以真实作者绑定标定竖向蹄底留量，播放仅采样已烘焙轨道。正向低位脚轨迹向-Z后掠，抬脚向+Z回摆，不倒放时钟或镜像补救。进食只在本体页，骑乘沿用静态／停驻／步行／奔跑。

## 牛鞍与缰具

SaddleId仍为none／simple／travel。普通款为低宽厚背垫、浅鞍座和简化蹬带；旅行款增加左右布袋、小卷包和绑绳，仍是一件整体资产，没有袋子或鞍垫子槽位。

鞍具和稳定RiderSeat分别跟随Spine，Head挂鼻带与侧环。bitLeft／bitRight只是沿用兼容字段，语义为鼻侧金属环，不表示黄牛嘴中有马衔铁。独立ReinProfile设置牛颈外侧导向，动态双绳继续使用原固定200三角形缓冲；无绳物理、手部IK或逐帧Geometry分配。

CATTLE_RIDER_FIT为成年男女分别指定坐高与更宽跨坐，大腿略向前，双手低且稍宽。骑手仍是20条局部四元数轨道，人物先独立绑定再挂接，不重算inverse bind，不重定向原FBX。同页换鞍不重建人物、动物或绳；换物种保留人物和归一化相位，并更换独立动物／鞍具／绳适配。

none隐藏骑手与缰绳、冻结骑乘但保留动作、相位和外观；切其他物种仍为none，不自动装鞍。本体无鞍仍可播放四动作，有鞍无骑手不显示悬空持缰绳。

## 工作台和临时预览状态

不新增页面。种类下拉依次为栗色马、灰驴、双峰骆驼、黄牛；仍只有坐骑本体与骑乘试衣两种模式、种类与整体鞍具两项选择。

两模式链接携带当前种类与鞍具。preview-session只在用户点击模式链接时，将该模式的动作、真实采样相位、暂停／循环／速度、Orbit相机位置／缩放和未保存骑手V5装扮写入页签sessionStorage。返回时按各自快照恢复，不持有旧GPU对象，不创建隐藏Canvas，不覆盖人物工坊localStorage，也不改变Recipe V5格式。普通URL深链不读取临时缓存；格式错误或存储被禁用时安全退回URL初值。

## 检查覆盖和验收边界

统一入口仍为npm run check:mounts，没有新增永久check:cattle命令。黄牛专项由mount-cattle-checks.ts与mount-cattle-anatomy-checks.ts组成，并追加在原灰驴和骆驼矩阵之后。

检查本体27壳闭合／绕序／体积／非退化、28骨父关系与绑定、双权重、头角刚性及左右对称／根部嵌合、鼻镜与眼鼻贴合、垂皮权重、八个Foot刚性分趾及真实分缝。964本体姿态检查有限值、地面、循环闭合、进食最低头和Walk／Run正向脚轨迹；男女×两鞍×三骑姿×241相位为2892骑乘姿态，加70套衣裤关键相位与32次四物种切换。

旧蹄底-0.012米、进食最低头0.01–0.12米、嘴环0.006米制作接触门槛不放宽。缰绳中心线穿越范围额外包括鼻镜、角和垂皮，不能豁免整头。反例包括错误权重、角不对称、缺失趾壳、悬空鼻镜／鼻孔、反向脚轨迹、变坏的缰绳端点及非法物种；恢复后原实例继续工作。
