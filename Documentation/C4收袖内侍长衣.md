# C4 · 收袖内侍长衣

正式 ID：`attendant_fitted_long_robe`；top 槽位；独立作者文件 `src/character/wardrobe/assets/attendant-fitted-long-robe.ts`。任务 PR #75。本文描述作者和验收契约，具体交付状态以《工作交接》和精确 run 为准，不把登记等同于已合并或用户美术认可。

## 外形与 C1 的区别

C1 `narrow_long_robe` 是近似 H 型、腰带与小展完整长摆；C4 是窄肩、肘下收袖、无凸出束带的轻收腰、前后窄长片和窄侧衩。需要在同机位素模正/侧/三分之四中识别，不靠颜色、纹样或亮度。

实际袖山最外缘约为 C1 的 95%，袖口截面投影约 80%；下摆横向跨度小于 C1 的 80%。腰身不是极细束腰，髋部必须在固定人体外留量。前摆作者高度 .350 m，后摆 .310 m（男作者坐标），双侧缝隙约为横截面前后深度的 10%；不是两片宽敞围裙或官员大袖袍。仅为游戏用泛化内侍长衣，不宣称朝代礼制精确复原。

第一版实图曾发现宽开口近似围片、肩部只测衣身而实际袖山仍宽，以及坐姿前摆离膝较远；后续收窄真实袖山与侧衩、减小前后深度。长摆中线列保持横向支撑，修复原行走/跑动的前后片交叉，不靠改容差或删面。

## 作者和装配

单件封口后 364 逻辑顶点、724 三角形；12 列上身、独立六边袖筒截面、前后下片与 6 mm 法向内收厚边。领口、两袖口和腰内口仍由原 `sealGarmentInterfaces` 完整封闭。开衩边和前后下缘是明确共边厚边，不是透明面或任意拓扑修洞。

前后片跨 pelvis/thigh/shin；covers 仅 torso/upperArm/forearm/pelvis，大腿小腿保留，避免无下装时侧衩露空。Hip→SlitRoot→UpperPanel 只用 Hips/各侧 Thigh；膝下用既有两骨 kneeWeights。作者不读取性别、下装或动画相位；男女只经过原 shapePoint 一次。

Recipe V5 六字段、七槽位、固定男女、20 骨、最多双权重、一个装配 Mesh、原染色/自由混搭全部保持。没有内侍身份字段、专用页、骨链或布料。C4 有自己的共面前襟，装配仅为该 ID 停用旧通用交领装饰，其他上衣不改。类型、版型、slot options、taxonomy 和 gap 说明同步；默认平民随机池不变。
