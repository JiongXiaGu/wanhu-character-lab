# 运行时人物生成架构

## 1. 最新设计决策

当前代码中的 Segmented Low-Poly Humanoid 已完成低面数、Mesh Validation 与三视图实验，但它暴露出两个长期问题：

- 身体蒙皮不连续；
- 没有从一开始为服装 Surface / Body Hide 设计稳定拓扑。

因此它不再作为最终人体拓扑。

下一主线定义为：

V2 Continuous Low-Poly Base Body + Garment-Friendly Topology

注意：这不是回到早期高分段 Ring / JointPatch 方案。

V2 的目标是：

- 单一连续人体 Cage；
- 固定且长期稳定的低模拓扑；
- 面数仍严格受控；
- 关节只保留最少必要环线；
- 通过参数移动固定顶点，而不是运行时改变拓扑结构；
- 从人体设计阶段就定义 Garment Anchor 与 Body Face Group；
- 服装默认骨骼驱动，不做实时 Cloth Simulation。

当前 Segmented 实现保留为技术实验参考，后续 V2 完成后再清理。

## 2. 正式数据链

~~~text
BodyParameters
→ HumanLandmarks
→ Continuous Base Body Topology
→ Body Surface Semantics
→ RigDefinition
→ Skin Weights
→ GarmentRecipe
→ Body Hide
→ Body / Garment Mesh Assembly
→ Mesh Validation
→ LOD
→ CharacterMeshKey
→ Mesh Cache
→ Renderer
~~~

Web 与 Unity 共享的是参数语义、Landmark、Body Region / Face Group、Garment Anchor、Recipe、Skeleton 语义和 LOD 规则。

不共享 Three.js / Unity 渲染 API。

## 3. V2 基础人体原则

V2 人体不是高模人体，也不是独立积木。

目标是一个连续低模 Base Cage。

### 必须连续

以下区域必须在同一人体 Surface 中连续：

- Neck → Torso；
- Torso → Shoulder → UpperArm；
- Pelvis → UpperLeg；
- Elbow；
- Knee。

### 必须稳定

同一个 LOD Profile 下：

- Vertex Count 固定；
- Index 拓扑固定；
- Vertex Semantic 固定；
- Body Face Group 固定。

身高、体型、肩宽等参数只改变顶点位置。

这样 Skin Weight、Garment Mapping、Body Hide 和 Mesh Cache Key 都能保持稳定。

### 不追求写实环线

肩、肘、髋、膝只保留动画与服装需要的最少环线。

目标不是 Blender 人体雕刻拓扑，而是游戏低模 Cage。

## 4. HumanLandmarks

人体、Rig 和服装必须引用同一套 Landmark。

建议至少包括：

- HeadTop / HeadBottom；
- Neck；
- Shoulder；
- Chest；
- Waist；
- Hip；
- Elbow；
- Wrist；
- Knee；
- Ankle。

Landmark 不等于 Vertex Index。

Landmark 是稳定的人体语义位置，可以由 BodyParameters 计算。

## 5. Body Surface Semantics

V2 必须新增两层语义。

### Body Face Groups

Triangle 按身体覆盖区域分组，用于 Body Hide：

- Head；
- Neck；
- Chest；
- Back；
- Abdomen；
- Pelvis；
- UpperArm；
- LowerArm；
- Hand；
- UpperLeg；
- LowerLeg；
- Foot。

### Garment Anchor Loops

服装生成引用少量稳定锚点：

- NeckLine；
- ChestLine；
- WaistLine；
- HipLine；
- UpperArmLine；
- ElbowLine；
- WristLine；
- ThighLine；
- KneeLine；
- AnkleLine。

这些是 V2 人体拓扑设计的第一等公民，不允许等衣服阶段才临时补。

## 6. Rig 与 Skinning

人体 Surface 连续后，默认不再使用“每个独立棱柱 100% 单骨骼”的方式作为最终近景方案。

但仍然坚持有限 Skinning：

- 普通 Body Vertex：1 Bone；
- 关节区域：最多 2 Bone；
- 只有确实需要时才增加更多权重。

目标：

~~~text
大部分顶点 rigid
+
极少量 joint blend
~~~

而不是所有顶点复杂 4 Bone Skinning。

## 7. 服装总原则

服装默认不做 Cloth Simulation。

正式分类：

~~~text
Material Only
Body-Derived Garment
Independent Silhouette Garment
Rigid Attachment
~~~

服装必须与人体设计同时考虑。

详细方案见：

Documentation/服装生成架构.md

## 8. Body Hide

穿衣后的最终几何不应是：

~~~text
完整裸体
+
完整衣服
~~~

GarmentRecipe 必须提供 Body Hide 信息。

Mesh Assembly 根据当前穿着直接跳过被完全覆盖的人体 Triangle。

收益：

- 降低 Triangle；
- 降低 Skinning；
- 降低 Overdraw；
- 消除大量穿模；
- 避免 Z-Fighting。

## 9. Garment Mapping

普通服装优先从 Body Surface 生成。

~~~text
Body Surface
→ semantic / barycentric mapping
→ garment offset / ease
→ garment vertex
~~~

真正改变外轮廓的服装使用独立 Low-Poly Garment Cage：

~~~text
HumanLandmarks
+ Garment Anchors
+ Garment Profile
→ Independent Garment Mesh
~~~

长袍、裙、宽袖属于第二类。

## 10. Secondary Motion

默认层级：

~~~text
Skeleton Driven
→ Shader Sway
→ Few Helper Bones
→ Cloth Simulation
~~~

大量 NPC 默认只使用前两层。

真正 Cloth Simulation 不进入基础角色方案。

## 11. 面数预算

V2 设计阶段先使用以下目标：

~~~text
Base Body：350–500 tris
普通穿衣居民 LOD0：450–700 tris
复杂服饰居民 LOD0：600–900 tris
LOD1：250–400 tris
LOD2：100–200 tris
极远：Impostor / Billboard
~~~

预算按最终可见 Mesh 计算。

因为 Body Hide 会删除被服装覆盖的人体 Triangle，所以不能用“裸体 + 上衣 + 裤子”的简单相加方式评估最终成本。

最终预算必须通过 Unity 实机 Profile 再调整。

## 12. Mesh Validation

所有运行时生成 Mesh 继续执行：

- Finite Vertex；
- Degenerate Triangle；
- Winding；
- Index Range；
- Budget；
- Structure。

未来增加：

- Body Face Group 完整性；
- Garment Coverage 完整性；
- Body Hide 泄漏；
- Garment Mapping 越界；
- Skin Weight Sum；
- Bone Index Range。

## 13. Review 门槛

Build / Mesh PASS 只代表技术正确，不代表美术与拓扑正确。

人体修改必须实际检查：

- Front Orthographic Overlay；
- Right Orthographic Overlay；
- Top Orthographic Overlay；
- Back；
- 3/4 Perspective；
- Front / Side Wireframe。

进入 Skinning 后，再增加：

- 抬手；
- 屈肘；
- 抬腿；
- 屈膝；
- 转颈。

进入 Garment 后，再检查：

- Body Hide；
- 衣服外轮廓；
- 关节露缝；
- 身体穿出；
- Triangle Budget。

## 14. 参考系统

MakeHuman / MPFB 主要参考稳定人体语义、参数与拓扑分离、Rig 与 Mesh 分离、Body-to-Clothing Mapping。

MakeClothes 主要参考 Clothes 对 Body Surface 的映射、Body Delete / Hide Group、Weight Transfer。

UMA 主要参考 Recipe、Character Build Pipeline、Mesh Combine、Runtime LOD 和 Cache / Build 分层。

本项目只吸收这些架构原则，不照搬高面数人体和 Slot Mesh 资产路线。

## 15. 当前代码状态

当前 Web 代码仍是 Segmented Low-Poly prototype。

它已经验证：

- 极低面数 Runtime Mesh；
- UInt16 Index；
- UInt8 Part / Bone 语义；
- Winding；
- Mesh Validator；
- 自动三视图 Review。

这些基础设施继续保留。

下一步不要直接在当前 Segmented Mesh 上增加正式 Rig / Garment。

先完成 V2 Base Body Topology 设计。
