# 运行时人物生成架构 · V3

## 1. 当前生成链

~~~text
Recipe
→ makeBody
→ makeCharacter
→ shapePoint
→ CharacterData
→ makeActor
→ SkinnedMesh + Skeleton + MotionClip
~~~

Recipe 保存职业、身高、体格、头饰、装备和颜色组。

types / cage / body / outfit 是不依赖 Three.js Renderer 的生成层。

rig.ts 是 Web 验证适配层。

## 2. 人体与渲染数据

头、颈、躯干、双臂、裆部、双腿共享连续人体表面。

肩和髋使用固定连接，不做运行时最近点焊接。

主体四边面最终固定三角化。

逻辑 Cage 与渲染顶点不同：

- Cage Vertex：拓扑 / 语义 / 权重
- Render Vertex：Position / Normal / Color / SkinIndex / SkinWeight

硬法线和颜色可以拆渲染顶点，但必须保留相同骨骼绑定。

职业、服装、体型不得改变这个顺序。

## 4. SkinBinding

逻辑权重：

~~~text
[BoneA, BoneB, WeightA]

WeightB = 1 - WeightA
~~~

正式规则：

- 每顶点最多两个非零权重
- 刚性区尽量单 Bone
- 肩 / 肘 / 髋 / 膝 / 颈允许 2 Bone Blend
- 权重和必须为 1
- Bone Index 必须合法

Three.js 当前写入标准 4 通道 skinIndex / skinWeight，但后两通道恒为 0。

Unity Crowd 路径以后可压紧到 Bone0 / Bone1 / Weight0。

## 5. 当前 Web 动画

当前 Motion：

- Bind
- Idle
- Walk
- Run
- Wave
- Squat

动画在构建时生成 KeyframeTrack，运行时 AnimationMixer 只更新骨骼，不重建 Mesh。

主体角色使用 Three.js SkinnedMesh GPU skinning。

CPU 蒙皮只存在于：

- 结构线框 Debug
- 测试 reference path

不能把 Debug CPU 路径当作正式角色动画方案。

## 6. 坐标与步态

固定坐标：

~~~text
+X = 人物右侧
+Y = 向上
+Z = 人物正前方
~~~

Walk / Run 当前是原地动作。

导航 / ECS 负责角色世界位移。

Walk 回归规则：

~~~text
0.00  右脚 +Z 前触地，右臂后摆
0.25  左脚抬起向前摆
0.50  左脚 +Z 前触地
0.75  右脚抬起向前摆
~~~

这条规则已经进入 CI。

## 7. 服装与装备

当前短衣、裤子、绑腿和轻甲轮廓采用覆盖区域表面替换。

不在同一位置完整保留裸体 + 衣服两套表面。

领口、腰带、五官、头发和装备是附加面。

所有可蒙皮衣物共享同一 SkeletonDefinition。

Rigid Attachment：

- 帽子 → Head
- 武器 → Hand
- 箭袋 → Chest / Back 语义

不为普通衣服建立独立骨架。

## 8. Unity 动画迁移

Web 不迁移 AnimationMixer 类层级。

Unity 共享契约：

~~~text
SkeletonDefinition
SkinBinding
MotionClip
AnimationState
~~~

近景第一阶段：

~~~text
SkinnedMeshRenderer
+ 固定 Skeleton
+ GPU Vertex Skinning
~~~

Crowd 目标：

~~~text
ResidentAnimationState
→ ClipId / Phase / Speed
→ Animation Texture 或 StructuredBuffer
→ Bone Transform
→ Entities Graphics
→ GPU Skinning
~~~

详见 Documentation/GPU骨骼动画迁移契约.md。

## 9. Cache

几何与动画分开缓存。

CharacterMeshKey 只描述几何：

~~~text
BodyTopologyVersion
QuantizedHeight
QuantizedBuild
OutfitRecipe
Equipment
LOD
~~~

颜色尽量不进入 Geometry Key。

MotionClip 按 SkeletonVersion + ClipId 共享。

单个居民主要保存：

~~~text
Transform
CharacterMeshKey
Appearance Parameters
ResidentAnimationState
~~~
