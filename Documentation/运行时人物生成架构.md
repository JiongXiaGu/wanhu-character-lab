# 人物数据与装配 · 固定基模

数据协议位于src/character/v3/types.ts，目录名v3是内部路径，不代表仍支持Recipe V3。入口为createRecipe→makeBody/makeJoints→服饰装配→CharacterData→makeActor。createRecipe仅供内部创建，用户文件必须经parseRecipeFile。

Recipe V5：固定bodyType、七slots、dyes、hairStyle、hairColor。男基模名义高度1.76m、女1.66m是制作常量，不是玩家参数。femalePoint是固定女性外形映射而非可编辑体型场。动态height/build已经删除。

骨骼顺序：Root,Hips,Spine,Chest,Neck,Head,RightClavicle,RightUpperArm,RightForearm,RightHand,LeftClavicle,LeftUpperArm,LeftForearm,LeftHand,RightThigh,RightShin,RightFoot,LeftThigh,LeftShin,LeftFoot。名称、索引与父关系保持；男女局部绑定位置可不同。权重为[boneA,boneB,weightA]；+X右/+Y上/+Z前，单位米。

逻辑人体仍510tris。上衣/裤装/鞋是独立部件，覆盖区域中的皮肤不参与绘制；剩余皮肤和服装装配为一个蒙皮网格。发髻冠帽工具为附件。硬边拆点不改变逻辑蒙皮。基础网格允许在后续明确任务中局部重建，不再要求永远等于旧男性哈希。

动画切换复用已有网格；衣服或性别变化生成新几何并保留动画相位。源数据与目标烘焙在加载时处理，不每帧重建人物。无程序动作、实时布料或全身IK。

资源状态：固定男女与独立衣裤装配已落地；尚未有外部服装网格导入器、独立asset编译管线、GPU群体运行或多档人物LOD。服饰、头饰与染色的完整组合仍需逐批审查。

CharacterData新增garments资产/版本/覆盖/开口清单，Face.part标明skin/top/bottom/shoes；接口索引在surface.anchors。装配结束清除未使用顶点，不每帧删面。新几何版本wanhu-modular-garments-v2；旧人体衣面生成器已删除。
