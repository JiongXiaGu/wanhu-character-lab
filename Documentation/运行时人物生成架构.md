# 运行时人物生成架构

## 1. 当前核心方向

正式角色不是一组预制 Mesh Asset，而是：

`Parameters + Recipe + Runtime Generator`

但人体基础拓扑不再追求一张连续、可平滑变形的皮肤。

当前采用：

`Segmented Low-Poly Humanoid`

核心原则：

- 极低面数；
- 固定、可预测拓扑；
- 身体部件逻辑分段；
- 关节允许少量互相穿插；
- 优先刚性或有限蒙皮；
- 运行时最终仍可合并为一个 Mesh；
- 近景依靠轮廓与材质提升观感，而不是堆人体环线。

## 2. 已停止扩展的路线

Phase 1 / 1.5 曾验证：

- Ring Topology；
- JointPatch；
- Shoulder Opening；
- Shared Boundary；
- 连续 Torso → Arm 拓扑。

这套方案技术上可行，但对《万户天工》的大规模城市居民成本过高。

因此：

- 不继续做 HipPatch；
- 不继续做 NeckPatch welding；
- 不继续追求连续裸体 Mesh；
- 旧代码暂时保留用于对照，但不进入当前运行链。

## 3. 当前生成链

```text
BodyParameters
→ createLowPolyHumanoidBlueprint
→ LowPolyPart[]
→ PrismSection[]
→ buildLowPolyGeometry
→ BufferGeometry
```

当前人体由 16 个逻辑部件组成：

- Head；
- Neck；
- Torso；
- Pelvis；
- Left / Right UpperArm；
- Left / Right LowerArm；
- Left / Right Hand；
- Left / Right UpperLeg；
- Left / Right LowerLeg；
- Left / Right Foot。

## 4. 固定截面

只允许三种基础截面：

- `box4`
- `hex6`
- `oct8`

不使用通用高分段圆环。

推荐：

- Head / Hand / Foot / Neck：box4；
- Arms / Legs：hex6；
- Torso / Pelvis：oct8。

目的不是做 Minecraft 外观，而是借鉴其“低复杂度分段角色”工程思想。

## 5. 关节

关节默认允许相邻部件重叠约 5%～15%。

例如：

```text
Torso
  overlaps
UpperArm
```

以及：

```text
UpperLeg
  overlaps
LowerLeg
```

不再为这些位置创建专用 JointPatch。

这样可以：

- 大幅减少三角面；
- 保持布线规则；
- 避免复杂共享边界；
- 简化后续骨骼动画；
- 让 LOD 更容易直接生成。

## 6. 顶点语义

当前每个顶点至少写入：

- Position；
- Normal；
- `bodyPart`；
- `boneIndex`。

当前 `boneIndex` 先使用逻辑部件 ID。

下一阶段骨骼验证时，默认采用：

```text
1 vertex
→ 1 bone
→ weight = 1
```

也就是刚性 Skinning。

只有确实需要改善的近景关节，才允许增加有限的 2-Bone Blend。

## 7. 面数预算

基础裸体人物：

- 硬上限：500 tris；
- 当前目标：200～300 tris。

以后 LOD 大致方向：

- LOD0：约 300～600 tris（含基础衣物后再重新定）；
- LOD1：约 150～300 tris；
- LOD2：约 60～150 tris；
- 极远：Impostor / Billboard。

这里是方向性预算，最终以 Unity 实机 Profile 为准。

## 8. 衣服方向

衣服继续保持程序化生成，但优先采用与身体一致的低模分段思想。

例如：

```text
Torso Prism
→ outward scale
→ Shirt Shell
```

裤子：

```text
UpperLeg / LowerLeg
→ outward shell
→ Pants
```

长袍、裙装等再使用独立低模轮廓。

不要回到：

`每件衣服一个 FBX / GLB`

## 9. Debug Review

网页保留：

- Shaded；
- Wireframe；
- Wire Overlay；
- Part Colors；
- Part Guides；
- Grid / Axis；
- Perspective / Orthographic；
- 固定 Front / Back / Left / Right / Top / 3/4。

自动 Visual Review 固定生成：

1. 3/4 Overlay；
2. Front Orthographic Wireframe；
3. Right Orthographic Part Colors。

主线修改不能只通过 Build 判断。

## 10. 当前关键代码

`src/character/types.ts`
人物参数。

`src/character/lowPolyTopology.ts`
低模部件与固定截面协议。

`src/character/createLowPolyHumanoidBlueprint.ts`
参数解析为 16 个分段部件。

`src/character/buildLowPolyGeometry.ts`
直接生成顶点与 Index。

`src/character/generateHumanoidGeometry.ts`
当前薄编排入口。

`src/scene/createLowPolyDebug.ts`
Part Color / Part Guides。

`src/scene/CharacterViewport.tsx`
预览与 Debug View。
