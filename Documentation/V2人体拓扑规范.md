# V2 人体拓扑规范

## 1. 目标

V2 是《万户天工》正式人物系统的基础人体拓扑规范。

目标不是高写实人体，也不是把当前 Segmented Prototype 焊在一起。

V2 应当是：

- 一个连续的 Low-Poly Base Body；
- 固定拓扑；
- 稳定 Vertex / Face 语义；
- 适合有限蒙皮；
- 从一开始支持服装 Anchor 与 Body Hide；
- Runtime 只根据 BodyParameters 重新计算顶点位置；
- 最终 Mesh 仍由程序在运行时构建；
- 不保存每个体型的最终人体 Mesh。

## 2. 核心原则

### 固定拓扑，不运行时发明连接关系

错误方向：

~~~text
BodyParameters
→ 临时决定 Ring 数量
→ 临时连接肩 / 髋
→ 每次重新发明拓扑
~~~

V2：

~~~text
BaseBodyTopologyTemplate
+
BodyParameters
+
HumanLandmarks
→ Resolve Vertex Positions
→ Fixed Triangle Indices
→ Runtime Mesh
~~~

同一 LOD 下：

- Vertex Count 固定；
- Triangle Index 固定；
- Vertex Semantic 固定；
- Face Group 固定；
- Garment Anchor 固定；
- Skin Weight Rule 固定。

身材变化只移动 Vertex，不改变拓扑。

## 3. 运行时保存什么

允许保存的是“生成规则”，不是最终人物 Mesh。

### BaseBodyTopologyTemplate

建议包含：

~~~text
BaseBodyTopologyTemplate
├─ version
├─ bindPose
├─ vertexRules[]
├─ triangles[]
├─ mirrorPairs[]
├─ bodyFaceGroups[]
├─ garmentAnchorLoops[]
├─ jointRegions[]
└─ lodProfile
~~~

### VertexRule

VertexRule 不保存某个居民的最终世界坐标。

它描述该顶点如何由人体语义计算。

概念示例：

~~~text
VertexRule
├─ semanticId
├─ landmarkWeights
├─ lateralFactor
├─ frontDepthFactor
├─ backDepthFactor
├─ bodyRegion
└─ mirrorPolicy
~~~

运行时：

~~~text
HumanLandmarks
+ Body Measurements
+ VertexRule
→ Final Vertex Position
~~~

这样可以在 Blender 中辅助设计一次基础 Cage，但导出的仍然是拓扑和规则数据，不是最终居民模型。

## 4. 坐标与对称规范

统一约定：

- +X：人物右侧；
- +Y：向上；
- +Z：人物前方；
- 原点：两脚之间的地面中心；
- 人体中线：X = 0。

基础人体默认左右对称。

推荐只人工维护半身的 VertexRule，再由运行时镜像生成另一侧。

中线 Vertex 不重复。

必须维护稳定的 MirrorPair：

~~~text
LeftShoulder.Front
↔ RightShoulder.Front
~~~

这样可以自动检查左右拓扑与参数对称性。

## 5. Bind Pose

V2 建议采用轻微 A-Pose 作为生成 / 蒙皮基准：

- 双腿自然直立；
- 双臂从躯干向外约 30°；
- 肘和膝保持接近伸直；
- 手掌保持中性简化姿态。

理由：

- 肩部比完全 T-Pose 更自然；
- 腋下不需要极端拉伸；
- 上衣与袖子更容易生成；
- 后续仍可用动作 Review 转成 T-Pose / 抬手姿态。

是否最终与 Unity Humanoid Avatar 直接对应，在 Rig 阶段单独验证；V2 拓扑不依赖 Mecanim 才能成立。

## 6. 顶点与三角面预算

第一版目标：

~~~text
Base Body
Vertex：约 180–260
Triangle：约 350–500
硬上限：550 tris
~~~

预算不是平均分配。

优先保留面数的位置：

1. Shoulder
2. Hip
3. Elbow
4. Knee
5. Neck
6. Silhouette

优先节省面数的位置：

- 胸腹大平面；
- 背部大平面；
- 前臂中段；
- 小腿中段；
- 手；
- 脚；
- 头部内部细节。

不做：

- 独立手指；
- 独立脚趾；
- 耳朵复杂结构；
- 鼻唇写实拓扑；
- 肌肉环线。

## 7. 基础横截面密度

以下是 V2 第一版建议，不是通用生成器参数。

### Head

建议 8 边截面。

最低语义层：

~~~text
Jaw
MidFace
Cranium
Crown
~~~

头部不做完整面部拓扑。

需要保证：

- 正视不像方盒；
- 侧视有前额 / 后脑体积；
- Neck 连续进入 Head。

### Neck

建议 6 个环向顶点。

最低两层：

~~~text
NeckBase
NeckUpper
~~~

### Torso

主横截面建议 8 顶点。

最低语义层：

~~~text
UpperChest / Shoulder
Chest
Waist
UpperHip
~~~

不要增加无用途的中间 Ring。

### Arm

环向建议 6 顶点。

最低：

~~~text
ShoulderRoot
UpperArm
ElbowUpper
ElbowLower
Wrist
~~~

其中 ElbowUpper / ElbowLower 是必要的最小关节变形区。

### Leg

环向建议 6 顶点。

最低：

~~~text
HipRoot
UpperThigh
KneeUpper
KneeLower
Ankle
~~~

KneeUpper / KneeLower 是必要的最小关节变形区。

### Hand

Mitten-style。

不做手指。

目标约 8–12 verts。

### Foot

Wedge-style。

目标约 8–12 verts。

不做脚趾。

## 8. Shoulder Junction

肩部是 V2 最重要的固定 Junction。

不要运行时创建 JointPatch。

Shoulder Junction 必须直接存在于 BaseBodyTopologyTemplate。

结构：

~~~text
UpperChest
   ↓
Armhole Boundary
   ↓
ShoulderRoot
   ↓
UpperArm
~~~

要求：

- Torso 与 Arm 共用连续 Surface；
- 腋下无开口；
- 无内部重叠面；
- Armhole Boundary 是稳定语义；
- Shoulder Face 可被上衣 / 袖子隐藏；
- 抬手时不能明显撕裂。

建议 Armhole Boundary 使用约 6 个稳定顶点。

## 9. Hip Junction

Hip 与腿同样采用固定 Junction。

~~~text
UpperHip
  ↓
LegRoot
  ↓
UpperThigh
~~~

要求：

- Pelvis 与 UpperLeg 连续；
- 不依赖两个 Mesh 互相插入；
- 抬腿 45° 时无明显裂缝；
- 裤子 / 长袍能够引用 HipLine。

## 10. Elbow / Knee

Elbow 与 Knee 都使用“两层关节环”。

例如肘：

~~~text
UpperArm
↓
ElbowUpper
↓
ElbowLower
↓
Forearm
~~~

膝：

~~~text
UpperThigh
↓
KneeUpper
↓
KneeLower
↓
Calf
~~~

不要用大量环线追求写实。

两层环的目的只有：

- 允许 2-Bone Blend；
- 弯曲时维持基本体积；
- 为袖子 / 裤腿提供稳定关节映射。

## 11. Body Face Groups

V2 每个 Triangle 必须属于一个稳定 Body Face Group。

第一版建议：

~~~text
Head
Neck

Shoulder
Chest
Back
Abdomen
Pelvis

UpperArm
LowerArm
Hand

UpperLeg
LowerLeg
Foot
~~~

左右肢体通过 side semantic 区分，但不需要复制一套完全不同的 Group enum。

Body Hide 直接作用于 Face Group / Face Range。

例如长袖上衣：

~~~text
hide:
Shoulder
Chest
Back
Abdomen
UpperArm
~~~

裤子：

~~~text
hide:
Pelvis
UpperLeg
LowerLeg
~~~

更细粒度的 Hide 只有明确服装需求后才增加。

## 12. Garment Anchor Loops

V2 必须内置以下 Anchor。

### Torso

~~~text
NeckLine
ShoulderLine
Armhole
ChestLine
WaistLine
HipLine
~~~

### Arm

~~~text
UpperArmLine
ElbowLine
WristLine
~~~

### Leg

~~~text
ThighLine
KneeLine
AnkleLine
~~~

Anchor Loop 是有序 Vertex ID 列表。

例如：

~~~text
WaistLine = [v41, v42, v43, ...]
~~~

服装代码不允许扫描 Mesh 猜 Waist 在哪里。

## 13. Body Surface Patch

除了 Anchor Loop，Body-Derived Garment 还需要稳定 Surface Patch。

例如：

~~~text
TorsoFrontPatch
TorsoBackPatch
ShoulderPatch
UpperArmPatch
LowerArmPatch
PelvisPatch
ThighPatch
CalfPatch
~~~

普通上衣可以直接：

~~~text
TorsoFrontPatch
+ TorsoBackPatch
+ ShoulderPatch
+ UpperArmPatch
→ Offset / Ease
→ Shirt
~~~

因为基础人体拓扑固定，标准服装不需要每次运行时做昂贵的最近点搜索。

## 14. Garment Mapping 策略

第一版优先级：

### 标准程序化服装

使用 Semantic Patch / Anchor Loop。

这是主路径。

### 特殊美术服装

如果以后需要 Blender 中手工设计特殊轮廓，可以使用 MakeHuman / MakeClothes 风格的：

~~~text
Garment Vertex
→ Body Triangle
→ Barycentric Weights
+ Offset
~~~

但它是扩展路径，不是所有服装的基础路径。

这样可以避免为普通上衣、裤子做不必要的通用映射开销。

## 15. Skeleton V1 预留

V2 Topology 必须至少支持以下骨骼语义：

~~~text
Root
Hips
Spine
Chest
Neck
Head

Clavicle.L
UpperArm.L
LowerArm.L
Hand.L

Clavicle.R
UpperArm.R
LowerArm.R
Hand.R

UpperLeg.L
LowerLeg.L
Foot.L

UpperLeg.R
LowerLeg.R
Foot.R
~~~

LOD0 约 20 bones。

是否保留独立 Clavicle 在后续动作测试决定，但 V2 Shoulder Topology 必须允许它存在。

## 16. Skin Weight 规则

默认：

- 普通区域：1 Bone；
- Joint Region：最多 2 Bone；
- 不默认使用 4 Bone Influence。

建议：

Shoulder：

~~~text
Chest → Clavicle
Clavicle → UpperArm
~~~

同一个 Vertex 默认不同时混 3 Bone。

Elbow：

~~~text
UpperArm ↔ LowerArm
~~~

Hip：

~~~text
Hips ↔ UpperLeg
~~~

Knee：

~~~text
UpperLeg ↔ LowerLeg
~~~

Neck：

~~~text
Chest ↔ Neck
Neck ↔ Head
~~~

## 17. Clothing Skinning

Body-Derived Garment：

- 继承对应 Body Patch 的骨骼语义；
- 必要时重新插值 1–2 Bone Weight。

Independent Garment：

- 按 Anchor / Section 决定 Bone Policy；
- 长袍、裙默认绑定 Hips + Legs；
- 宽袖默认 UpperArm + LowerArm。

不默认增加大量服装骨骼。

## 18. Body Hide 编译规则

Body Hide 不在材质阶段做。

正式 Mesh Assembly：

~~~text
Base Body Faces
- Hidden Face Groups
+ Garment Faces
+ Hair / Attachment Faces
→ Final Mesh
~~~

被隐藏的人体 Triangle：

- 不写入 Index Buffer；
- 不参与 Skinning；
- 不参与 Overdraw。

Vertex 是否同时裁掉，在 Mesh Assembly 优化阶段决定。

## 19. LOD

V2 LOD 不要求所有级别共享完全一样的 Vertex Count。

但语义必须可映射。

建议：

### LOD0

完整 V2 Base Cage：

~~~text
350–500 tris
~~~

### LOD1

减少：

- Head 中间层；
- Elbow / Knee 细分；
- Hand / Foot 轮廓。

~~~text
200–300 tris
~~~

### LOD2

使用更激进的低模结构：

~~~text
80–160 tris
~~~

可重新使用 Segmented Prototype 的部分经验，但不是直接复用它的最终 Mesh。

## 20. 三视图 Review

Base Body 每次结构修改必须固定检查：

### Front Orthographic

检查：

- 头肩比；
- 肩腰胯；
- 手臂与腿粗细；
- 左右对称；
- Armhole；
- Hip Root。

### Side Orthographic

检查：

- Head 前后深度；
- 胸 / 腹 / 臀轮廓；
- Knee / Calf；
- Foot；
- Neck 前后位置。

### Top Orthographic

检查：

- Shoulder / Chest 截面；
- Head Depth；
- Arm 与 Torso 间距；
- 左右对称。

三视图不过，不能进入 Rig。

## 21. 动作 Review

Rig 完成后必须过：

~~~text
Bind A-Pose
T-Pose
Arm Raise 90°
Elbow Bend 90°
Leg Raise 45°
Knee Bend 90°
Neck Turn ±45°
Walk Extreme
~~~

检查：

- 肩是否塌；
- 腋下是否裂；
- 肘是否夹成纸片；
- 髋是否漏；
- 膝是否翻面；
- Neck 是否拉断轮廓。

## 22. Garment Review

第一件衣服开始后增加：

- Front / Side / Back；
- Wireframe；
- Body Hide Overlay；
- Anchor Loop Overlay；
- Arm Raise；
- Elbow Bend；
- Leg Raise；
- Knee Bend。

重点检查：

- Body 穿出；
- Hide 过多造成空洞；
- 袖口 / 裤脚 Anchor 错位；
- Clothing Weight 与 Body Weight 不一致；
- Triangle Budget。

## 23. Template Authoring

推荐允许使用 Blender 设计一次基础 Cage。

但 Blender 的作用是“拓扑设计工具”，不是最终运行时资产来源。

推荐流程：

~~~text
Blender Low-Poly Base Cage
→ 标记 Mirror
→ 标记 Vertex Semantic
→ 标记 Face Group
→ 标记 Anchor Loop
→ 导出 Topology Template / Vertex Rules
→ Runtime 根据 BodyParameters 重建
~~~

不能变成：

~~~text
Blender
→ 导出多个体型 FBX
→ 游戏换模型
~~~

## 24. 第一版实现顺序

文档确认后：

~~~text
Step 1
定义 BaseBodyTopologyTemplate / VertexRule 数据结构

Step 2
实现一套固定 Default Body
不做参数变化

Step 3
三视图 Review 固定拓扑

Step 4
接入 HumanLandmarks
让 Height / Build / ShoulderWidth 改 Vertex Position

Step 5
加入 Body Face Groups / Anchor Loops Debug

Step 6
用户 Review

Step 7
RigDefinition V1

Step 8
Skin Weight + 动作 Review
~~~

第一件衣服必须等 Step 8 通过后再开始。

## 25. V2 Base Body 验收条件

同时满足以下条件才算 V2 Base Body 完成：

- 连续单一人体 Surface；
- 无肩 / 髋 / 颈可见裂缝；
- 无内部重叠人体面；
- 350–500 tris 目标范围；
- UInt16 Index；
- 固定 Vertex / Index topology；
- Body Face Group 完整；
- Garment Anchor Loop 完整；
- 正交 Front / Side / Top 通过；
- Mesh Validator 通过；
- 左右镜像检查通过；
- 能进入 Rig 阶段而无需重新设计服装接口。
