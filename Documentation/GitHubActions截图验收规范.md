# GitHub Actions 验收 · 固定基模

## 当前验收方式（2026-09-20 更新）

用户已调整流程：完成代码和自动检查，实际检查图片后合并 main，再由用户进行简单视觉复核。视频不再是合并前置条件，不要求下载、播放或逐帧分析视频。

只在 Actions runner 内启动 Preview 和 Playwright 生成截图，不部署 Visual/Vercel。现有脚本附带的视频和时间接触表可以保留为可选诊断产物；它们的生成不代表已经人工查看。截图生成成功、下载成功、实际看图分别记录。

五条正式任务：Build、Character Model Review、Mixamo Retarget Review、Wardrobe Review、Tailoring V2 Review。工作流名称保留，测试契约为固定 V5。

## 图片和自动检查

两个固定成年男女基模，一种标准精度。保留现有服饰和动作矩阵，只删除退役身材、LOD 维度。全部 FBX 自动扫描，当前文件数不是上限。

重点动作包括 Pilot Flips Switches、Shooting Arrow、Jogging、Snatch 和现有起步、行走、劳动动作。静态、坐姿和深蹲检查正面、侧面、背面及多个相位，不只挑一张画面。修模时补充浅色髋裆近景、无光照或线框定位、同相机同相位前后对照。

图片可使用真实截图接触表，并对关键画面打开原图。记录原图精查、缩略图检查及未查看部分；不根据静态截图声称整个连续过程已全部通过。

文件和交互继续检查 V5 往返、旧版与非法字段拒绝、错误导入不改变角色、旧存储隔离、退役控件清除、换装与性别切换保持相位、三色与发色、保存恢复、搜索收藏、暂停逐帧、小屏布局。

源键、帧间中点、贯穿检测算法、数值容差与现有截图矩阵保持。测试失败仍上传诊断，报告明确失败。视频改为可选人工审查，不改变上述自动测试要求。
