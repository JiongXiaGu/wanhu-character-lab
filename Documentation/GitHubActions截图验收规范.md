# GitHub Actions验收 · 固定基模

仅在Actions runner启动本地Preview+Playwright并上传Artifact，不部署Visual/Vercel。agent-browser可用时先验证页面，不可用用仓库Playwright。必须下载并实际看图和连续时间采样；artifact生成/数值通过不是美术批准。

五条任务：Build；Character Model Review；Mixamo Retarget Review；Wardrobe Review；Tailoring V2 Review（工作流名称保留用于识别，测试契约已为固定V5）。

## 固定矩阵

两基模、单精度。删除已退役的身材端点和重复LOD组合，保留现有服装／动作维度。Character模型8基础组合、头脸、换装相位、移动端；衣柜8推荐×2固定男女与170部件组合；23FBX全源关键采样及源/目标多视角；坐姿拨动开关三样板男女正侧背五相位。慢跑、射箭、抓举和起步的源键及帧间中点贯穿算法/容差不变。

新增文件协议检查：V5往返、旧V4拒绝、未知/缺字段拒绝、错误导入不改变当前角色、旧存储键不读取、没有身高/体格/LOD控件、换装/性别切换保留相位、切动画复用网格。去掉参数不等于去掉坏文件防护。

截图脚本固定记录清单及完整数量；错误时仍上传诊断，但report必须passed=false。视频按动画完成或实际循环次数结束，不只等待固定墙钟秒数。compose脚本提取每秒4帧全时段，供人工检查，不替代原视频。

## 版本与美术边界

16份golden fixture采自main4740a5c旧LOD2，证明此次重构未改造型。它们不是永久人体冻结：后续修模需说明变更、升级资源版本、实际审图后显式更新，而不是自动刷新以掩盖失败。

髋裆分叉/偏薄/硬折是旧造型已知限制；不要把架构通过写成艺术修复。PR12深蹲失败补面不混入。未来修复仍须保留Snatch深蹲检查。

交付记录包含受测代码SHA、各run ID、图片/视频数量、实际查看范围、已知限制、最终mainSHA。仅文档提交可引用未变化的受测代码；任何运行代码改变都要重测。不得放宽阈值、跳失败或用DoubleSide隐藏。
