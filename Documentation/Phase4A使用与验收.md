# Phase 4A：第一轮劳动动作

## 使用

拉取main，双击 `Start-Local.cmd`。左侧顶部“劳动动作库”提供拾起木箱、放下木箱、抱箱行走、扛木行走、背柴行走、推独轮车、拉车行走、双手锄地、单手锤击。每项都有实际程序化道具。

拾放单次播放、结束停在最后姿势；“重播动作”重新执行。其他动作循环。支持暂停、变速、进度定位；定位不触发生产事件。

“握点检查”显示绿色目标点、金色实际掌心点。三视图、素模、布线和骨骼叠加继续可用。工作预览临时占用左右手/背部，但不改变Recipe V4；退出劳动回基础动作恢复原DIY。

## 保留的边界

人体510三角形、20骨骼、最多两非零权重。角色与道具全部运行时生成；Clip按当前绑定骨长采样，正常播放不逐帧IK或重建人体。

推拉/负重为原地动作，导航位移、按实际路程滚轮、生产资源变更、跨动作连续装卸状态机尚未接入。事件是可复用语义与调试记录，不是已经完成的游戏生产逻辑。

未加入通用运行时分层、Unity Crowd、布料、射箭或战斗。4B扩展劳动及连续物品生命周期，4C处理战斗与瞄准。视觉和算法测试不证明任意服装/姿势组合无自交。
