# Phase 4A：第一轮劳动动作

## 使用

拉取 main，双击 `Start-Local.cmd`。左侧顶部新增“劳动动作库”。点击动作即建立对应道具与预览姿态；下方保留待机、行走等基础动作，点击基础动作可退出劳动演示。

九项为：拾起木箱、放下木箱、抱箱行走、扛木行走、背柴行走、推独轮车、拉车行走、双手锄地、单手锤击。每项是实际模型与骨骼动画，不是占位按钮。

拾起与放下单次播放，完成后保持最后一帧。使用“重播动作”重新执行。其他动作循环。支持暂停、变速、拖动进度和重新定位；定位不触发劳动事件。

开启“握点检查”显示绿色目标点和金色实际手掌点。正面、侧面、背面、三视图、结构布线、骨骼叠加继续可用。角色和工作道具分别统计面数。

工作动作临时占用对应左右手或背部，不修改原始 DIY Recipe。例如弓手戴草帽推车时，弓暂时隐藏，回到待机后恢复；头饰和服装仍可编辑。

## 第一轮实际截图发现的问题

初版候选 `b4d3059` 的 Labor Action Review 为 `35421301244`，生成九项共90张动作图及额外界面图；旧 Character Visual Review 为 `35421301239`，两者自动检查成功。

人工逐项查看后仍发现需要修正之处：

- 拾放木箱的下蹲过深、双膝过分向两侧张开。改为较浅下蹲、髋部前倾、膝盖主要向前，保留箱侧握点与脚底接地。
- 木箱装饰木条比箱体略高，落地中心上移1厘米，避免木条埋地。
- 背柴从背面缺少清楚的捆扎。增加绕束两侧与背面的绑带，不增加人体骨骼。
- 结束停帧和暂停不能被当作 seek，否则会清除事件计数。UI 直接显示真实播放器进度，只有主动定位才重置事件游标。
- 道具握点集中为 `actions/anchors.ts`，明确手掌点、道具局部点和腕骨原点是不同概念。

这些修正需再次通过同一套截图与交互流程后才能合入。具体最终版本与运行结果以对应提交的 Actions 为准，不把上面的初版运行当成最终验收版本。

## 自动门槛

`npm run check:mesh` 保留原人体/衣服/步态检查。

`npm run check:actions` 检查9动作×3体型×61采样帧（1647帧）：实际骨骼矩阵还原掌心、握点误差、脚底、蒙皮三角面、循环首尾、单次终点、暂停/seek/跨帧事件、占槽不修改原配方、播放不重建人物 Mesh。

GitHub Actions `Labor Action Review` 为每项生成正/侧/背/结构线四图、六个关键帧；额外测试单次结束保持、事件不丢失、暂停、定位、混搭、体型端点和移动端。产物 `labor-actions-review` 内含 `review-actions/index.html`、截图、报告和测试日志。

截图数量不是美术通过的证明：每项都要打开查看，尤其拾放接触、独轮车把手、工具落点和变形关节。

## 本轮边界

角色沿用510三角形人体、20骨骼、每顶点最多两个非零权重。人体与动作道具仍全部运行时创建。工作 Clip 按当前绑定骨长采样，正常播放不用逐帧 IK 或重建人物网格。

推拉和负重行走为原地动画；游戏导航位移、按实际路程滚轮、生产资源变更、跨动作连续装卸状态机尚未接入。本轮事件是可复用语义与调试记录，不是已经完成游戏业务逻辑。

没有增加通用实时骨骼分层混合、Unity Crowd、布料、拉弓或战斗。下一轮4B扩展城市劳动与物品生命周期，4C再处理双手战斗和瞄准。
