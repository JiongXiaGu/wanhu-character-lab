# 服饰动作稳定性与 LOD · 第一批

## 用户确认的方向

玩家自定义优先；同一外观配方供城市居民取样。Web 只做人物外观、换装、动画试衣与数据验证，玩法由 Unity 实现。服饰偏写意，允许为稳定动画和群体性能简化版型；本批不增加实时布料、每帧碰撞、全身 IK、程序动作或服装骨骼。

用户特别要求 **Pilot Flips Switches（坐姿拨动开关）** 加入重点 review，与慢跑、射箭并列。原 FBX、时间曲线和骨骼校准不因衣服修改。没有导入椅子和操作台时，不宣称已经完成座椅接触或手柄交互。

## 本批范围

先改造劳动短装、日常分裳、礼仪袍装三个代表性轮廓，并让共用这些部件的推荐配方同步使用新结构。保持七槽位、跨身体混搭、染色、发式、旧配方导入与当前暂停相位。

- 袖口收束，取消原礼衣前臂过度放大，不改手掌/绑定。
- 下摆缩短，不拖地；裙裳有明确的前后开口，内衬裤装是可见设计部分，不是用缺腿补丁填缝。
- 上衣下摆和下装合成连续的同一衣面，用色区/有限缘边表达层次，避免两个独立壳体在同一位置互穿。
- 左右分裳不横跨焊接双腿；腰髋、大腿、膝、小腿使用相应身体骨骼的绑定权重。新增顶点最多两项非零权重，衣服不拥有单独 Animator。
- 优先保留完整连续内衬，取消上一批对长裳大腿/膝前的整区删除。只有某版型在受支持动作中确定不可见的部分，才可建立更细的离线遮挡配置；本批不以继续扩大隐藏身体范围来修补。

以上是制作约束，不是尚未运行测试时的完成声明。最终参数、运行版本及实际审查结果以本文件末尾的验收状态和对应 Actions 报告为准。

## LOD 第一批边界

提供 **LOD0 / LOD2 草案** 的手动试衣对照。LOD 是视图/生成选项，不写入玩家的 Recipe；切换必须保留衣服、颜色、体型和动画相位。

本批先简化服饰的褶面与采样，不改原男女连续 510 tris 人体、20 Bone ID/Parent Map，也不重烘焙一套动画。保留袖口、腰口、分裳开口和膝部结构行，不能为了减面重新焊死双腿。LOD2 必须生成真实减少三角形的网格，不是缩小人物或隐藏整个服装。

这只是服饰 LOD2 草案，尚不是全人物 250–450 tris 的最终 Crowd LOD。最终人体/头发/道具降面、LOD1、按屏幕占比自动切换、交叉渐变、GPU Crowd、剔除和性能结论留在后续批次。不得把仍保留完整基模的草案写成已完成万人优化。

迁移的几何缓存键包含服饰几何版本、内衬/遮挡版本、部件/体型与 LOD；染色目前仍写顶点色，Unity 参数染色和共享网格需要另外实现。动画键与服饰网格键分开；同一体型的两个 LOD 使用同一目标动画时间和骨架。

## 检查矩阵

保留原 Build / Character Model Review / Mixamo Retarget Review / Wardrobe Review，不更新男性 12 份基线来掩盖变化。新增独立 Tailoring Review：

1. 三个样板 × 男女 × 身材端点 × 两个 LOD 的数值、绕序、完整内衬、骨架/配方不变与真实减面检查。
2. 慢跑、射箭、坐姿拨开关的完整时间采样；相同时间检查新分裳与内衬，不把有限值当作没有穿模。
3. 默认体型三个样板、两个 LOD 的正侧背、素模、动作关键相位；身材端点补坐姿正侧视。
4. 三个样板男女各录制完整坐姿片段；礼仪男女另外录制慢跑/射箭。LOD 切换检查动作相位和配方保持。
5. 报告记录 sourceSha/testedSha、真实图片和视频列表、错误及通过状态。只在 Actions runner 本地 Preview，不部署任何站点。

必须下载同提交图像/视频实际查看后再声明视觉通过；出现明显常用动作穿插，修改版型或权重后重跑。极端翻转等实验片段仍保留压力测试，不宣称所有服饰已经适配所有姿态。
