# 模块化服装生成架构

Recipe V5 → patterns注册 → 独立衣裤裙鞋 → 作者接口封闭 → 固定皮肤覆盖 → 一个最终网格 → 同一套20骨骼。固定人体不负责服装轮廓，只在换装时装配；不逐帧碰撞求解或生成网格。

## 职责与数据所有权

patterns.ts注册8上衣与6下装的当前固定资产，提供专用资产ID、接口和低运动边界。assets/contract.ts定义GarmentPiece、覆盖区域、作者构造阶段的openings与交付的sealedInterfaces；服装几何版本wanhu-modular-garments-v9，覆盖契约wanhu-authored-coverage-v1。

tops.ts负责上衣分派；work-shirt、cross-shirt、half-sleeve、work-vest、short-jacket各自拥有衣身、领袖、门襟、色区与静态权重。top-seams只提供有限缝片操作，不能以统一宽度参数冒充新服饰。

trousers.ts负责下装分派；两种实用长裤的原闭裆操作提取到trouser-shell，数值和权重不变，宫卫只复用裤装内衬。short-bottoms只拥有封口短裤。旧authored-legs和分片裙裤路径已删除。skirts.ts独立制作连续短裙和素面长裙，不调用裤腿或源皮肤构造器。

seal-interfaces只在makeTop/makeTrousers创建资产时封闭作者声明的接口。复用原顶点及权重、验证边界绕序、选择无退化扇分根；不是扫描任意破洞的自动修模器。上衣Cap使用原主布primary，长裤与裙腰Cap使用原裤布/腰头secondary。已认可背心、短裤和布鞋不重复封闭、不重染。

两条真裙仍采用12段连续环、前后跨中线、固定厚裙边和12片简单封底，本轮只追加腰口封面。它们不是超宽裤腿、外贴片、内裤叠层或复杂里衬。所有权重一次写入，每顶点至多双权重，共享原骨架，不能新增裙装Animator或裙摆骨链。

footwear负责cloth_shoes并分派military/boots的独立军靴；双脚踝接口直接Cap，短靴boots已退役。assembly只按固定covers装配可见皮肤及服饰，并保留接口锚点，再剔除未引用顶点；不改源皮肤、不读取动作或临时删面。头饰不走GarmentPiece：adornments拥有包巾、方冠、玉簪和额带作者网格，v3/outfit保留草帽与轻盔入口，headwear-fit只在网格完成后做一次固定安全留量。正式头饰除none外也要求自身零开放边；详见《头饰闭合与安全留量.md》。

## 固定覆盖和闭合接口

| 类型 | 隐藏的源皮肤 | 必须保留 |
|---|---|---|
| 第一批劳作短衣 | torso、upperArm | forearm、手 |
| 交领常服／半臂内袖 | torso、upperArm、forearm | 手 |
| 背心／短褂 | torso | 原上臂、前臂、手 |
| 长裤 | pelvis、thigh、shin | foot由鞋决定 |
| 短裤／真短裙 | pelvis、thigh | 原shin；foot由鞋决定 |
| 素面长裙 | pelvis、thigh、shin | foot由鞋决定 |
| 鞋 | foot | 对应脚踝接口 |

女性使用既有固定映射一次。覆盖来自资产，不能写成“所有上衣遮上臂”“所有下装遮小腿”。封口使用衣料色，不把保留皮肤重染成衣服。

当前每件正式服装自身必须闭合：上衣领口、双袖窿/袖口及腰口；裤装腰口与双裤口；两条连续裙的腰口；布鞋双脚踝，均登记为sealedInterfaces，openings交付时为空。连续裙原closedHem另行保留。并不要求衣服、裤子与身体共享同一顶点环。

未声明破洞、重复面、非流形边/顶点、失效封口、坏权重和退化扇片均报错。不能通过重新声明opening放行破洞。退役裙裤不再参与运行时或回归。

## 制作接口与动作边界

身体或相邻服装可以从固定Cap处伸出，这是中远景遮挡简化，不是实体布料模拟。现有离线贯穿检测先计算原始交点，再将短裤Cuff与可见shin、连续裙HemCenter与末端裙边或可见shin的既有制作接触单列；不对全部Cap或衣服外表面整体豁免。既有算法、容差和源键/中点不变。

普通站立、行走、起步、轻跑、坐姿是裙装用途。stressOnlyClips仅对两条连续裙标明Snatch深蹲举重压力片段，源帧与中点仍全量检查；不是独立Animator或删除测试采样。极端开腿／高踢／翻滚不保证零穿插。

## 预算、染色与验证

男女原皮肤各524三角形，绑定和保护签名不刷新。当前宫卫上甲386、甲裙与裤装360、军靴120，作者规则见《皇宫禁卫与长枪》。原上衣work_vest128、short_work_jacket200、rough_tunic246、cross_jacket316、layered_vest366、ceremony_robe212、farmer_tunic164；下装short_trousers164、work_pants240、work_wrap240、true_short_skirt190、long_skirt262；cloth_shoes64。此次新增封面没有增加逻辑顶点。完整规则与表格集中于《服装Cap封闭实验.md》。

primary／secondary／accent仍作为面颜色进入缓存，染色不改坐标、拓扑、覆盖或权重。不存在外部DCC通用服装导入器、跨染色网格共享或GPU万人运行时。

原身体／绑定、源FBX、压力姿态、源键和中点检查继续保留；已退役服装不再为了维持历史数量继续执行。新增全目录封口、颜色、装配、漏面与错误颜色故障注入；连续裙保留连续性、原封底和左右色区检查。贯穿样本按当前正式下装目录计算，不降低检测容差。
