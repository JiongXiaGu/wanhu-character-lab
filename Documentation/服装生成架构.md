# 模块化服装生成架构

Recipe V5 → patterns注册 → 独立衣裤鞋 → 固定皮肤覆盖 → 一个最终网格 → 同一套20骨骼蒙皮。固定人体不负责服装轮廓；只在换装时装配，不每帧碰撞求解或生成。

## 职责与所有权

`patterns.ts`注册9种上衣和9种下装的固定资产与接口。款式有专用构造和制作数据，不用统一宽度参数冒充新服饰。`assets/contract.ts`定义GarmentPiece、覆盖区域和明确开口；几何版本为 `wanhu-modular-garments-v6`，覆盖契约为 `wanhu-authored-coverage-v1`。

`assets/tops.ts`只负责分派。第一批 `work-shirt.ts`、`cross-shirt.ts`、`half-sleeve.ts`分别制作劳作短衣、交领常服和半臂；第二批 `work-vest.ts`、`short-jacket.ts`分别制作真无袖背心和短袖短褂。旧轻甲、礼衣等保留自己的既有路径。`top-seams.ts`只提供有限缝片／接袖操作，衣身切线、领型、袖筒和双权重由各款明确给出，不读取动画。

`assets/trousers.ts`负责下装分派及既有固定腰臀、左右腿根和有限宽裆底。`authored-legs.ts`保留直筒与束脚两套长裤制作表；`short-bottoms.ts`制作短裤和A字分片短下裳，拥有自己的裤长、外侧褶面与下摆坐标。不是复制皮肤，也没有单点裆底、动作补壳或通用变形补偿。

`assets/footwear.ts`负责鞋及脚踝接口。`assembly.ts`只按明确覆盖表装配可见皮肤和各部件，再剔除未引用顶点；不修改源皮肤，不按动画删面。`adornments.ts`负责冠髻；`headwear-fit.ts`在男女映射前对帽饰顶点执行一次固定制作留量，不读取发型或动画。

`v3/outfit.ts`负责脸、发饰和工具总装配。第一批领缘属于上衣自身的共享边色区，不再叠加旧CrossCollar／InnerCollar浮动条。旧轻甲等保留自身装饰。

## 覆盖与接口

覆盖来自服装资产，不由槽位一概决定；不能把“所有上衣都隐藏上臂”或“所有下装都隐藏小腿”写成通用规则。

| 资产类型 | 隐藏的源皮肤区域 | 必须保留 |
|---|---|---|
| 第一批劳作短衣 | torso、upperArm | forearm、手 |
| 交领常服／半臂长内袖 | torso、upperArm、forearm | 手 |
| 第二批背心／短褂 | torso | upperArm、forearm、手 |
| 既有长裤 | pelvis、thigh、shin | 由鞋独立决定foot |
| 第二批短裤／短下裳 | pelvis、thigh | shin；foot仍由鞋决定 |
| 鞋 | foot | 裤脚／脚踝接口依各资产声明 |

第二批短袖在可见上臂外侧包裹，不因此隐藏整条上臂；短下摆与源膝上边界固定重叠，保留原小腿。女性使用既有固定制作映射一次，不新增连续体型适配器。

上衣允许腰、领、双袖窿／袖口四处开口；裤装允许腰与两裤口；鞋允许两脚踝。未声明开口、重复面、非流形、坏权重或失效接口必须报错。裙裤中间是完整裆底与两条独立分片结构，不是裸露破洞。

## 资产差异与简化边界

第一批三上衣拥有不同衣长、门襟、袖型和层次。半臂通过外袖缘→内缩环→内袖连续连接，省略被遮住的内层，不新增内衬装备槽。

第二批背心是真无袖；短褂只到上臂。短裤露出膝下皮肤；短下裳利用外侧展开与前后褶面形成A字轮廓，但本质仍是可独立随两腿运动的分片裙裤，不宣称连续软布短裙。普通低模折面不触发人体重建。

帽子采用固定偏大的包覆轮廓。保留既有戴包覆帽隐藏额外发髻、取帽恢复同一发型的规则；源头皮／头发体积没有为帽子缩小。额前束带后侧统一开放以避开低髻，方冠横翼移到后壳；不是每种发型一套适配。簪饰维持插簪关系。

三色作为face.color进入最终网格，染色不改坐标、拓扑或静态权重。未实现外部DCC衣服通用导入器、跨染色网格缓存或GPU万人实例化。

## 检查与预算

男女源皮肤均524三角形；固定绑定与受保护皮肤签名不刷新。第一批上衣220／290／340、长裤272／304三角形；其余五款旧长裤220。第二批上衣102／174、短下装144／176三角形。具体完整角色计数与逻辑顶点见《轻便服饰与头饰安全留量.md》。

原身体／绑定、故障注入、服饰组合、全部FBX、源帧与中点检查保留并扩展。新短裤没有旧长裤的膝下三圈结构，使用独立下摆／露肤契约；旧七款长裤仍执行原膝结构检查，新下装同时进入原贯穿循环。不能把短装结构差异变成动画或贯穿豁免。

六项正式Actions保留，第二批加入Modular而不删除第一批或旧形变矩阵。衣柜新增推荐后按目录计算177张证据并保留原143张及旧8套搭配下限。自动成功不等于人工美术签署，真实SHA、run及实际查看范围见《工作交接.md》。
