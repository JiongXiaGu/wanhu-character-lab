# 服装生成架构 · V3

## 当前实现

当前使用同一个连续人体、Skeleton 和 SkinBinding 体系生成：

- 农户
- 卫兵
- 弓手

当前衣服不使用实时 Cloth Simulation。

短衣、裤子、绑腿和轻甲轮廓主要采用 BodyDerived.Replace：

- 直接改变覆盖区域可见轮廓与颜色
- 不在同一位置保留完整裸体表面

领口、腰带等为少量附加面。

帽子、剑盾、弓、箭袋、农具属于 Rigid / Limited Attachment。

## Slot Recipe

当前正式槽位：

| Slot | 当前可选内容 |
| --- | --- |
| Headwear | none / farmer_straw_hat / guard_helmet / archer_headband |
| Top | body / farmer_tunic / guard_light_armor / archer_tunic |
| Bottom | body / work_pants / guard_pants / archer_pants |
| Shoes | body / cloth_shoes / boots |
| Back | none / archer_quiver |
| LeftHand | none / guard_shield / archer_bow |
| RightHand | none / farmer_hoe / guard_sword |

“农户 / 卫兵 / 弓手”只是默认组合，不是兼容性限制。

修改任意槽位后 Recipe.preset = custom。不同职业来源的部件允许混搭，只要使用相同 SkeletonDefinition 和合法 Bone Policy。

当前已经通过浏览器和生成器回归验证“弓手 + 农户草帽 + 箭袋 + 短弓”。

后续增加服饰时先扩展对应 Slot ID / Definition，不增加新的职业 if/else 总开关。

## Skeleton 约束

服装不得拥有一套与人体不同的 Bone ID 语义。

Body、Garment、Armor、Hat、Equipment 必须引用同一 SkeletonDefinition。

当前固定 20 Bone Skeleton。

BodyDerived Garment：

- 继承身体对应权重
- 普通区域尽量 1 Bone
- 关节最多 2 Bone Blend

Rigid Attachment：

- Headwear → Head
- Hand Props → Hand
- Quiver / Back Item → Chest / Back 相关 Bone

Independent Silhouette Garment 以后也默认复用现有人体 Bone。

只有明确需要时才增加少量 Garment Helper Bones。

## GPU 动画关系

服装不参与独立动画求解。

Unity Crowd 目标仍然是一份 ResidentAnimationState：

~~~text
ClipId
Phase
Speed
~~~

GPU 根据同一 Bone Transform 同时驱动：

- Body
- Clothes
- Armor
- Attached Skinned Parts

Rigid Attachment 直接跟随 Bone Transform。

不要给衣服建立独立 Animator。

## 后续分类

- Material Only
- BodyDerived.Replace
- BodyDerived.Offset
- Independent Silhouette
- Rigid Attachment

长袍、宽袖、裙摆优先：

~~~text
Skeleton Driven
→ Shader Sway
→ 少量 Helper Bones
→ 最后才考虑 Cloth
~~~

大量城市居民默认不做 Cloth Simulation。

## Body Hide

后续通用 Body Hide 必须基于版本化 Face Group / Mask 生成最终 Index。

不能只在 Renderer 层把完整裸体和完整衣服一起画出来。

Body Hide 目标：

- 降低 Triangle
- 降低 Skinning 顶点
- 降低 Overdraw
- 减少穿模

## 面数

按最终可见角色统计：

- 默认农户：675 tris
- 农户 + 农具：699 tris
- 卫兵 + 剑盾：806 tris
- 弓手 + 弓箭袋：805 tris

这些数值不替代 Unity GPU / CPU Profile。

## 制作与审查

服装内容保存 Recipe、轮廓规则、覆盖区和 Bone Policy，不要求每个身材制作独立 FBX。

扩展服装前先检查：

- Front / Side / Back
- Structure Cage
- Arm Raise
- Elbow Bend
- Walk
- Squat
- 体型端点
- Body Hide
- GPU Animation Weight 兼容性

详细动画数据契约见 GPU骨骼动画迁移契约.md。
