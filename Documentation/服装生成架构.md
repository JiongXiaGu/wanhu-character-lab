# 模块化服装生成架构

Recipe V5 → patterns注册 → 独立衣裤裙鞋 → 固定皮肤覆盖 → 一个最终网格 → 同一套20骨骼。固定人体不负责服装轮廓，只在换装时装配；不逐帧碰撞求解或生成网格。

## 职责与数据所有权

patterns.ts注册7上衣与5下装的当前固定资产，提供专用资产ID、接口和低运动边界。assets/contract.ts定义GarmentPiece、覆盖区域、真实openings与sealedInterfaces；服装几何版本wanhu-modular-garments-v8，覆盖契约wanhu-authored-coverage-v1。

tops.ts负责上衣分派；work-shirt、cross-shirt、half-sleeve、work-vest、short-jacket各自拥有衣身、领袖、门襟、色区与静态权重。top-seams只提供有限缝片操作，不能以统一宽度参数冒充新服饰。

trousers.ts负责两种实用长裤及下装分派；short-bottoms只拥有封口短裤。旧authored-legs和分片裙裤路径已删除。skirts.ts独立制作连续短裙和素面长裙，不调用裤腿或源皮肤构造器。

两条真裙采用12段连续环、前后跨中线、固定厚裙边和12片简单封底。它们不是超宽裤腿、外贴片、内裤叠层或复杂里衬。所有权重一次写入，每顶点至多双权重，共享原骨架，不能新增裙装Animator或裙摆骨链。

footwear当前只负责cloth_shoes；双脚踝接口直接Cap，短靴boots已退役。assembly只按固定covers装配可见皮肤及服饰，并同时保留openings/sealedInterfaces锚点，再剔除未引用顶点；不改源皮肤，不读取动作或临时删面。本轮没有修改assembly。v3/outfit负责脸、发饰与工具总装配，本轮未改。adornments／headwear-fit维持第二批冠髻与一次性帽壳留量，不为裙装顺手改发型。

## 固定覆盖和开口

| 类型 | 隐藏的源皮肤 | 必须保留 |
|---|---|---|
| 第一批劳作短衣 | torso、upperArm | forearm、手 |
| 交领常服／半臂内袖 | torso、upperArm、forearm | 手 |
| 背心／短褂 | torso | 原上臂、前臂、手 |
| 长裤 | pelvis、thigh、shin | foot由鞋决定 |
| 短裤／真短裙 | pelvis、thigh | 原shin；foot由鞋决定 |
| 素面长裙 | pelvis、thigh、shin | foot由鞋决定 |
| 鞋 | foot | 对应脚踝接口 |

短裙外缘与源膝上边界固定衔接；长裙不恢复内部腿部绘制。女性使用既有固定映射一次。覆盖来自资产，不能写成“所有上衣遮上臂”“所有下装遮小腿”。

普通资产仍以openings声明真实边界。Cap试验资产则把接口环移入sealedInterfaces：work_vest封住腰、领和双袖窿，short_trousers封住腰和双裤脚，cloth_shoes封住双脚踝；这些环仍作为换装/审查锚点，但不再产生boundary edge。连续裙原有closedHem规则不变。未声明破洞、重复面、非流形、坏权重仍报错。退役裙裤不再参与运行时或回归。

## 制作接口与动作边界

short_trousers试验已移除CuffInset厚断面，直接用现有8点Cuff封面，腰口也直接封面；小腿和上身穿过这些不可见Cap。只有裤脚Cap×可见shin被离线相交检查窄范围分类为合法制作接口，腰口Cap及裤身没有额外豁免。真裙固定封底与腿出口／末端裙边的数学接触仍属于原专门制作接口；离线检查先计算全部原始交点，再由garment-contact-scope.ts窄范围分类，报告保留原始与分类计数。该脚本不进入运行时，不执行碰撞修正。

只有两个新裙子的HemCenter扇面与末端Hem/HemInset/HemFacing或皮肤shin可列为接口。Calf、腰臀、裙身、上衣、大腿及任何旧服装不豁免。普通动作其他穿插继续阻塞。stressOnlyClips仅对新裙装标明Snatch深蹲举重压力片段，源帧与中点仍全量检查；它不是独立Animator或测试采样删除开关。

普通站立、行走、起步、轻跑、坐姿是裙装用途，极端开腿／高踢／翻滚不保证零穿插。完整制作细节见《短裤封边与连续裙装.md》。

## 预算、染色与验证

男女原皮肤各524三角形，绑定和保护签名不刷新。当前保留的三件独立制作上衣rough_tunic／cross_jacket／layered_vest为220／290／340三角形；work_pants与work_wrap各220；work_vest128、short_trousers164、cloth_shoes64；真短裙180、长裙252。short_trousers为84逻辑顶点。

primary／secondary／accent仍作为面颜色进入缓存，染色不改坐标、拓扑、覆盖或权重。不存在外部DCC通用服装导入器、跨染色网格共享或GPU万人运行时。

原身体／绑定、源FBX、压力姿态、源键和中点检查继续保留；已退役服装不再为了维持历史数量而继续执行。连续裙仍检查连续性、封底、左右色区与接口分类故障注入。贯穿样本按当前正式下装目录动态计算，不降低检测容差。

六条正式Actions保持；新裙装并行job追加到Modular，原compare和两批矩阵不减少。自动检查、真实图片生成与实际人工查看必须分别记录，具体SHA、run和抽查范围见《工作交接.md》。
