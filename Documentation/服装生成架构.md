# 服装生成架构 · 衣冠工坊 V1

## 职责

Web 专注角色自定义。`src/character/wardrobe/catalog.ts` 保存写意搭配、部件标签、染色、确定性随机和严格导入；`src/character/wardrobe/geometry.ts` 保存新服饰/头饰/发髻几何。`v3/outfit.ts` 仍统一组合 Body/Slots；不新增按身份切换的完整人物生成器。

## 部件与配方

保留 Recipe version=4、男女比例及 7 槽位。新增：

| 槽位 | 新 ID |
| --- | --- |
| top | rough_tunic / cross_jacket / layered_vest / ceremony_robe |
| bottom | loose_trousers / work_wrap / pleated_skirt / robe_skirt |
| headwear | cloth_wrap / scholar_cap / jade_pin |

原有部件全部保留。三种新发髻为 topknot / low_bun / double_bun，auto 保留身体默认。可选 dyes={primary,secondary,accent} 与 hairColor 为六位十六进制颜色。旧配方省略扩展时不改变原几何与颜色。

八套推荐是槽位、染色、发式的组合，不是新职业 enum。应用推荐保留 bodyType/height/build/hairColor；任何身体均能选全部款式。随机只在推荐轮廓基础上取样并变色/头饰，保留锁定项；不代表全部笛卡尔积组合已经视觉验收。

## 几何与绑定

身体保持连续封闭的 510 tris / 257 顶点基模和原权重。BodyDerived.Replace 改变可见衣面颜色/局部轮廓，不同时画一份完整裸体。

短衣/裤装沿原身体环扩形。新增长袖只扩到肘和前臂，不扩大 Wrist 共边，避免把手掌一起撑大。

裙裳使用左右独立、有厚度的外/内壁与缘边，骨盆/单侧大腿最多两骨混合。`pleated_skirt`、`robe_skirt` 的前后中线采用有深度间隔的搭接边，不再把两片中间的贯通细缝当成褶裙；左右片仍独立随腿运动，不将双腿焊进一个裙筒。上衣下摆和劳作短围裳保留开衩。

不同摆长共用按高度定义的权重和采样行；外层考虑褶面最大半径，保持层间距。被上层遮挡的下层不重复生成，接口保留 3.5cm 搭接。当前 `GARMENT_GEOMETRY_VERSION=wanhu-garment-geometry-v3`；迁移端几何缓存必须包含此版本。

## 服饰遮挡

`BODY_HIDE_VERSION=wanhu-garment-hide-v2`。只过滤最终服饰表面 `surface.faces`，不删除源 `body` 的拓扑、顶点、权重或骨架。

- 短围裳与长裳都替换 pelvis 区域的原可见面。
- 褶裙/长裳另外隐藏被覆盖的大腿、膝与上段小腿裤面，防止慢跑时裤腿从裙面穿出；以稳定 region 与 Calf/Ankle 锚点识别，不根据变形后的世界高度临时裁切。
- 两侧 Calf→Ankle 裤脚及足部继续可见。穿回裤装时由同一源人体重新生成，腿部可见面自动完整恢复。

这是固定版型的遮挡表，不是任意衣物的通用 BodyHide/碰撞系统。大幅抬腿、翻转、贴地动作仍可能使裙片张开、衣层互穿或暴露遮挡边界；不宣称布料仿真或所有姿态无穿插。新衣轮廓/色区直接生成最终网格，缘边有限附加面；禁止用 DoubleSide、共面补片或修改 FBX 掩盖问题。

刚性帽冠/簪/道具引用现有 Head/Hand/Chest，通过源目标骨锚点变换，不把身体非线性比例场逐点套到工具上。新发髻替换默认髻，帽冠遮蔽时保留 Recipe，取下恢复。原 auto 女性低髻的旧遮蔽行为不变。

## 预算与 GPU

固定 20 骨骼、每顶点最多 2 非零权重、单 SkinnedMesh。新增组合检查预算为 <2600 tris；实际三角形与渲染拆点以对应 Actions numeric.json 逐行记录为准。旧男性 12 份哈希保持，不自动刷新。

衣服不拥有 Animator，不独立求解动作。动态 FBX 播放复用几何；换配方才重建。当前颜色烘焙到顶点色，因此仅颜色不同也会导致不同网格输出；Unity 如要共享网格，需要把染色区域编码为参数/掩码再实例化，并单独验证，不能直接宣称当前染色方案已批量渲染最优。

缓存区分骨架/体型绑定、几何部件、色区和动画轨道：发型/服饰改变网格不改变骨架；height/build/bodyType 改变绑定，不能无验证共用最终骨矩阵。所有 key 需含相应生成器与掩码版本。详见 GPU骨骼动画迁移契约.md。

## 验收与限制

保留原角色回归，增加男女×8搭配×3身材、全部上下装组合、头饰×发式，以及11 FBX关键时刻的顶点有限值检查。`check:wardrobe` 独立检查最终体型网格前后各行的搭接跨度及内外壁间距、源人体未变、外露裤脚保留和脱裙恢复。报告记录 geometryVersion/bodyHideVersion/wrapEdgesChecked/coveredLegCases，不用同一个生成公式自证正确。

浏览器看正侧背、素模、布线、两端身材和长摆慢跑/射箭连续视频；随机锁定、配方导出重入和旧链接同样验收。数值和绕序通过不代表无自交，最终截图必须下载并实际查看。

不包含实时 Cloth、Shader Sway、Helper Bones、完整宫廷/官服考据、装扮影响职业的玩法。图标是 SVG 示意；Actions WebGL 截图才是模型效果。流程和下一批见玩家角色自定义与服饰分期.md。
