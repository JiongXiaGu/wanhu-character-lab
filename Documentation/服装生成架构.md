# 固定基模服饰架构

catalog.ts管理推荐、随机、严格文件入口；patterns.ts保存固定版型美术数据；tailoring.ts生成连续衣面；geometry.ts负责染色、冠髻；v3/outfit.ts装配。只有一种标准精度，不再接收lod参数。

TOP_PATTERNS含4种上衣的下摆、袖面色区和袖口；BOTTOM_PATTERNS含4种下装的款式、衣长和外侧放量。它们是已制作资源，不是玩家体型滑条。当前PATTERN_VERSION=wanhu-authored-patterns-v1；几何wanhu-fixed-garments-v1。

当前身体表面克隆成一层连续裤式分裳，不同时画完整内裤和独立裙壳，不整段删腿，不用DoubleSide。髋膝褶窝为固定制作数据；没有每帧碰撞/布料/形变求解。后续不同服装允许独立拓扑和权重，但需遵守骨架与接缝规范，不要求所有服饰必须同一网格。

两套固定基模、各自固定绑定，20骨骼、每顶点最多2非零权重。基模拓扑不是永久冻结，修模时明确升级版本并验收。当前重构只证明原LOD2输出不变，不声称改善髋裆观感。

上衣／下装／鞋／头饰可独立选，领袖腰带归入款式；连身服装可后续采用占位组合规则，本轮未新增。衣服不按性别/职业锁定。帽冠对发髻采用显式覆盖，非动态变形。

缓存键应包含基模ID及版本、服装版型/几何版本、slots与颜色/发式。当前顶点色仍烘焙入网格，不能宣称跨颜色共享网格已实现。无需再按连续height/build/LOD缓存。服装共享基模骨架，无独立Animator。

验收：标准男女16推荐配置、170部件组合、主衣面闭合、双权重/绕序、全FBX加载和重点动作源帧/中点贯穿检查。数值检查不覆盖一切共享顶点反折，仍需实际多视图及连续视频。衣柜丰富度优先于复杂求解器。
