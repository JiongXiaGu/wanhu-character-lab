# 模块化服装 · 独立衣裤第一批

## 当前路线

2026-09-20 用户批准：服装负责最终外观，固定人体提供骨架、比例与裸露皮肤。不再把修完裸模裆部作为衣柜开发前置条件。可清理旧代码/资源，不维护两套服装框架。

Recipe V5 → 固定版型注册 → 独立上衣/裤装/鞋 → 显式皮肤覆盖 → 部件合并 → 同一套20骨骼蒙皮。衣服在换装时装配，不在每帧生成、碰撞求解或调整源动作。

## 职责

- `patterns.ts`：7种现有上衣、7种现有下装的固定制作参数与资源ID；无连续体型参数。
- `assets/contract.ts`：服装部件、覆盖区域、明确开口和资源版本契约。
- `assets/tops.ts`：独立短袖/长袖衣面，含腰带色区和袖口，不从人体复制衣面。
- `assets/trousers.ts`：腰臀、两条裤腿和四片有宽度的裆底连接；不共用旧人体的单个裆点，不调用旧压缩补偿。
- `assets/footwear.ts`：独立鞋面和固定脚踝接口。
- `assembly.ts`：只对被服装完整覆盖的皮肤区域删面；装配完成移除未使用顶点，保留部件来源、接口与覆盖清单。
- `adornments.ts`：冠帽和发髻；`v3/outfit.ts`负责脸部、领缘与随身附件装配。

几何版本 `wanhu-modular-garments-v2`，版型 `wanhu-authored-patterns-v2`，覆盖 `wanhu-authored-coverage-v1`。不存在旧 `tailoring.ts` / `styleGarmentSurface` 路线和回退开关。

## 制作与组合边界

当前独立网格由固定制作空间中的专用构造器生成，再沿既有两个固定基模映射装配。这是小型正式服装资产契约，不是通用体型/布料公式；也不是已经完成的 Blender/FBX/glTF 衣服导入器。需要不同拓扑时新增专用服装资产，而非向人体生成器追加补偿。

首批重点是短衣、长袖交领衣、直裤和简化阔裤。现有农户、卫兵、弓手及V5资产ID保留并接入同一条新路径，不是旧协议兼容。礼衣/分裳暂采用适合动画的短衣与裤式轮廓，不冒充完整宫装或真实垂坠长裙。衣柜进一步丰富属于后续制作。

同款跨男女可穿，固定女基模仍使用既有制作映射；尚未从外部美术工具导入男女各一份独立源文件。后续可在资产注册中提供两份制作好的网格，不恢复连续体型适配器。

## 覆盖与开口

裤装替换 pelvis/thigh/shin 皮肤；上衣替换 torso/upperArm，长袖另替换 forearm；鞋替换 foot。裸露头颈、手及短袖前臂保留。此规则由所选资产确定，与动作相位无关；脱衣恢复皮肤，不永久改动源人体。

上衣声明腰口、领口和两袖口；裤装声明腰口和两裤脚；鞋声明两脚踝。任何未声明开口（尤其裆底）、重复面、非流形或坏权重均失败。开口不是任意删面的许可证。腰/袖/脚踝采用制作好的重叠区，仍需实际动作截图检查露空。

当前顶点色仍烘焙进最终网格。一个角色一个蒙皮渲染网格和骨架；不宣称跨染色网格缓存、GPU实例化或万人性能已实现。

## 验收

原人体与绑定的16组哈希保持；原人体复制衣面的表面哈希已明确退役，不用自动刷新旧哈希掩盖改造。新增32项部件检查、128种上下装覆盖组合、4种检测器破坏性反例；170组合、全FBX加载/姿态检查保留。

贯穿检测扩展为全部7种裤装 × 两个基模 × 坐姿/射箭/慢跑/深蹲/起步，沿用原几何判定、源键和帧间中点。没有放宽阈值、修改FBX或删除Snatch。截图检查独立裤子与上衣组合、正侧背、多相位、浅色、无光照/线框及同相机前后对照；视频不录制，但原播放结束/循环检查仍执行。数值通过不等于全部连续姿态无穿插或最终美术通过。
