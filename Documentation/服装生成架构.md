# 模块化服装 · 第一批独立制作资产

Recipe V5 → patterns注册 → 独立衣裤鞋 → 固定皮肤覆盖 → 一个最终网格 → 同一套20骨骼蒙皮。固定人体不负责服装轮廓；只在换装时装配，不每帧碰撞求解或生成。

## 职责

- `patterns.ts`：7上衣/7下装的资产注册与接口尺寸；第一批使用asset判别项，不保留假装控制它们的旧宽度参数。
- `assets/contract.ts`：GarmentPiece、覆盖、明确开口；几何`wanhu-modular-garments-v5`，版型`wanhu-authored-patterns-v3`，覆盖`wanhu-authored-coverage-v1`。
- `assets/tops.ts`：注册分派及四种既有短衣/轻甲/礼衣路径。`work-shirt.ts` / `cross-shirt.ts` / `half-sleeve.ts` 分别制作劳作短衣、交领常服、半臂配内衬。
- `assets/top-seams.ts`：有限缝片/接袖操作。各款自己给出制作空间坐标、前襟切线、袖筒拓扑和静态权重；不读取人体或动画。
- `assets/trousers.ts`：固定腰臀、左右腿根和有限宽裆底；`authored-legs.ts` 提供直筒与束脚两套明确的裤腿制作表。不是复制皮肤；没有单点裆底、动作补壳或通用变形补偿。
- `assets/footwear.ts`：鞋及脚踝接口；`assembly.ts` 只做显式覆盖和装配/压缩未引用顶点；`adornments.ts` 只处理冠帽和发髻。
- `v3/outfit.ts`：脸、发饰、工具总装配。第一批领缘已属于上衣网格，不再叠加旧CrossCollar/InnerCollar条；旧轻甲等保留自身装饰。

## 制作边界

三上衣有独立衣长、肩线、门襟、袖型与层次。半臂用外袖缘→内缩环→内袖的连续网格，省略不可见内层，不新增装备槽位。两裤装只在衣服上留量、收腿、做裤脚环；不改裸模。原其他ID与职业推荐保留，不将简化礼衣/裤式分裳宣称为完整宫装长裙。

女性使用既有固定制作映射一次，非连续体型适配器；同款男女都穿。未实现外部DCC/glTF/FBX衣服通用导入器。三色作为face.color进入最终网格；不宣称跨染色网格缓存或GPU万人实例化已经实现。

## 覆盖与接口

短上衣覆盖torso/upperArm，长袖和半臂另覆盖forearm；裤装覆盖pelvis/thigh/shin；鞋覆盖foot。头颈/手/短袖前臂保留。覆盖不依赖动作；穿脱不污染源皮肤。

上衣只允许腰、领、双袖四开口；裤装只允许腰与两裤脚；鞋只允许两脚踝。未声明开口、重复面、非流形、坏权重和失效接口全部失败。边界连续并不自动证明所有动画无接触/贯穿，仍须实际看图。

## 检查与预算

基础皮肤524tris、固定绑定和受保护皮肤签名保持，不刷新哈希。第一批上衣220/290/340tris，下装272/304tris；其他裤装220tris。检查声明这两项有意面数变化，原膝权重/压力姿态/所有源键与中点检测及错误注入保留。

原32独立部件、128覆盖组合、170衣柜组合和全部FBX检查继续；新增第一批12混搭、染色不改拓扑、真实半臂缩进和轮廓差异反例。六项正式Actions保留，新截图矩阵并入Modular，不另造第七条永久流程。详情和证据边界见《服饰第一批制作与验收.md》。
