# 头饰闭合与安全留量

## 目标

当前角色以低模、中远景为主。头饰采用与服装Cap相同的生产原则：优先保证正常镜头看不到帽壳内部或背景，不追求真实帽内结构，也不要求帽子与头发／头皮焊接为同一网格。

头饰仍全部绑定Head骨骼，固定留量只在制作完成后一次应用，不读取动画、不按发型逐帧拟合。

## 当前正式头饰

| ID | 类型 | 闭合方式 |
|---|---|---|
| farmer_straw_hat | Shell | 原有草帽外壳与内底已闭合，不改 |
| guard_helmet | Shell | HelmetBrim复用原8点环加同盔身色底盖 |
| cloth_wrap | Shell | WardrobeCapBase复用原8点环加同帽身色底盖 |
| scholar_cap | Shell | WardrobeCapBase复用原8点环加同帽身色底盖 |
| archer_headband | Band | 保持前额局部造型，改为有内外表面、上下沿和端面的封闭薄实体 |
| jade_pin | Ornament | 两个solidBox分量原本已闭合，不改 |

none不生成几何。

## 拓扑契约

除none外，每个正式头饰的自身几何必须满足：

- Boundary Edge = 0。
- 每条边恰有两个邻接面，不允许非流形边。
- 不允许退化三角扇片。
- 不允许未使用的头饰顶点。
- 所有头饰顶点保持 `[Head, Head, 1]` 刚性权重。
- 固定留量只改变坐标，不改变拓扑。

Shell必须有封闭底盖；Band不要求绕完整后脑一圈，但它自身必须是封闭实体；Ornament的每个独立实体都必须闭合。

## 帽底与头发的制作接触

guard_helmet、cloth_wrap、scholar_cap的底盖允许头部／主头发从中穿过。这是固定的中远景遮挡接口，不代表放宽全部帽发穿插。

允许：

- HelmetBrim底盖 × 主头发。
- WardrobeCapBase底盖 × 主头发。

仍然禁止：

- 帽侧 × 主头发。
- 帽顶 × 主头发。
- 额带外壳 × 主头发。
- 任意未声明的帽饰穿插。

现有帽壳留量与包围检查继续保留，只有明确的底盖三角形从普通帽发贯穿失败中单列。

## 颜色

新增底盖必须使用所属帽身颜色，不使用肤色、不新增内衬色：

- guard_helmet底盖：`#66716c`，与盔身一致。
- cloth_wrap底盖：与包巾主体 `tone(primary, .78)` 一致。
- scholar_cap底盖：`#303d42`，与方冠主体一致。
- archer_headband封闭薄实体全部继续使用 `#a48760`。

草帽原有深色内底与玉簪配色保持。

## 检查

`check:lightwear`覆盖男女 × 三种发型 × 六个实体头饰，共36种组合。检查头饰零开放边、面数预算、刚性权重、同色帽底、帽发非底盖贯穿、摘帽恢复原发型。

故障注入至少包括：

- 每个头饰删除一个面必须失败。
- 三种Shell帽底改成肤色必须失败。
- 轻盔缩小到会穿头发时必须失败。

这些数值检查不等于视觉验收。正常游戏距离下帽底是否显得突兀、额带厚度是否合适，仍由用户实际查看。
