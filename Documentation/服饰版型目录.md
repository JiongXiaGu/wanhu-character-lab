# 服饰版型目录

本页说明“如何检索当前已经有什么轮廓、下一批还缺什么”。运行时合法 ID 仍以 `src/character/v3/types.ts` 为准；当前可穿戴部件的版型检索权威是 `src/character/wardrobe/taxonomy.ts`。不要在本文复制每件资产的实现参数，也不要从历史文档恢复已退役 ID。

## 目的

衣冠工坊继续以自由换装为核心。皇帝、皇后、宫女、太监、官员、居民和军人都不是新的 Recipe 身份字段，也不把某件服饰锁死给某个职业。版型目录只回答三件事：

1. 当前资产属于什么轮廓；
2. 它与相邻资产靠什么视觉特征区分；
3. 某个场景还缺哪一种轮廓。

这样新增服饰前可以先查目录，避免把同一种短衣、长裤或军盔换名换色后再次制作。

## 当前目录

当前代码登记可穿戴部件共 42 件，不含 `none` 与裸身 `body`。C1、C2 已分别由 PR #72、#73 合入 main；C1 用户基本接受，不主动返工。C3 新增独立正式官帽，其检查、审图与主分支交付状态见工作交接，不把代码登记等同于用户美术认可。

| 槽位 | 数量 | 当前主要覆盖 |
|---|---:|---|
| 头饰 | 19 | 包巾、方冠、正式官帽、簪饰、草帽、轻盔、三驻地普通/队长盔、三驻地重盔 |
| 上装 | 12 | 背心、短褂、劳作短衣、交领常服、半臂叠穿、短身礼衣、窄袖直身长袍、宫女短襦、轻/中/重甲 |
| 下装 | 9 | 直裤、束脚裤、短裤、短裙、素面长裙、宫女高腰长裙、军裤、中/重甲长围裳 |
| 鞋履 | 2 | 日常布鞋、短筒军靴 |

每条 `WARDROBE_TAXONOMY` 至少登记：

- `slot`：头饰／上装／下装／鞋履；
- `family`：轮廓族，不是职业；
- `silhouette`：远景剪影类型；
- `length`：主要覆盖长度；
- `layer`：基础层／中层／外层等；
- `formality`：劳作、日常、正式、礼仪或军用；
- 上装额外记录 `sleeve` 与 `neckline`；
- `contexts`：方便查“宫廷、官署、劳作、军人”等使用场景；
- `visualTraits`：必须能说明它和相邻款式为何不是换色重复。

`contexts` 只是检索标签。例如 `jade_pin` 可以带“宫廷候选”，但玩家仍可把它与任意兼容服装混搭。

### C3 官帽覆盖的细分缺口

`official_winged_cap` 补足原方冠未覆盖的“横向长薄翅＋近直立方圆帽身＋前低后高屋面”。它不是给 `scholar_cap` 换色或只加长原横条；以帽翅与帽身侧壁两个独立维度比较。详见《正式官帽》。这一已实现帽型不再新增为待制作 gap，也不代表官员袍服或内侍帽已经完成。

## 当前主要缺口

`WARDROBE_GAPS` 只登记真实轮廓空缺，不预注册运行时服饰 ID。C1 提供窄袖长袍，C2 提供基础宫廷日常高腰裙，C3 提供正式官帽。当前九项剩余缺口如下：

| 缺口 | 槽位 | 主要服务场景 | 与现有资产的边界 |
|---|---|---|---|
| 宽袖礼服长袍 | 上装 | 皇帝、皇后、高等级礼仪 | `ceremony_robe` 仍是短身礼衣，不能只加宽袖口 |
| 多层宫廷外服 | 上装 | 皇后、高级宫廷女性、高级官员 | `layered_vest` 只有半臂叠穿，覆盖和体量不足 |
| 高等级宽摆或多层礼裙（C8/C11） | 下装 | 皇后、高等级宫廷礼仪 | C2 已有基础宫廷高腰裙，但不包含宽摆高体量或多层礼裙 |
| 官员袍服 | 上装 | 官员、官署 | C3 官帽可与 C1 混搭；专门的规整宽松官袍仍是独立缺口 |
| 皇帝冠饰 | 头饰 | 皇帝 | 方冠、横向官帽和军盔都不能建立皇室纵向高冠轮廓 |
| 皇后大型头饰 | 头饰 | 皇后 | 单一簪饰体量不足 |
| 宫廷内侍帽冠 | 头饰 | 太监、内侍 | 应紧凑、无长翅，与 C3 横向官帽形成反差 |
| 宫女日常头饰 | 头饰 | 宫女 | 当前宫廷女性只有单一簪饰，缺内部层级 |
| 正式鞋履 | 鞋履 | 皇帝、皇后、官员、宫女、太监 | 当前只有日常布鞋和军靴 |

这些是“版型缺口”，不是下一批必须一次全部完成的制作清单。具体单轮边界、差异门槛、制作顺序和视觉验收见《宫廷与官署服饰工作流》。默认一轮只做一个正式可穿戴 ID；只有 2–3 个强关联部件必须组合才能形成独立剪影时，才允许按一个小套装处理。

## 后续宫廷人物的差异原则

后续应先保证无颜色剪影也能拉开，而不是先堆纹样和配色。

- 皇帝：最高礼仪纵向长袍 + 唯一冠饰；不能只是 `ceremony_robe` 换成黄色。
- 皇后：更大的裙装/外服层次 + 高识别头饰；不能只是 `long_skirt + jade_pin`。
- 官员：规整、克制的长袍 + 官帽语言；可以通过颜色和局部附件形成内部变化，不要求每个品级一套新 Mesh。
- 太监：更收敛、便于活动的长衣 + 独立内侍帽冠；应与官员的正式宽松感拉开。
- 宫女：轻量长裙/下裳 + 窄袖或轻层叠上装 + 成组轻量头饰；不能与皇后共享同等体量。

人物身份仍由未来玩法/生成逻辑决定；衣冠工坊只维护可混搭外观资产。

## 新增服饰流程

新增正式可穿戴 ID 前，先把它与同槽位最近似资产放在统一灰色/素模条件下比较；衣长、袖型、肩部、腰线、下摆体量、层数、前后长度、领口大结构、头饰体量或鞋履结构中至少两个维度必须明显不同。颜色、纹样和材质亮度不算结构差异。

新增正式可穿戴 ID 时：

1. 先查 `WARDROBE_GAPS`，确认是在填真实空缺，而不是复制已有轮廓；
2. 在 `types.ts` 注册正式 ID；
3. 制作真实作者资产并接入现有槽位；
4. 同步加入 `SLOT_OPTIONS`；
5. 必须同步补 `WARDROBE_TAXONOMY`；
6. 从 `WARDROBE_GAPS` 删除或重写已经被真实资产覆盖的缺口；
7. 运行现有 Wardrobe Numeric Checks 和相关动作/贯穿检查；未通过的候选不能标记为交付完成。

`check-wardrobe-batch.ts` 会强制检查：所有当前可穿戴 ID 必须且只能存在一条版型档案、槽位必须一致、显示名必须与衣柜一致、检索场景和视觉特征不能为空、缺口不能伪装成已经注册的运行时 ID。

## 边界

本目录不新增职业、阶级、宫廷玩法、NPC 身份、Recipe 字段、骨骼、Renderer 或布料模拟。也不替代单项服饰专题文档：几何、蒙皮、动作压力、贯穿与视觉验收仍由对应作者文档和代码负责。

C2 已提供基础宫廷日常高腰裙的作者结构；剩余裙装 gap 专指 C8/C11 高等级宽摆/多层礼裙，不重复宣称缺少同一基础宫廷裙。
