# Wanhu Character Lab 项目概览

Wanhu Character Lab 是《万户天工》的程序化人物生成实验项目。

## 项目目标

游戏需要大量城市居民，同时允许近距离观察。

本项目优先验证：

- 低面数连续人体；
- 稳定人体语义；
- 程序化服装；
- 骨骼与有限蒙皮；
- Body Hide；
- LOD；
- Mesh Cache；
- Unity Burst / MeshData 迁移。

最终角色几何由参数和 Recipe 运行时生成，而不是依赖大量预制 FBX / GLB 人体与服装 Mesh。

## 当前路线

早期已经完成：

- 最小 Runtime Mesh；
- Ring Topology 实验；
- Segmented Low-Poly 实验；
- Mesh Winding Validation；
- 正交三视图 Review。

这些实验确认了低面数和运行时生成可行，但 Segmented 人体不适合作为最终蒙皮与服装基础。

正式下一路线：

~~~text
BodyParameters
→ HumanLandmarks
→ Continuous Low-Poly Base Body
→ Body Surface Semantics
→ Rig
→ GarmentRecipe
→ Body Hide
→ Final Mesh
~~~

## Web 与 Unity

Web：

- 快速调参数；
- 三视图审查；
- 拓扑审查；
- Garment Recipe 调试；
- 数据协议验证。

Unity：

- 正式大规模运行；
- Burst / Jobs；
- MeshData；
- ECS 生命周期；
- LOD / Cache；
- Animation；
- Rendering。

Web 不是 Unity Runtime 的替代品。

## 服装原则

默认不做 Cloth Simulation。

服装分为：

- Material Only；
- Body-Derived；
- Independent Silhouette；
- Rigid Attachment。

穿衣时删除被覆盖的 Body Faces。

普通居民最终预算按“可见 Mesh”计算，不按“裸体 + 每件衣服”简单相加。

## 非目标

当前不追求：

- 通用 Avatar SaaS；
- 高写实人体；
- 大量 BlendShape；
- 实时布料模拟；
- 每个服装款式一个完整 FBX；
- 每个体型一套独立衣服；
- 在 Web 中做最终游戏运行时。
