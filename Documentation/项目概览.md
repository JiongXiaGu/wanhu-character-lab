# 项目概览

衣冠工坊是写意古代角色换装与FBX试衣网页，不是居民模拟或通用捏人软件。两个固定男女基模、一个标准低模档，重点扩充服饰。

React/Vite/Three.js；配方与逻辑网格数据不依赖渲染引擎。固定20骨骼双权重；FBX唯一动画源。主路径与边界见固定基模与换装V5、运行时人物生成架构及GPU骨骼动画迁移契约。

允许破坏性重构、不兼容旧Recipe。仍需真实Actions审图，合并成功不代表髋裆美术问题解决。先固定基模造型可靠，再量产版型和款式，最后Unity单人对照与群体性能。

## 动物路线

动物部分的后续顺序已经固定为山羊、猴子、绵羊、鹿、兔子、鸟类和鱼类。地面家畜、环境动物、鸟类与水生动物不强求共用同一运行时；具体分线和每阶段验收规则见 [动物工作流](动物工作流.md)。
