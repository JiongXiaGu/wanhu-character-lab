# 项目概览 · V3

本仓库是《万户天工》人物系统的网页实验台，验证低模人体、运行时生成、服装组合和基础骨骼动作。当前不依赖外部人物 Mesh 资产。

## 当前可用产品

人物工坊提供农户、卫兵、弓手预设，以及裸模检查。界面包括外观参数、颜色、头饰与装备、动画控件、同屏三视图、结构线和骨骼调试。

## 当前工程方向

`Recipe → 固定三维人体 cage → 可见服装/装备表面 → 权重 → SkinnedMesh → AnimationMixer`

基础人体是连续闭合网格，服装和硬质装备不要求与皮肤焊为一个拓扑连通分量。它们共享骨骼，合入一个角色渲染 Mesh。当前身体 510 triangles，三套穿衣/装备预设均低于 1000 triangles。

## Web / Unity 边界

可迁移的是 Recipe、人体语义、固定连接关系、骨骼层级、权重规则和生成方法。Three.js 渲染与 AnimationMixer 不是 Unity Runtime 的最终实现。

本轮只验收人物模型与基本动作。LOD、缓存和大规模动画渲染需要在 Unity 中另行验证，不能从网页单人性能推断。

请从 工作交接.md 和 V3验收记录.md 了解当前状态。旧 V2 方案已经停止执行。
