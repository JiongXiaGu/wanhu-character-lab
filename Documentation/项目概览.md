# 项目概览 · V3.3 / Phase 4A

本仓库是《万户天工》人物系统的网页实验台，验证低模连续人体、运行时生成、服装/装备组合、固定骨骼、基础蒙皮、劳动/射箭动作与 Unity GPU Crowd 数据契约。不依赖外部人物 Mesh 或动画资产。

## 当前可用内容

农户、卫兵、弓手、基础人体是 Slot Recipe 预设。头饰、衣服、下装、鞋、背部和双手可继续混搭；身高、体格、配色可调。

保留 6 个基础 Motion/检查姿态，另有 17 个可播放 Action 入口：10 项拾放、负重、推拉、锄地/锤击，以及 7 项完整射箭、分段和高低瞄准姿势。具体清单与范围见 `Phase4A使用与验收.md`。

界面支持暂停、变速、逐帧、重播、握点检查、正/侧/背/三视图、结构布线、三角线框、骨骼叠加、截图和 Recipe JSON。动作不锁职业，临时道具不会改掉原穿戴。

## 生成与播放链

```text
Recipe
→ 固定三维人体 Cage
→ 服装/装备可见表面
→ CharacterData
→ 固定 20 Bone Skeleton + ≤2 Influence SkinBinding
→ 基础 Motion / Action 构建期 FK/IK
→ 人体局部轨道 + 道具轨道 + 语义事件
→ Web SkinnedMesh 与独立动作道具
```

基础人体连续闭合。服装和硬装备不必与皮肤焊成同一拓扑分量，但共享骨骼语义。弓臂、弓弦、箭和其他动作道具节点不增加人体 Bone ID。

正常播放不由 CPU 每帧重建人体 Mesh，也不每帧求全身 IK。结构布线 Debug Overlay 会 CPU 蒙皮用于线段显示，只服务审查，不是正式游戏路径。

## 动画与方向

+X 右、+Y 上、+Z 前。所有动作原地演示，导航负责世界位移。循环、单次末帧停止、持续保持分别处理；seek 只还原视觉，正常播放才派发语义事件。

完整射箭包含搭箭至收势；保持瞄准不会自动放箭，取消无释放事件。拾起末帧、抱箱待机和放下起点共用抱持姿态。其他任务连接层、世界物品生命周期、任意中断混合和生产/战斗业务尚未实现。

## 验收

仅使用 GitHub Actions runner 内 Vite Preview + Playwright，不部署 Visual/Vercel。基线回归保留 1152 个姿态样本；动作检查 17×3×61=3111 帧。每个已实现动作有四视图与关键阶段截图。

自动成功不等于美术通过。Agent 下载产物、逐项看图、修正重跑，再合入 main。实际 SHA/run 和范围见本轮验收记录；不能把老版本截图当作新提交证明。

## Web / Unity 边界

迁移 Recipe、Cage/Topology、SkeletonDefinition、SkinBinding、MotionClip、ActionDefinition、PropClip/锚点及动画状态；不直接迁移 Three.js Bone、AnimationMixer、OrbitControls 或 Web Renderer/Material。

Unity 仍需实现 MeshData、Burst/Jobs、BlobAsset、ECS 状态、GPU Bone Buffer/Animation Texture、Entities Graphics、LOD、Cache、Culling 和真实 Profile。

尤其注意：Phase 4A 动作采样依赖人体比例，已烘焙 Clip 不能未经验证就仅按 SkeletonVersion+ClipId 跨体型共享；道具轨道与 CPU 语义事件也不能丢失。详见 `GPU骨骼动画迁移契约.md`。

目标是近景保留完整 20 骨骼/双权重，中远景共享经过验证的 Mesh/Clip 数据并使用轻量实例状态，而不是每名居民各自运行完整 Animator 与 GameObject 骨骼层级。当前单人物网页不代表 Unity 万人性能已经通过。
