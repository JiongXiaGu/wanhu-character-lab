# 项目概览 · 衣冠工坊 V1

《万户天工》玩家/居民角色自定义工具。先做好可编辑换装，城市居民复用相同Recipe生成外观。Web不实现职业、阶层、库存、生产或宫廷玩法；这些由Unity实现。

写意美术：明确版型和大色块优先，不宣称朝代服制考据。当前四组八套推荐、七槽位、发式/发色、三色染色、种子随机/锁定、撤销与配方保存重入。任何部件均可选给男女，推荐不是职业或性别限制。

## 技术基础

程序生成人体、衣物和附件；连续封闭身体510tris/257逻辑顶点，固定20骨骼、每顶点最多2权重。男女同拓扑不同形态场，保持旧男体12份哈希；服饰不改源身体与绑定语义。

所有动态动作来自11个Mixamo FBX，经真实bind、坐标单位、T/A参考姿态校准后驱动当前人物。头部修正保持wanhu-mixamo-2。默认静态试衣，选择FBX后可暂停/变速/定位/源对照；旧程序动作已删除。

## 目录

- `src/character/v3`：协议、拓扑、男女比例、统一服饰组装、蒙皮适配。
- `src/character/wardrobe`：美术部件轮廓、推荐搭配、染色/发式、确定性随机及配方导入验证。
- `src/character/mixamo`：源协议/注册表、重定向/导出、唯一播放器。
- `scripts/lib/mixamo-fbx.ts` 与 prepare-mixamo：离线提取骨架和动画，不导入源人物网格/贴图。
- `CharacterViewport`：真实模型预览与诊断；`App`：换装状态、文件与浏览器保存接口。

Recipe V4新增可选dyes/hairStyle/hairColor，与旧配方兼容。目标动画JSON不是Unity运行时。当前染色烘焙进顶点色，未来参数化染色和批量共享需要单独迁移验证。

## 验收与边界

四条Actions分别覆盖构建、旧模型、FBX、衣冠数值/浏览器/视频；下载同提交产物实际查看后合main，不部署线上preview。长摆是分片蒙皮非Cloth，不能保证所有大幅动作无自交。精确道具接触、Unity群体/LOD和性能均未完成。

详细分期及操作见《玩家角色自定义与服饰分期》《换装工作台使用》。
