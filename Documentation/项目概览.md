# 项目概览 · V3

本仓库是《万户天工》人物系统的网页实验台，用于验证：

- 低模连续人体
- 运行时生成
- 服装 / 装备组合
- 固定骨骼语义
- 基础蒙皮与动画
- Unity GPU Crowd Animation 数据契约

当前不依赖外部人物 Mesh 资产。

## 当前可用产品

人物工坊提供：

- 农户
- 卫兵
- 弓手
- 基础人体

界面支持：

- 身高 / 体格 / 配色
- 头饰与装备
- 动画播放 / 暂停 / 速度 / 逐帧
- 正 / 侧 / 背三视图
- 结构布线
- 三角线框
- 骨骼叠加

## 当前生成链

~~~text
Recipe
→ 固定三维人体 Cage
→ 服装 / 装备可见表面
→ CharacterData
→ 固定 20 Bone Skeleton
→ ≤2 Bone SkinBinding
→ MotionClip
→ Web SkinnedMesh
~~~

基础人体是连续闭合网格。

服装和硬质装备不要求与皮肤焊成一个拓扑连通分量，但必须共享相同 Skeleton 语义。

## 动画当前结论

Web 主体角色不是 CPU 每帧重建 Mesh。

Three.js 通过 SkinnedMesh 做 GPU 顶点蒙皮，AnimationMixer 更新 Bone Transform。

结构布线调试模式会 CPU 计算蒙皮位置用于 LineSegments，这条路径只服务审查，不属于正式游戏运行时。

统一坐标：

~~~text
+X = 右
+Y = 上
+Z = 前
~~~

Walk / Run 是原地动作，导航系统负责世界位移。

## Web / Unity 边界

可迁移：

- Recipe
- Cage / Topology 语义
- SkeletonDefinition
- Bone ID / Parent Map
- SkinBinding
- MotionClip 语义
- AnimationState
- Garment / Equipment Bone Policy

不直接迁移：

- Three.js Bone 类
- AnimationMixer
- OrbitControls
- Web Renderer / Material

Unity 正式路径会重新实现：

- MeshData
- Burst / Jobs
- BlobAsset
- ECS AnimationState
- GPU Bone Buffer / Animation Texture
- Entities Graphics
- LOD / Cache / Culling

## Crowd 方向

近景：

~~~text
20 bones
≤2 weights
GPU skinning
~~~

中远景：

~~~text
Instance Transform
+ CharacterMeshKey
+ ClipId
+ Phase
+ Speed
→ Shared Motion Data
→ GPU Skinning
~~~

不默认给几千居民各自运行完整 Animator + Bone GameObject Hierarchy。

详细见 GPU骨骼动画迁移契约.md。

当前网页单人物表现不能替代 Unity 大规模 Profile。
