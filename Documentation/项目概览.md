# 项目概览 · V3.5

《万户天工》男性居民的程序建模、DIY 与外部动画实验台。程序生成人物和服装，动画仅来自 FBX；女性尚未接入。

人体连续封闭510tris/257逻辑顶点，固定20骨骼，每顶点最多2权重。Recipe V4职业只写槽位；头饰/衣服/鞋/背部/双手独立混搭。

11个Mixamo文件离线提取，经过真实绑定/坐标/参考姿态校准后驱动目标。wanhu-mixamo-2修正头顶辅助骨段引起的额外低头。默认慢跑，支持暂停/变速/定位/重播/完整末帧、源对照、头向检查和目标JSON。

## 目录职责

- src/character/v3：类型、连续拓扑、身体、服装、蒙皮适配。rig不再生成任何动画。
- src/character/mixamo：源协议/注册表、目标重定向/导出、唯一播放器及调试。
- scripts/lib/mixamo-fbx.ts、prepare-mixamo.ts：离线提取，只输出源骨架/动画，不带人物网格和贴图。
- CharacterViewport/App：模型预览、相机、播放状态、异步切换隔离和DIY。

src/character/actions等旧程序动作已删除，历史Phase4A记录仅为历史，不再是功能入口。静态bind不是动作。

## 验收和边界

GitHub Actions Build、Male Character Model Review、Mixamo Retarget Review；实际下载审图/视频后才能合main，无线上视觉部署。

FBX只提供人体轨道。道具接触/弓弦/箭/业务事件仍需单独制作；低模极端姿势自交未完全解决。Unity导入器、GPU Crowd、LOD与性能尚未实现，目标JSON不是Unity运行时。
