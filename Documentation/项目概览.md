# 项目概览 · V3.4 / Mixamo

《万户天工》城市模拟经营的人物生成与动作验证实验台。正式目标仍是程序人体、可 DIY 服装/装备和固定骨架；动画来源现允许外部软件制作与 Mixamo FBX 导入。

## 当前可用

- 连续封闭三维人体：510 tris / 257 逻辑顶点，20 固定 Bone ID/Parent Map，每顶点最多 2 个非零权重。
- Recipe V4：职业预设只写 Slots；帽子/上衣/下装/鞋/背部/双手独立 DIY，保留旧参数迁移。
- 6 基础 Motion 与 17 程序 Action 对照。
- 仓库 11 个 Mixamo 动作经真实 bind、坐标和参考姿态校准，驱动现有角色，不替换为源人物模型。
- 暂停/变速/定位/重播/末帧，源骨架同步对照，当前体型目标动画 JSON 导出。
- GitHub Actions 基模/旧动作回归、新 Mixamo 多视图与连续视频，禁止视觉部署。

## 目录

src/character/v3：类型、拓扑、身体、衣服、蒙皮适配与旧基础动作。

src/character/actions：程序动作、构建期 IK/烘焙、道具、事件与播放器。

src/character/mixamo：外部源协议/注册表、目标重定向/导出、播放器与源对照。

scripts/lib/mixamo-fbx.ts、prepare-mixamo.ts：离线提取用户上传 FBX，生成 public/mixamo，忽略提交；不下载外部资源，不保留源网格/贴图。

src/scene/CharacterViewport、App：预览、相机、控件、异步切换隔离。

## 制作方向变更

早期「不依赖外部动画资产」约束已经取消，**仍禁止用外部人物 Mesh 替代程序人物**。旧 Phase4A 资料保留为程序动作架构/历史验收。详见 Mixamo动画接入.md 与 AGENTS。

外部动作人体轨道不等于完整游戏行为。弓弦/箭、道具接触、场景、第二人物和业务事件需另外制作。极端动作仍需检查旧人体蒙皮/服装。

## Unity

迁移骨架、蒙皮、局部轨道、体型和来源元数据，不迁移 Three.js 类。当前 JSON 导出不是 Unity Runtime；先单人对照再做 GPU 群体、缓存、LOD/剔除与性能。导航负责世界位移，动作保留骨盆姿态运动。

首次接手先读 README/AGENTS/工作交接/Mixamo动画接入。实际验收由对应 SHA 的 GitHub Actions 产物和审图记录确定。
