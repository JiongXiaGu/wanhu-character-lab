# 服装动画适配 V2

## 当前目标与范围

玩家/居民换装优先，写意服饰，玩法留在 Unity。所有动作来自用户的 Mixamo FBX。基于 main 5d07b439（新增动画）开发，不把 PR #10 未通过的重叠裙片直接合并。

## 动画测试库

`npm run prepare:mixamo` 递归扫描 `动画参考/` 的 FBX，保留旧 11 个 ID，给新增文件生成稳定 ID、原文件名和测试分类。生成 catalog.generated.ts，随后才加载提取器。新文件在重启 dev/build 时生效，不需要手动写两个目录。提取失败显示完整文件名并让构建失败，不漏文件、不用程序动作回退。缓存核对源 SHA；源 Mesh 与贴图不进入网页。

右侧动作试衣库：中英文/文件名搜索、分类、收藏、上一个/下一个、坐姿/射箭/慢跑快捷入口、劳动分类。收藏只存此浏览器。中央保留全动作下拉、进度、暂停、变速、重播，并增加 30fps 上一帧/下一帧。分类不是衣服兼容许可，也不是已通过美术审核的标签。没有椅子、台面、工具时不声称已制作这些交互。

## 服饰结构取舍

此前长摆壳体与内衬独立蒙皮，坐姿会形成衣层穿插。V2 在用户允许简化的前提下改为**连续裤式分裳**：主衣面即服装表面，不同时绘制外裙和整条内裤两张互穿表面。以颜色、腰线及腿外侧放量表达层次，保留完整腰裆/大腿/小腿，不靠整段隐藏腿部或 DoubleSide 遮掩。

这不是传统连筒长裙，也不是四片裙自动无穿模方案。为稳定性牺牲拖尾与大幅飘摆，保留七槽位和旧语义 ID，显示名应同步体现分裳。想恢复宽大悬垂礼服时另做少量服装骨骼/离线修形评估，不在此版本添加运行时求解器。

仅改可见服装表层的裆点高度、放量与细分，不改源男女人体、20骨骼、绑定、FBX、头部校准。髋膝过渡细分采用共享边中点，邻接面同步拼接，不能产生 T 接缝；每顶点仍最多两项有效权重。

## LOD 框架

LOD0/1/2 为真实服饰几何选项，不进入玩家 Recipe。0保留衣面过渡，1保留关节重点过渡，2使用基础连续衣面。三档共用骨架、服装ID和动画相位；未做按屏幕占比自动切换、完整人体/头发/道具减面或 GPU Crowd。不得将保留 510 tris 人体的 LOD2 描述为 250 tris 整个人物。

动画缓存不因颜色/服装LOD而复制骨骼语义，但当前播放器换网格仍重建演员并进行目标采样；优化共享缓存是后续工作。网格缓存必须含 geometryVersion、LOD、体型/比例、部件和当前顶点染色参数。Unity 先验证单人物与网页一致，再实现群体/剔除/批量绘制。
