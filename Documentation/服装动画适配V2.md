# 服装动画适配 V2

## 目标与范围

玩家/居民换装优先，写意服饰，玩法留在 Unity。所有动作来自用户的 Mixamo FBX。基于 main 5d07b439（新增动画）开发，不把 PR #10 未通过的重叠裙片直接合并。

## 动画测试库

`npm run prepare:mixamo` 递归扫描 `动画参考/` 的 FBX，保留旧 11 个 ID，给新增文件生成稳定 ID、原文件名和测试分类。生成 catalog.generated.ts，随后才加载提取器。新文件在重启 dev/build 时生效，不需要手动写两个目录。提取失败显示完整文件名并让构建失败，不漏文件、不用程序动作回退。缓存核对源 SHA；源 Mesh 与贴图不进入网页。

右侧动作试衣库：中英文/分类词/文件名搜索、分类、收藏、上一个/下一个、坐姿/射箭/慢跑快捷入口、劳动分类。收藏只存此浏览器。中央保留全动作下拉、进度、暂停、变速、重播，并增加 30fps 上一帧/下一帧。分类不是衣服兼容许可，也不是已通过美术审核的标签。没有椅子、台面、工具时不声称已制作这些交互。

## 服饰结构取舍

此前长摆壳体与内衬独立蒙皮，坐姿会形成衣层穿插。V2 在用户允许简化的前提下改为**连续裤式分裳**：主衣面即服装表面，不同时绘制外裙和整条内裤两张互穿表面。以颜色、腰线及腿外侧放量表达层次，保留完整腰裆/大腿/小腿，不靠整段隐藏腿部或 DoubleSide 遮掩。

这不是传统连筒长裙，也不是四片裙自动无穿模方案。为稳定性牺牲拖尾与大幅飘摆，保留七槽位和旧语义 ID，显示名及目录示意图同步体现分裳。想恢复宽大悬垂礼服时另做少量服装骨骼/离线修形评估，不在此版本添加运行时求解器。

仅改可见服装表层的裆点高度、放量、静态褶窝与细分，不改源男女人体、20骨骼、绑定、FBX、头部校准。髋膝过渡细分采用共享边中点，邻接面同步拼接，不产生 T 接缝；每顶点仍最多两项有效权重。

## 深屈曲修正

V2初次Actions在坐姿/抓举发现主衣面贯穿，不能将闭合拓扑视为通过。修正将裆点从单骨盆跟随改为左右大腿各半权重，髋环提高、膝关节过渡区拉长，内大腿留间距，膝后收量形成静态褶窝。按体格平滑调整大腿前侧厚度，避免只修高壮角色却挤压纤细角色。上述操作发生在生成衣面时，不修改原始人体和FBX，不加入姿势检测、BlendShape、衣服骨骼、每帧碰撞或实时布料。

独立贯穿测试覆盖坐姿拨开关、射箭、慢跑、Snatch抓举、Start Walking起步，男女×三样板×三级LOD×五组身材，每条动画检查全部源时间键及相邻键中点。扫描线仅加速AABB筛选，不放宽三角贯穿判定。仍不涵盖所有共面接触、共享顶点邻面反折、袖子/手臂/工具、任意动画组合和连续时间碰撞。

## LOD 框架

LOD0/1/2 为真实服饰几何选项，不进入玩家 Recipe。0保留衣面过渡，1保留关节重点过渡，2使用基础连续衣面。三档共用骨架、服装ID和动画相位；未做按屏幕占比自动切换、完整人体/头发/道具减面或 GPU Crowd。不得将保留 510 tris 人体的 LOD2 描述为 250 tris 整个人物。

本次144组静态组合中，整个人物统计的范围为 LOD0 1231–1305、LOD1 1159–1233、LOD2 691–765 tris；不是普遍性能保证。动画缓存不因颜色/服装LOD而复制骨骼语义，但当前播放器换网格仍重建演员并进行目标采样，优化共享缓存是后续工作。网格缓存必须含 geometryVersion、LOD、体型/比例、部件和当前顶点染色参数。

### 结论与限制

接受为可使用的 V2 分裳兼容与动画测试版本：旧双层裙壳相互穿插已从结构上移除，已测坐姿和抓举中的主要腰髋乱折/贯穿问题已修正。没有通过降低测试门槛、删掉腿、改变FBX或双面渲染来获得通过。

这不是最终服饰美术验收。近景仍有明显低多边形折线与髋下暗面；深屈曲侧面大腿偏薄、膝前轮廓偏硬，三级LOD也有细分阴影变化。裤式分裳不是自然垂坠的连筒裙。后续应在不破坏贯穿测试的前提下改善轮廓与着色。

23动作均加载并驱动人物，不等于所有极端翻转/贴地/劈叉、所有衣物混搭均完成无穿插保证。手臂/袖子与道具仍需专项；Snatch只是源抓举片段，不等于完整劳动任务。没有坐具、弓弦/箭事件、工具抓握、Unity导入器、全人物/动画LOD或GPU群体性能实现。原始FBX仅实验使用，本次不改授权或重新发布来源资源。
