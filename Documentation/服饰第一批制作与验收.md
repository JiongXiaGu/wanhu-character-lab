## 网格、染色与接口

`top-seams.ts` 只提供有限的缝片/接环操作。三件上衣分别拥有制作好的衣身切线、袖筒坐标和双权重；不是把不同名字塞进统一 width/cuff 参数。`patterns.ts` 使用明确 asset 判别项，删除这五件款式不再使用的旧参数。

斜襟、半臂前襟、短衣门襟是衣身中的共享边色区，不再叠加旧 CrossCollar / InnerCollar 浮动条。老款轻甲等仍保留自己的既有装饰逻辑。半臂外缘与内缩环共用上臂权重，省略被遮挡的内袖/内衣；不是三层完整衣服，也没有 innerShirt / lining 槽位。

三色：primary=主布、行动裤腰口/束口；secondary=裤身、可见内衬、短衣卷袖与领缘；accent=斜襟/对襟缘边、腰带、袖口/裤脚。染色只改 face.color，不改坐标、权重或拓扑。

覆盖规则仍为 authored-coverage-v1：短衣覆盖 torso/upperArm；长袖和半臂另覆盖 forearm；裤装覆盖 pelvis/thigh/shin；鞋覆盖 foot。上衣仅开放腰口、领口、两袖口；裤装仅开放腰口、两裤脚。半臂叠层连接不是额外开口。覆盖与动作相位无关。

## 操作

Node.js >=22.12。正常环境：`npm ci` → `npm run dev`。一次安装浏览器 `npx playwright install chromium`。

`npm run review:local -- --wardrobe`：本地48静态图；加 `--full` 得到完整第一批矩阵。原 `npm run review:local` / `--full` 的32/156张人体形变检查保持。正式六项Actions分别承担构建、人体、全部动作、衣柜、裤装贯穿和衣服前后对照，不以新小矩阵替代旧回归。

## 边界与下一批

保持低模硬边、简化手部和固定蒙皮；不追求近景平滑布料褶皱。长袖屈肘、半臂腋下及宽裤深蹲仍需多角度观察，自动有限值/贯穿检测不保证所有连续时间、共面接触、手臂与道具的零穿插。普通折面本身不是重做人体的理由。
