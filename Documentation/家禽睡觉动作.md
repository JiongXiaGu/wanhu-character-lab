# 家禽睡觉动作

## 目标与范围

鸡、鸭、鹅在既有家畜工作台新增 `sleep`（睡觉）。它是保持卧伏的三秒循环，只有毫米级呼吸，不在每一轮重新站起或趴下。鸡低伏收颈，鸭卧伏收拢短颈，鹅以原双段长颈回收、头朝背侧。没有新增闭眼骨、眼睑网格、羽毛或可见翅膀。

只做陆地作者动画，不包含入睡／起身过渡、水上睡眠、昼夜调度、疲劳、动物AI或Unity正式运行时。猪、犬、人物、服饰和坐骑不在本轮修改范围。

## 数据所有权与不变量

睡姿与轨道分别属于 `src/chicken/animation.ts`、`src/duck/animation.ts`、`src/goose/animation.ts`。公共目录继续读取各物种动作列表，Actor、时钟、姿态缓存和群体实例不扩职责。没有新建家禽继承体系或专属页面。

三档作者网格、顶点数、原骨序、inverse bind、单权重与不透明FrontSide材质保持。鸡／鸭仍八骨，空Wing兼容位不绑定可见几何；鹅仍七骨，不增加空骨。鸡动作版本v4、鸭v4、鹅v2；原有动作轨道和时长不变，动作总数依次为5／8／9。

睡眠只烘焙现有骨的位置与四元数，不用骨骼缩放压扁身体或缩短腿。足底校正在作者阶段完成，没有运行时IK。鸡低伏包住腿根，脚保持近水平支撑，让省略长趾的低档也能接地；不恢复脚趾或提高低档预算。三物种三档统一检查足底3至8毫米、全身不穿地及脚端不随呼吸滑动，不设鸡低档悬空例外。

## 预览与生命周期

动物工坊→家畜→选择鸡／鸭／鹅→陆地→睡觉。入口例：`?lab=livestock&animal=goose_domestic_white&clip=sleep&phase=.5&paused=1&view=three`；换成 `chicken_brown` 或 `duck_domestic_brown` 使用同一动作语义。原数量1／10／50／100／500、自动／固定LOD与时间控件均保留。

睡眠不加入日常混合池。群体点击睡觉会退出混合，原地错峰呼吸；仍使用固定种子布局，不增加移动路径或AI。切换水面时睡觉不可用，回退到漂浮；三种家禽间可保留sleep语义，切到猪／犬回退其默认停驻。

每个已访问LOD的睡眠缓存追加73帧；只是页面内共享静态姿态，不是每只一套Mixer。单一睡眠群体最多8个动物批次。缓存随原页面生命周期释放，不增加Renderer、RAF、材质或跨页面GPU缓存。

## 检查与视觉验收

`check:livestock`保留全部旧回归并扩充动作矩阵。鸡／鸭／鹅分别为3615／5784／6507个实际蒙皮姿态，三者共15906；未改动猪、犬各3615个姿态的回归继续保留。

`check-livestock-sleep.ts`另行检查三物种×三档×241相位，共2169个睡姿：持续低伏、接地／收足、头身距离、面不退化、毫米级呼吸、脚端静止、首尾闭合、73帧缓存与实际蒙皮一致及1至500群体不移动。81个真实故障注入覆盖站立替代、悬浮／穿地、脚部下沉、头部脱离、Root漂移、缩骨、腿错绑及错误inverse bind。

桌面睡眠专项覆盖9个物种／LOD组合、15个数量组合，另保留原家禽所有动作浏览器矩阵；检查真实按钮、暂停／定位／末帧、物种与水陆过滤、栏目恢复、相机／Renderer复用及人物存档不变。`review:livestock`或PR标题的`[visual]`显式生成真实WebGL单只、侧视、同机位三档和百只睡眠图。
