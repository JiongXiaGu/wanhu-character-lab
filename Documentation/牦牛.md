# 牦牛：低宽长毛本体与骑乘

## 目标与边界

yak_black是第五种真实坐骑，定位为中国西部／高原语境下的牦牛，与马、灰驴、双峰骆驼、黄牛并列。不是黄牛换色加毛、水牛、野牛或现代观光卡通动物。识别重点是低宽厚重的体量、强肩前躯、低位宽头、连续下垂长毛、外展后上扬的角和真实分趾蹄。

只制作独立本体、四动作、普通／旅行牦牛鞍、男女骑姿、既有工作台接入与检查。不做幼体、套绳、驮队、货架／库存玩法、奶制品或牧业、群体AI、高原特殊移动、攀爬、上下坐骑、Root Motion、腿／地形IK、毛发／绳／包袋物理、透明毛卡或新通用动物系统。旅行行囊只是整体鞍具里的静态造型。

## 作者资源与所有权

src/yak/geometry.ts拥有牦牛专属横截面、连续毛披、短粗颈、宽头、角、小耳、闭合毛壳与八趾。rig.ts拥有29骨的索引、父关系和米制绑定。animation.ts拥有四个原生片段及创建时烘焙；saddles.ts拥有两套牦牛鞍、鼻带侧环、坐面、YAK_RIDER_FIT和YAK_REIN_PROFILE。网格当前为m7-v2：只包含眼区可读性补丁；绑定、动作和鞍具仍保持m7-v1，不升级人物配方。

只复用现有闭合低模几何工具、蒙皮装配器、语义播放器和双绳算法，不导入或缩放黄牛／马／驴／骆驼作者工厂。src/mounts只登记第五项真实资产，src/riding继续拥有稳定座点、唯一时钟、人物与坐骑组合及生命周期。原四物种作者文件和人物Recipe V5、20骨、服饰／帽饰／FBX源码保持不变。

本体2328三角形、1224逻辑点、6984硬边渲染顶点，30个闭合作者小壳；鞍具和双绳另计。这是逐作者壳闭合，不是整只动物全部焊接成单一流形。代码为实现权威，文档不重复逐点网格数据。

## 连续长毛轮廓

Body不是普通桶身再套外壳。它由牦牛专属纵向横截面直接形成较高肩背、宽前躯、后躯与两侧长毛下摆，中腹在两侧裙毛上方回收。躯干与左右裙毛共用一张闭合、连通、欧拉数为2的表面；178个逻辑点、352三角形。两侧下摆通过少量不等高宽面表达蓬垂，不用大量碎片。

独立ChestFur为宽厚闭合胸毛；Forelock为贴头前额毛；两块CheekFur加强低头侧面并部分遮住小耳；TailPlume形成长而蓬的尾束。四条腿本身的上段截面拥有毛量，下段收窄并露出蹄部承重结构，不额外挂四套漂浮腿毛。所有毛均是不透明低模实体，没有透明贴片、材质毛发、逐帧几何或物理。

角从两侧外展后转向上方，明显宽于黄牛短角，尖端收细；角根与头壳嵌合而非悬空接头。两角刚性随Head。宽鼻镜与Head接触，眼睛／鼻孔小壳的中心在创建时投到承载三角面，不在播放中修补位置。Foot下的InnerHoof／OuterHoof是八个独立闭合趾壳，实际分缝而非黑色贴线。

m7-v2只修正脸部表达：眼睛仍是Head刚性的小型闭合低模体，但由首版的小点扩大为更圆钝的短椭圆豆豆眼，并略向下、向前、向两侧调整，使默认3/4视角更容易读到。前额毛收窄少量，侧脸毛上缘向下／向后让出眼窗，靠近眼区的上缘毛面仅做轻微暖灰棕提亮。没有白眼球、写实虹膜、眼骨或卡通大眼，也没有改变头壳、角、颈部或整体厚重轮廓。

## 骨架与蒙皮

29骨：Root、Pelvis、Spine、Chest、NeckBase、Neck、Head；四腿各Upper／Middle／Lower／Foot；Tail／TailMiddle／TailEnd；LeftEar／RightEar；最后一根Forelock。

米制，+X右、+Y上、+Z前，每点最多双权重。Body只在Pelvis／Spine／Chest间过渡；ChestFur只在Chest／NeckBase间过渡；前额毛在Head／Forelock间过渡，根部留在Head。额毛只有微小作者摆动，不扩大为毛骨链。侧脸毛与角刚性随Head，趾壳刚性随Foot，尾束随相邻尾骨。短粗颈和低头的绑定属于牦牛，不复用黄牛Skeleton或inverse bind。

站姿前肢位于肩下，前蹄只小幅前探；后肢根落在后躯，保留膝部前折、飞节回收和蹄落回后躯下方。检查同时约束骨点相对Body纵向比例与蹄壳位置，不能仅以骨架合法替代合理腿位。

## 四个本体动作

| 语义 | 原生片段 | 时长 | 表现 |
|---|---|---:|---|
| idle | Yak_Idle | 5.8秒 | 慢呼吸、低头回稳、小耳轻摆与蓬尾慢甩 |
| walk | Yak_Walk | 1.95秒 | 低重心短步、稍错相四足支撑，厚前躯较小起伏 |
| run | Yak_Run | 1.10秒 | 独立较大步幅与收腿的沉重短跑，不作赛马疾驰 |
| eat | Yak_Eat | 7.2秒 | 短颈与头一起下探，低位停留、轻扫啃食后抬头 |

创建时按现有30fps采样预算烘焙完整首尾，生成28条局部旋转轨道和一条Pelvis位置轨道。Root无轨道，没有水平根位移或缩放。蹄底竖向留量仅在创建AnimationClip时通过真实绑定前向变换标定，播放只采样固定轨道，不做腿目标、地形求解或实时贴足。

低位支撑足向-Z后掠、抬脚向+Z回收。Walk／Run各四脚的轨迹有向面积与反转反例独立受测，不用镜像相机或倒放时钟修方向。进食只在本体页，骑乘仍为静态、停驻、步行、奔跑。写意原地动作不是零滑步或完整动物生物力学证明。

## 牦牛鞍与缰具

仍只有none／simple／travel三语义。simple为顺应宽背与肩部坡度的厚织垫、低宽坐面和简化蹬带，不使用马鞍高桥。travel增加两侧厚布包、后卷包和绑绳，全部属于同一整体模块，不增加装备子槽。

鞍具和稳定RiderSeat分别挂Spine；鼻带及两侧金属环随Head。bitLeft／bitRight是兼容字段，其语义为鼻侧环而非马衔铁。YAK_REIN_PROFILE从较低的头位将双绳引向角下、颈侧再至掌心；首稿导向与角冲突已在作者配置中修正，没有放宽穿越门槛。

固定双绳仍为200三角形，动物采样→同相位骑手采样→两端与导向→写回原Geometry／TypedArray。没有手部IK、绳物理或逐帧分配。有限中心线检查额外包括牦牛胸毛、前额毛、侧脸毛和尾束；Body本身已包括长毛下摆。原6毫米鼻环制作接触例外不扩大为整头／整毛壳豁免。

## 骑姿与生命周期

YAK_RIDER_FIT为男女提供比黄牛略高的hipsLift、更宽的大腿跨坐、稍前膝位以及较低、较宽的持缰方向。不增加人物骨骼、不改服装权重、不重定向原FBX。人物独立绑定后才挂Seat，之后不重算inverse bind或rebind。

普通／旅行互换只换静态鞍具与坐点，不重建人物、坐骑或绳；换物种成功构造候选后再释放旧动物和旧绳，保持人物Geometry、inverse bind、外观、动作语义、归一化相位与相机方向／缩放。none释放鞍具、隐藏骑手和绳并冻结骑乘；五物种往返仍保持none，不自动装鞍。完整共享规则见多坐骑、骑乘与马具文档。

本体页无鞍仍播放四动作，有鞍无骑手只显示辔头；跨本体／骑乘页面沿用preview-session，只在明确点击模式链接时保存临时相位、相机与未保存装扮，不写人物工坊存档。没有单独牦牛页面。

## 检查与验收边界

仍使用npm run check:mounts，无永久check:yak命令。mount-yak-anatomy-checks检查30壳闭合、连续Body连接性／对称／肩背与下摆、29骨及双权重、角对称／刚性／嵌合、鼻镜／眼鼻贴合、眼睛尺寸／位置／左右对称、八分趾、腿位与毛壳根部关系。故障反例覆盖错角权重／对称、单蹄、错误趾权重、缺毛／飘毛／坏毛权重、壳缺面、悬空鼻镜、眼睛缩小回退和腿位偏移。

mount-yak-checks追加964本体姿态，逐姿态检查有限值、地面、循环闭合、毛根附着与正向脚轨迹；男女×两鞍×三骑姿×241相位共2892骑乘姿态、70套衣裤关键相位、40次五物种切换，以及inverse bind、换鞍复用、none、错误端点和幂等释放。旧蹄底-0.012米、进食最低头0.01–0.12米和鼻环0.006米门槛不变，不删减马、驴、骆驼、黄牛矩阵。

check:mounts-browser追加真实桌面四本体动作、男女／两鞍／三骑姿、五物种切换、none、换装与末帧／重播、两模式往返的相位／相机缩放／未保存外观以及坏缓存。check:riding-browser和check:saddles-browser保留。正式Targeted加入yak路径，仍仅三条永久Actions；默认交互测试不生成图片。

数值通过、浏览器通过、生成截图、实际看图和用户认可必须分别记录。近景仍需用户判断肩胸／长毛的美术比例、角形、眼鼻可读性、重步节奏，以及男女膝脚、衣摆、行囊、鞍垫与身体的接触。连续封底裙和手持物仍为骑乘试验装扮，不自动换裤或删道具；有限采样不保证全时域零穿插、精确抓缰或贴蹬。
