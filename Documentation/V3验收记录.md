## 行走方向修复

用户审查发现原行走视觉像“向后退”。

根因：

1. 脚步摆动期和支撑期相位反了
2. 同侧手臂与同侧腿同向前摆

已修复。

统一方向：

~~~text
+Z = 人物前方
~~~

Walk 当前 CI 锁定：

~~~text
0%   右脚位于 +Z 前方接地，右臂位于后方
25%  左脚抬起向前摆
50%  左脚位于 +Z 前方接地
75%  右脚抬起向前摆
~~~

同时 Visual Review 增加完整侧视步态周期截图。

## Web GPU Skinning 结论

主体人物使用 Three.js SkinnedMesh：

- CPU 更新 Bone Transform
- Vertex Shader 完成主体 Skinning
- Mesh 不逐帧重建

结构布线 Debug Overlay 为了显示真实 Cage 边，会 CPU 计算 Debug 顶点位置。

这条 Debug 路径不代表游戏正式动画方式。

## Unity 迁移结论

可以迁移的是：

- Skeleton Bone ID / Parent Map
- Bind Pose
- SkinBinding
- MotionClip 语义
- AnimationState

不会直接迁移：

- Three.js AnimationMixer
- Web Bone 类
- Web Renderer

近景目标：20 Bone GPU skinning。

中远景 Crowd 目标：ClipId / Phase / Speed + Animation Texture / Bone Buffer + Entities Graphics。

详细见 GPU骨骼动画迁移契约.md。
