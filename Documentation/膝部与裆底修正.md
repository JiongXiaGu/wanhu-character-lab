## 已实现，不等于视觉已通过

1. 裸模膝部的原始坐标、截面和权重不变。`leg-deformation.ts` 提取现有膝关节制作基准，身体与首批裤装引用相同基准，但仍是独立网格，不复制人体衣面。
2. 裤装删除膝后统一压到 -0.012 的处理；膝上/中/下重新使用局部控制圈与原裸模一致的权重，删除 UpperLeg 冗余环和小腿不必要的大腿混权。单件裤装从252降至220个三角形，人体保持510个三角形；不是通过全身细分修复。
3. 裸模 Crotch 从 `[Hips,Hips,1]` 改为 `[RightThigh,LeftThigh,0.5]`。这是消除中央点随骨盆刚性悬挂的候选，不是已经完成的裆底拓扑重建，也不保证单点连接在任何动作都自然。须查看坐姿/深蹲正侧背和多相位图片。
4. 调试布线加入真正渲染的三角对角线，避免四边面内部扭曲在线框中不可见。正常材质、法线算法、灯光和FBX重定向没有为本轮改动。

裤装腰臀/裆底仍使用上一阶段的独立资产连接，覆盖规则不按动作删面。新代码不引入每帧补偿、布料、额外骨骼或更多顶点权重。上衣、头饰和已存在的混搭功能保留。

```sh
npm ci
npx playwright install chromium
npm run review:local
```
