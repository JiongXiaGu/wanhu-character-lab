## 已实现，不等于视觉已通过

1. 裸模膝部的原始坐标和截面保留。`leg-deformation.ts` 提取固定关节制作基准，并让膝后按顶点深度放宽静态双权重过渡；身体与首批裤装引用相同关节基准，但仍是独立网格，不复制人体衣面。
2. 裤装删除膝后统一压到 -0.012 的处理，删除UpperLeg冗余环和小腿不必要的大腿混权。单件裤装从252降至220个三角形；人体因有限宽度骨盆/裆底从510升至524个三角形，不是通过全身细分修复。
3. 裸模不再依赖单一中央Crotch点。`skin-pelvis.ts` 从腰口建立左右8点腿根、有限宽度裆底，再连接原6点大腿；这是固定制作拓扑，不读取动作相位，也不做每帧补偿。
4. 调试布线加入真正渲染的三角对角线，避免四边面内部扭曲在线框中不可见。正常材质、法线算法、灯光和FBX重定向没有为本轮改动。

裤装腰臀/裆底仍使用上一阶段的独立资产连接，覆盖规则不按动作删面。新代码不引入每帧补偿、布料、额外骨骼或更多顶点权重。上衣、头饰和已存在的混搭功能保留。

## 回归而非偷偷更新黄金文件

旧 `fixed-body-bind-baseline.json` 的whole-body哈希不再作为新骨盆拓扑的活动基线；固定关节哈希迁到 `fixed-bind-baseline.json`。`skin-protected-regions.json` 从原参考皮肤提取保护签名：新骨盆之外的位置、未受骨盆影响的面和锚点，以及声明腿部权重范围之外的权重必须保持精确一致。

`check-body-profiles.ts` 对男女×全部衣柜外观重复验证绑定与保护签名，并用头部位置、膝部位置、手部权重三个故障注入确认检查会真的失败。报告仍明确 `manualVisualApproval=false`；脚本不会自行签署视觉通过。

`check:deformation` 已接入 `check:mesh`。全部七款裤装和男女检查控制圈、权重和面数；新增反例覆盖旧压薄、旧长过渡位置和旧权重。原源键/中点贯穿检测器和容差不变，额外覆盖不穿裤子的情况。参数回归、几何贯穿和图片审查分别报告。

## 本地短循环

安装依赖后运行：

```sh
npm ci
npx playwright install chromium
npm run review:local
```

该命令自动扫描/提取现有FBX，在仅本机可访问的随机端口启动当前工作副本 Vite，生成32张男女×裸模/裤装×静态/坐姿×正侧背/斜视图，完成后关闭进程。图片位于 `review-deformation/local/`。完整模式 `npm run review:local -- --full` 生成156张，增加深蹲、实际三角线和坐姿/深蹲/慢跑多相位。

已有服务可使用 `REVIEW_URL` 和 `npm run review:deformation -- --quick`；完整默认156张。环境变量设置遵守当前shell语法。不能把其他端口上的旧服务当作当前源码；报告记录服务URL、checkout SHA、受测SHA、tracked dirty状态和运行环境。

这些是真实浏览器截图，不是源码几何重建，不自动表示逐帧人工审图通过。截图目录已加入gitignore，命令不推送、不部署、不改黄金数据。本次收尾已从Actions产物实际打开男女裸模、慢跑、坐姿与Pilot Flips Switches等代表性图片；未见缺面、爆炸式形变或旧式坐姿长尖片，但仍保留“图片抽样不等于所有连续瞬间”的限制。
