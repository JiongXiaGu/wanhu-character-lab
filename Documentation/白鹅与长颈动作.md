# 白鹅与长颈动作

陆地已追加 `sleep`（睡觉），原动作与网格保持。共同范围、缓存增量和睡眠专项检查见[家禽睡觉动作](家禽睡觉动作.md)；下文原阶段的动作数量与采样总量不包含此次新增动作。

## 目标与外形

goose_domestic_white是不可骑乘的白色家鹅，面向经营俯视和大量实例。暖白厚身、挺立长颈、窄长橙喙、橙色蹼足与黑眼睛形成识别轮廓，不是褐鸭换色或整体缩放。鹅不制作可见翅膀、翼区色块或空翼骨，也不恢复鸡鸭已删除的翅膀。

## 几何与绑定

src/goose/geometry.ts拥有三个独立作者档位。主体截面的朝向沿颈部中心线变化，尾—身体—颈根—颈梢—头—喙共享接口，形成一张连续闭合主壳。LOD0嘴根隆起直接进入截面，不加悬空额瘤；两侧眼睛为嵌入头面的微小闭合壳。腿和蹼足各合为一张闭合壳。

| 档位 | 三角形 | 逻辑点 | 保留内容 |
|---|---:|---:|---|
| LOD0 | 154 | 87 | 连续主壳、嘴根隆起、眼睛、腿蹼 |
| LOD1 | 82 | 47 | 完整双段长颈、头喙、腿蹼 |
| LOD2 | 44 | 28 | 長颈剪影、头喙、简化腿蹼 |

三档均由作者配置生成，不使用运行时删面或隐藏高模。单权重、单不透明FrontSide顶点色材质；逻辑点和三角展开后的渲染顶点分别计数。

src/goose/rig.ts独立拥有7骨，Root挂Body与左右Leg，Body→NeckBase→NeckTip→Head。两段颈骨服务低头觅食和前伸威吓；不是为鹅增加复杂颈链。米制、+Z前/+Y上/+X右，绑定位置转换为局部轨道。鸡鸭的8骨顺序、人物20骨与Recipe V5不变。

## 动作与水位

src/goose/animation.ts拥有作者姿态和30fps离线烘焙。运行时仍使用公共AnimationMixer与单一预览时钟，不增加IK、浮力或外部动画依赖。

| 环境 | 动作 | 秒 | 主要区别 |
|---|---|---:|---|
| 陆地 | idle_land | 3 | 挺颈观察 |
| 陆地 | walk | 1.2 | 较大跨步、少量侧摆、头颈稳定补偿 |
| 陆地 | run | 0.6 | 前倾快步、颈部前压，不只是加速Walk |
| 陆地 | graze | 3 | 双段颈部下弯，喙接近地面轻扫 |
| 陆地 | threat | 2 | 压颈前探，不展翅，不产生攻击事件 |
| 水面 | idle_water | 3 | 轻浮、蹼足水下收拢 |
| 水面 | swim | 1.5 | 平稳头颈、水下交替划蹼 |
| 水面 | feed_water | 3 | 喙浅入水面后抬起 |

参考水位为作者Y=0.235米。浮动只由Root提供；群体缩放沿用surfaceOffset对齐世界吃水线，水盘与水位裁切不改变作者网格。陆地接地检查与水下足检查各自执行，不能以裁切掩盖姿态错误。

两种环境混合周期均为6秒。陆地池只有停驻、行走、吃草，水面池只有漂浮、游泳、水面觅食；日常池不自动触发run/threat。统一动作仍是原地预览，混合位移在预留格位内的小闭环，不是导航、碰撞或动物行为树。

## 入口、构图与职责

入口为动物工坊→家畜→白色家鹅：?lab=livestock&animal=goose_domestic_white。游泳加&surface=water&clip=swim；吃草加&clip=graze&phase=.5&paused=1&view=left；群体加&count=100&mixed=1&view=farm。原数量1/10/50/100/500、三档固定/自动LOD、播放控制与模型审查共用，不新增鹅专属页面。

固定参考高度0.86米用于自动LOD估算；70/26px阈值不改。单只构图按物种参考高度适配，鹅与鸡鸭切换保留相机方向和用户缩放，只调整目标高度与正交取景范围；鸡鸭之间原相机保持不变。模型审查显示当前物种真实骨数，不再全局写死8骨。

鹅资源只在src/goose拥有；src/livestock/catalog.ts注册，Actor/缓存/水陆选择继续负责装配和生命周期。没有PoultryBase、WaterfowlSystem、额外装备槽位或鹅对鸭的继承。人物、服装和六种坐骑不因本轮改变。

## 检查与交付边界

check-livestock-goose.ts追加至原check:livestock，保留鸡鸭完整回归。三档×八动作×241相位共5784个真实蒙皮姿态检查有限坐标、首尾一致、陆地脚底、吃草最低点、水下足、浅入水范围及颈部面不塌缩；另检查闭合绕序、主壳连通/Euler、inverse bind、单权重、缓存与单只一致、各数量和混合池、重复释放。删掉颈骨权重、添加Wing、翻面、制造退化面必须被反例检查发现。有限采样不等于连续时间零自相交证明。

桌面测试追加24个档位/动作组合、真实种类与水陆切换、相位/相机方向/Renderer复用、单次末帧、100/500只与坏参数恢复；人物存档不被覆盖。显式review:livestock输出单只、侧视、步行、吃草、威吓、游泳、同角度三档和百只俯视证据。自动检查、实际看图和用户最终美术验收分别记录，Web帧率不作为Unity性能结论。
