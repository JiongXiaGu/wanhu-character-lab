## 本轮短襦作者修形

取消胸侧六点整体下挖的台阶；胸环保持连续。胸肋之间增加一段低模截面，胸背深度顺着肩、胸、肋与短下摆缓慢过渡，不再用同厚平板撑起背侧。

肩外端只做小幅落肩，前后角同步；袖山靠近腋下，用正常厚度的袖根连续接肩，不再让细管从远处跨接大袖窿。增加一段上袖过渡，肘与袖口仍保持窄长袖及原静态双权重带。

短襦下摆、裙头高度和重叠不变，不把短襦拉长。小对襟与窄袖保持；比 `short_work_jacket` 更短且是窄长袖，比 `cross_jacket` 更短、更收口且无交领大结构。与 C1 一体长袍仍是不同的两件式轮廓。

## 作者与运行时边界

两个独立工厂只复用有限缝片、连接、封口操作；不调用旧衣裙工厂，不读取另一个槽位、性别、动作或相位生成特殊几何。

短襦 covers 仍仅为 upperArm / forearm，保留完整 torso 皮肤。普通低腰裤混搭会露出腰部皮肤，不通过扩大 covers 隐藏模型问题。裙子 covers 仍为 pelvis / thigh / shin；高裙头沿 Spine / Chest，髋段过渡到 Hips / Thigh，膝下保留固定双权重。

Recipe V5 六字段、七槽位、固定成年男女、20 骨、最多双权重、一次男女映射、一个装配网格、三色染色和文件协议不变。宫女只是推荐/检索语义；不锁性别、职业或套装。

## 自动检查

`npm run check:c2` 继续检查闭合、非流形、重复面、退化面、有限值、权重、作者态自交、真实高腰/短身/袖口/裙长/折棱、男女映射一次、染色不改几何、全部另一槽位独立性与装配、V5、taxonomy 和结构故障反例。预算以实际 `c2-numeric.json` 为准，不把数值通过写成美术认可。

`npm run check:c2-motion` 继续检查男女 × 四组组合 × 起步行走、慢跑、坐姿拨动开关、射箭、Snatch。组合是 C2 整套、短襦 + 劳动直裤、短襦 + 素面长裙、交领常服 + 高腰裙。裸上身仅用于静态裙型展示，不宣称所有裸模动作已获验收。

除本轮明确授权的手/下身分类外，原分级不变：隐藏封口、衣层数学接触、仅中点接触、原裙底接口及显式资产 stress-only 保留 Warning。`snatch` 仅登记于高腰裙，不借给短襦自身的模型错误。原全目录下身贯穿和 C1 动作检查继续执行。
