# C2 宫女短襦与高腰长裙

## 当前状态

## 形与职责

`court_maid_short_jacket` 是独立 top，`court_maid_high_waist_skirt` 是独立 bottom。推荐组合形成“短上身、高腰、长下身”，不是 C1 一体长袍截成两段。两个作者工厂分别拥有固定坐标、面片与最多双权重，只复用缝片/连接/封口等小工具；不调用旧衣裙工厂，不读取当前另一槽位、性别、动作或相位改几何。

短襦相对 `short_work_jacket`：衣身明显上提，劳动短袖变窄长袖。相对 `cross_jacket`：衣长从髋部收至高腰，袖口变窄，小对襟替代旧交领装饰。新短襦不再叠加 `outfit.ts` 中的旧 CrossCollar / InnerCollar。

高腰裙相对 `long_skirt`：实际三段高裙头、16 段纵向裙片与浅折棱、克制增加的踝部展开。上部使用适合固定躯干的圆角截面，腰以下向纵向裙身过渡；中央裙片为左右错步保留固定作者宽度，不把整个素裙向上平移，不堆多层或皇后大裙摆。

## 接口、覆盖、权重

短襦下缘与裙头有固定纵向重叠；裙头独立装配，不用裙子切穿上衣，也不在换装时调整 top。高裙头沿 Spine / Chest，髋段过渡至 Hips / Thigh，膝下继续固定双权重。短襦肘内侧有静态展开权重带；没有布料、裙骨链、IK、逐帧补形。

短襦只隐藏 upperArm / forearm，保留整个 torso 皮肤；混搭低腰裤时露出的是腰部皮肤，不是空洞。高腰裙隐藏 pelvis / thigh / shin。接口封口沿用现有 seal-interfaces：top 四个封口、连续裙腰口、固定裙底。不新增覆盖协议或身份字段。

Recipe V5 六字段、七槽位、成年男女、20 骨、最多双权重、一个最终装配网格、文件协议和三色染色不变。男女映射只执行一次。宫女只是检索/推荐语义；不锁职业、性别或套装。

## 检查范围

`npm run check:c2`：闭合、非流形、重复面、退化面、有限值、权重、作者态自交、实际高腰/短身/袖型/裙长/折棱、男女映射一次、染色几何不变、全部另一槽位独立性及装配、V5、taxonomy。首轮作者结果为短襦 149 顶点 / 294 三角，高腰裙 193 顶点 / 382 三角；46 个男女装配组合，7 个结构故障反例。数字不是美术认可。

`npm run check:c2-motion`：男女 × 四组穿衣组合 × 起步行走、慢跑、坐姿拨动开关、射箭、Snatch。四组为 C2 整套、短襦 + 劳动直裤、短襦 + 素面长裙、交领常服 + 高腰裙。裸上身只用于静态裙型展示，不把裸模动画写成本轮已验收的穿衣混搭。每组保留全部源关键帧、相邻中点、首尾；全身包含高腰 torso 和双袖。原全目录下装检测与 C1 动作检测继续执行，不被 C2 代替。

相交检测数学、容差、共享顶点排除和采样均不变。日常源键/端点的外层自交、外层穿体为 Hard。原固定裙底接口、隐藏封口穿皮肤、独立服饰层之间的数学接触、仅中点瞬时接触、显式 stress-only 为 Warning。Warning 保留全部帧记录和具体顶点，每个有命中的组合/动作取最严重相位截图，不能只取安全帧。肉眼可见刺出、黑缝、翻面或破面仍升级为阻塞。
