# 背部装备

## 范围与使用

人物工坊的「随身装备 → 背部」增加竹背篓、柴捆和书笈，保留无背部装备与旧箭袋。一个选项是一个完整外观资产，男女共用语义 ID，不拆出内容物、背带、左右背挂等子槽位，不绑定职业或库存。

竹背篓 `bamboo_basket` 是宽口、窄底的厚壁空篓；外壁、口沿、内壁及内外底构成闭合表面。柴捆 `firewood_bundle` 是五根长度错落的木段与两道绑绳。书笈 `book_case` 是木框、箱体、布盖和一本固定书册，布盖沿用主布染色，扣带沿用缘边染色。竹木保留材质色。

Recipe 仍为 V5 六字段、七槽位，只扩展既有 `slots.back` 的合法 ID。导入、导出、撤销、保存恢复和随机背部锁定沿用原实现；旧客户端不知道新 ID 时仍按原严格边界拒绝，不新增兼容层。原箭袋、手持工具和服装生成不改。

## 数据所有权与装配

`src/character/wardrobe/back-equipment.ts` 拥有三件作者几何、创建时肩带贴合与版本号。`outfit.ts` 在原人物和服装完成男女映射后调用它；不把背具送进人体的非线性变形场。

载荷按男性作者空间创建，经 `shapeRigidPoint` 围绕胸骨绑定点等比映射，全部顶点刚性跟随原 Chest。肩带只在创建时对当前男女真实衣面采样；取样点复制衣面的最多双骨权重，随后随原人体骨骼蒙皮。模型、肩带与绑绳都是闭合不透明网格，不逐帧投影、不另建骨架或 Animator、不做绳或布料物理。人物继续为 20 骨、一套材质、一个 SkinnedMesh；切动作不重新生成背具。

装备不隐藏或改写人体和服装。几何生命周期继续归原人物 Actor；更换装备走原换装重建与释放，切坐骑复用骑手。骑乘只读取明确保存的装扮，不写回人物存档。

## 几何预算与检查

含双肩带的作者三角形数：竹背篓 380、柴捆 392、书笈 284；不是整个人物的面数。三种载荷各自独立，未新增人物 LOD 或运行时删面。

`npx tsx scripts/check-back-equipment.ts` 检查男女 × 全部八种上衣（包含裸模）× 三背具的 48 组组合、闭合绕序、退化面、骨权重、实际绑定姿态、服装不被改写、Recipe 往返、随机锁定和五个故障反例。

先执行 `npm run prepare:motion`，再以 `npx tsx scripts/check-back-equipment.ts --motion` 检查当前目录所有动作的源键和中点实际蒙皮、胸骨刚性跟随、网格与 inverse bind 不变，以及六坐骑上的三种骑姿采样。构建流程包含这两项检查，不削减已有检查或放宽阈值。

`node scripts/check-back-equipment-browser.mjs` 做真实换装、男女、保存恢复、导入导出、非法输入、锁定、动作相位和六坐骑切换交互，不生成截图。加 `--screenshots` 才保留三件背具三视图与女性轻跑共四张关键图。Manual Visual Review 的 `back-equipment` 范围调用该入口；PR 标题显式加入 `[back-visual]` 也能请求此范围。报告记录实际源 SHA。截图生成、AI 查看和用户认可分别报告。

## 视觉边界

数值检查不等于全部动作、衣物和坐骑之间在所有时刻零穿插。肩带不模拟受力，书册不会掉落，柴捆不散开；极端动作和骑乘时的实际接触仍由关键截图及网页验收确认。此批不做行囊、折伞、渔篓、长柄工具、背负到手持切换、物品容量或居民搬运玩法。

体验入口：`/?review=1&pose=bind&paused=1&back=bamboo_basket&view=three`，将背部 ID 换为另两种即可。普通使用不需要 `review=1`。
