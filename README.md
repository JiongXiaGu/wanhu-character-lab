# Wanhu Character Lab · 衣冠工坊 V1

《万户天工》**玩家/居民角色换装工作台**。先做好玩家自定义，再由同一套外观配方生成城市居民。服饰偏写意；Web 只负责外观、组合、动画试衣与数据审查，游戏玩法由 Unity 实现。

人体、服饰、装备由程序生成；动画只使用外部 FBX。既有男女比例、20 骨骼、双权重与男性头部校准保持，不恢复程序动作。

## 本地运行

Node.js 22.12+，拉取 main 后双击 `Start-Local.cmd`，或：

```sh
npm ci
npm run dev
```

predev/prebuild 离线提取 `动画参考/` 中的 11 个 Mixamo FBX，不下载资源、不加载源人物 Mesh/贴图。`public/mixamo/` 不提交。preview 前先 build。

## 本轮可用

| 内容 | 范围 |
| --- | --- |
| 搭配灵感 | 布衣、市井、雅居、礼仪四组，男女共 8 套推荐；可继续自由混搭 |
| 新服饰 | 4 上衣、4 下装、3 头饰；裤装、短围裳、褶裙与长裳拉开轮廓 |
| 发式与染色 | 高髻/低髻/双髻、发色；主布/下装内衬/缘边腰带三色、6 推荐色组 |
| 自定义操作 | 7 部件槽、锁定随机、可复现种子、30 次撤销、浏览器保存恢复、配方导入导出 |
| 动画试衣 | 静态绑定与全部 11 个 FBX；暂停、变速、进度、末帧、源骨架对照 |

默认静态试衣，不默认让人物一直慢跑。左侧选体型/搭配，右侧换部件、染色和发式。"全部 8 款" 可给任何身体应用任何搭配，不锁职业或性别。原农户、卫兵、弓手在折叠栏中保留。

切换男女保留现有身高和外观；"身材比例 → 重置"才恢复当前身体默认身高。切换配方保留暂停动画相位。诊断链接 `?review=1` 仍默认 FBX 慢跑，用来独立复查旧基线。

详见 [使用说明](Documentation/换装工作台使用.md)、[美术方向与分期](Documentation/玩家角色自定义与服饰分期.md)、[服装架构](Documentation/服装生成架构.md)、[第一阶段实际验收记录](Documentation/衣冠工坊V1验收记录.md)。

## 配方与迁移

Recipe V4 保留 `bodyType + preset + slots + height/build/palette`，可选新增 `dyes`、`hairStyle`、`hairColor`。旧配方不写扩展仍保留原输出。导入有格式与范围验证；普通 JSON 不是合法配方。

预设不是玩法身份；渲染只依据身体和部件数据。浏览器保存不是云存储。导出配方不是模型文件；目标骨架动画 JSON 也不是 Unity AnimationClip/Avatar/Blob 插件。Unity 应迁移明确版本的生成规则、配方、网格/绑定与目标轨道。

## 检查

```sh
npm run check:retired
npm run check:mesh
npm run build
npm run check:mixamo
npm run check:wardrobe
```

四条 Actions：Build、Character Model Review、Mixamo Retarget Review、Wardrobe Review。保留男女旧装×身材、11 个 FBX 的旧回归，新增 48 组服饰体型、184 组部件组合与新增服饰动画关键时刻检查；浏览器检查换装、锁定、导出重入、存储、移动端，并输出连续视频。

第一阶段受测代码5472912的四条流水线已通过，实际截图/视频已下载审查，完整运行、产物、SHA及已知限制见验收记录。最后纯文档收尾可引用未改变的受测代码，不把文档提交冒充新的视觉版本。

只在 Actions runner 内启动 Preview/Playwright，不部署 Visual/Vercel。必须下载当前代码版本的真实截图和视频审查，修正后合 main；绿色数值检查不是美术无穿模证明。

## 边界

第一批是写意服饰与换装工具，不是完整官服/宫廷/职业内容库，不宣称历史服制复刻。无实时布料、五指或全身 IK；长裙/袍摆使用分片蒙皮，摆动仍偏硬，宽步时内衬可能露出或穿插，极端翻转/贴地动作可能自交。静态武器不等于正确抓握，弓弦/箭/释放事件仍未制作。

无居民任务、导航、库存/生产/阶层玩法。脸型 DIY、儿童/老人、Unity 导入器、GPU 群体、LOD/剔除与万人 Profile 尚未完成。
