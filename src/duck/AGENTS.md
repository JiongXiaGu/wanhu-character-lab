# 家鸭作者资源

先读Documentation/家鸭与水陆预览.md。用户已授权非坐骑家鸭、陆地奔跑与水面三动作；不因此扩展其它物种、受惊AI、岸线或养殖玩法。

三档保持连续尾身颈头扁喙主体，不删除颈部，不将鸡作者网格换色当鸭。低档先去眼/翅附件，扁喙不能变成鸡的尖嘴。当前126/60/36三角形、77/36/24逻辑点，原8骨/每点1权重。实际预算以geometry、definition和数值报告为准。

陆地idle_land/walk/run/feed_land，水面idle_water/swim/dabble；不调用鸡的动画作者函数。水下足允许低于地面Y=0，但必须在固定水位下；不能放宽陆地接地门槛。浮动只由动作Root提供，水位对齐不能二次增加浮动。

保留鸡全部回归，新检查追加到既有家畜入口。审图用真实WebGL同版本截图，至少包含奔跑、水面和三档同角度对照；不能用图像生成替代运行时结果。合并前核对远端main并保留并行的人物动作更新。
