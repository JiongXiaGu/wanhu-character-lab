# 黑色家猪作者资源

先读 `Documentation/家猪.md`。本目录独立拥有 `pig_domestic_black` 的作者几何、米制绑定和五个陆地动作，不调用鸡鸭鹅或坐骑作者工厂。

用户最新反馈优先于L5首稿：鼻部缩小且完全取消鼻孔几何与鼻孔色块；眼睛要有可读深色眼面；四腿使用上粗下窄、无贯穿分趾凹槽的完整闭合实体。不为强守首稿面数而恢复细根腿、锥针腿或近景噪点。

三档248/138/82三角形、144/89/57逻辑点；九骨顺序为Root、Body、Neck、Head、Tail、FrontLegL、FrontLegR、RearLegL、RearLegR。每点单权重，四腿挂Root，耳眼鼻盘随Head，短卷尾随Tail。不增加膝、蹄、耳骨或毛发。

身—颈—头—鼻为连续闭合主壳。耳、尾、眼和四腿均为闭合实体且根部实际贴合。眼缘逐点投射到本档真实Head表面，LOD0保留深色眼面、LOD1保留简化眼；LOD2优先完整厚身、四腿和紧凑猪鼻。禁止为凑预算添加退化面或隐藏附件。

`root`是拱地动作ID，不是Root Motion。鼻盘靠近地面，四脚稳定；`run`仅显式预览，不进入日常池。新足底必须同步烘焙接地，不使用旧分趾外包。公共家畜层只装配、缓存和展示，不能增加猪圈、泥坑、骑乘、幼猪、繁殖或AI。
