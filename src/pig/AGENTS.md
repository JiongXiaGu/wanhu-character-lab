# 黑色家猪作者资源

先读 `Documentation/家猪.md`。本目录独立拥有 `pig_domestic_black` 的作者几何、米制绑定和五个陆地动作，不调用鸡鸭鹅或坐骑作者工厂。

三档248/114/62三角形、148/73/47逻辑点；九骨顺序为Root、Body、Neck、Head、Tail、FrontLegL、FrontLegR、RearLegL、RearLegR。每点单权重，四腿挂Root，耳眼鼻孔随Head，短卷尾随Tail。不增加膝、蹄、耳骨或毛发。

身—颈—头—鼻为连续闭合主壳。耳、尾、眼、鼻孔和四腿均为闭合实体且根部实际贴合；LOD0浅分趾不能变成悬浮黑块。低档保留厚身、四腿、猪鼻。禁止为凑预算添加退化面或隐藏附件。

`root`是拱地动作ID，不是Root Motion。鼻盘靠近地面，四脚稳定；`run`仅显式预览，不进入日常池。公共家畜层只装配、缓存和展示，不能增加猪圈、泥坑、骑乘、幼猪、繁殖或AI。
