# 鸡的低档轮廓与动作连接

## 当前作者资源

用户否定了 LOD1/2 v1：颈部缺失，头悬空，低档却保留眼睛、肉垂等无效细节。本目录的最新规则覆盖根文档中旧的64/32逻辑点记录；不是恢复旧稿或只添一根补丁脖子。

LOD0保留140三角形／100逻辑点，不改geometry.ts、rig.ts或animation.ts。LOD1 v2为72三角形／46逻辑点，LOD2 v2为36三角形／26逻辑点。实际数据与预算以catalog和检查结果为准。优先保留已合入的六边躯干轮廓，不为追求更低数字而覆盖并行修订。

## 不变量

低档的BodyNeckHead是单个闭合、连通的主体壳，躯干、颈、头和喙共用接口顶点。不能恢复分离的Head/Neck/Beak壳，更不能用隐藏连接杆、双面材质、改变镜头或只截远景来掩盖断颈。

LOD1保留六边体段和三边头颈段，删除独立眼睛、肉垂、翅片、脚趾；只保留单块小鸡冠。LOD2进一步取消独立鸡冠，仅保留连续主体、尾和合并腿脚。尾和腿可为相交闭合壳；头颈必须真实连通。

继续共用原8骨、每点单权重、四个真实动作及同一播放时钟，不增加IK或骨骼。Body到Head的连续面随原骨骼层级变形，不能为低档另改动作以逃避啄食测试。
